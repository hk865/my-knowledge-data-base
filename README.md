## 单篇论文怎样组织

每个已核验资源都有唯一文件夹，保存README文献入口和source.json。已有讲解的33篇另含reading.md与figures/；其余110项只保留文献卡，明确写出尚无独立精读，不制造空白正文。

- README：论文身份、官方原文入口、阅读深度与边界
- reading.md：实际完成的独立讲解；没有完成就不创建
- figures/：已有讲解中的原创图示，或明确说明尚无独立图像
- source.json：原文地址、阅读版本、许可、PDF本地状态与规范路径
- 原文PDF：本仓库使用官方全文链接，不公开镜像论文PDF；已核验的许可另行记录于source.json

阅读的主入口是领域目录和单篇文件夹。旧docs/deep-readings、机器人baselines和2026论文路径保留可打开的转接页。
