# 图文对齐：阅读与问题路线

[回到入门](README.md) · [Baseline](BASELINES.md) · [全部文献](PAPERS.md)

六步。前两步建立基线，中间三步各换一个部件（损失与初始化、数据、目标），最后一步看对齐空间做不到什么、怎样交给 VLM。每步给一个检验题，答不出来就回到对应的论文。

## 第一步：手算一次批内对比损失

读[自监督与生成目标讲义](../../../foundations/lessons/modules/objectives/03-pretraining-objectives.md)第 7–9 节。放在第一位，是因为本方向后面每一篇都在改这张 N×N 矩阵的某一部分：谁当负样本、每格怎样打分、矩阵里放什么数据。

检验：给一个 3×3 的相似度矩阵（自己编数，温度取 10），分别写出图到文、文到图两个方向的交叉熵；再说明批从 3 加到 3 万时，每张图的负样本数怎样变化，分布式训练时哪一步需要跨设备通信。

## 第二步：读基线 CLIP，并记下它自己承认的失败

读 [CLIP 精读](../../papers/clip/reading.md)第四至六节与第九节，对照 [ALIGN](../../papers/arxiv-2102.05918/README.md) 的数据选择。基线放在部件替换之前，因为后续每篇的动机都能在 CLIP §6 的局限清单里找到：细粒度与计数、只能在给定概念中选、零样本到少样本反而下降、建议把对比目标与生成目标联合训练。

检验：把 N 个训练配对改成 K 个候选类别，说明哪些向量可以缓存、模板集成在哪一步做；再用 ALIGN Table 10 的数字解释"规模弥补噪声"在什么规模以下不成立。

## 第三步：只换损失，或只换图像塔的初始化

读 [SigLIP](../../papers/arxiv-2303.15343/README.md)，对照 [LiT](../../papers/arxiv-2111.07991/README.md) 与 [EVA-CLIP](../../papers/arxiv-2303.15389/README.md)。这一步放在数据之前，因为它们回答的是第一步留下的工程问题：大批量的代价和从头训练的代价；三篇都不改变"整体对比"的本质，便于把效果归到单一部件上。

检验：对第一步的矩阵改用 sigmoid 损失（温度 10、偏置 −10），算出对角格与一个非对角格的损失，说明为什么不需要全批归一化；再用 LiT Fig.4 的现象解释：冻结图像塔为什么在 ObjectNet 上更好，在检索上却不一定。

## 第四步：数据才是主要的杠杆

按 [LAION-5B](../../papers/arxiv-2210.08402/README.md) → [OpenCLIP 缩放定律](../../papers/arxiv-2212.07143/README.md) → [DataComp](../../papers/arxiv-2304.14108/README.md) 与 [MetaCLIP](../../papers/arxiv-2309.16671/README.md) 的顺序读。放在这里，是因为只有先知道损失和初始化各值多少，才能看出同结构、同算力下只换数据带来的差距（ViT-L/14 从 75.5% 到 79.2%）比前两者都大。

检验：说明 LAION 用 CLIP 过滤、DataComp 用更大的 CLIP 加 ImageNet 聚类过滤、MetaCLIP 用元数据加平衡，三者各把哪一种"先验"写进了数据；如果你的下游任务是遥感或医学图像，哪一种筛选最可能漏掉你需要的数据，为什么。

## 第五步：对齐空间做不到什么

读 [Winoground](../../papers/arxiv-2204.03162/README.md)、[ARO](../../papers/arxiv-2210.01936/README.md)、[SugarCrepe](../../papers/arxiv-2306.14610/README.md)，再读 [Eyes Wide Shut](../../papers/arxiv-2401.06209/README.md)。这一步放在数据之后，是因为前面的每一次提升都用检索和零样本分类来衡量，而这几篇恰好说明这些指标测不到组合与空间关系，评测考题本身也会被刷分。

检验：为"马在吃草"写一个 ARO 式的规则负样本和一个 SugarCrepe 式的通顺负样本，说明为什么不看图的模型能识破前者；再解释 MMVP 用 CLIP 与 DINOv2 的相似度差来找题的逻辑。

## 第六步：加回生成目标，交给 VLM

读 [CoCa](../../papers/arxiv-2205.01917/README.md)、[BLIP](../../papers/arxiv-2201.12086/README.md) 与 [SigLIP 2](../../papers/arxiv-2502.14786/README.md)，然后转到[视觉语言模型方向](../vlm/README.md)。最后读它们，是因为它们是对第五步那些失败的回应：描述生成提供逐词的细粒度信号，自蒸馏与遮蔽预测提供逐块特征，而这些正是对齐编码器作为 VLM 视觉塔时最缺的东西。

检验：列一张表，把第二步与第五步记下的每一种失败（计数、细粒度、词序、朝向、多语言、分辨率）对应到 SigLIP 2 中试图修补它的部件；哪些失败没有对应的部件，留给 VLM 一侧解决。
