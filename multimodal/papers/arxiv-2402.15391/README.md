# Genie: Generative Interactive Environments

> 状态：文献卡 · 2024 · [原文](https://arxiv.org/abs/2402.15391)

[返回多模态目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：视频生成模型能生成好看的视频，却不能被"玩"：没有逐帧的动作接口；而传统世界模型需要带动作标注的数据。Genie 想只用无标注的网络视频学出可逐帧控制的交互环境。
- **核心方法**：用时空 Transformer 搭三个部件：视频分词器把帧压成离散 token；潜在动作模型从相邻两帧之间无监督地推断出 8 个离散"动作"之一；动力学模型给定过去的 token 与动作，用 MaskGIT 式掩码预测生成下一帧。最终 11B 模型在 3 万小时 2D 平台游戏视频上训练，用户每一步选一个潜在动作即可操控。后续的 Genie 2（3D、键鼠操作、自回归潜空间扩散）与 Genie 3（文本生成世界、720p 实时、一分钟视觉记忆）见官方博客。
- **为什么在这个库里**：[观点页：生成收敛](../../../perspectives/generative-convergence.md)"从视频生成到世界模型"一节的主线：Genie 系列三代各自自述的失败（16 帧记忆与 1 帧/秒 → 一分钟一致 → 动作空间与文字渲染受限）正好构成"可交互、长时一致、可编辑"三件事的进展表；与 [世界模型方向](../../fields/world-models/README.md)和[机器人世界模型讲义](../../../robotics-embodied/fields/world-models.md)中"带动作条件的预测"是同一个问题。优先级：必读。
