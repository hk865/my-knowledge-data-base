# Improved Denoising Diffusion Probabilistic Models

> 状态：文献卡 · 2021 · [原文](https://arxiv.org/abs/2102.09672)

[返回多模态目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：DDPM 样本好，但对数似然不如其他似然模型，是否覆盖了分布的全部模式也不清楚；它在 ImageNet 这类多样性高的数据上效果未知；图像上能否少步采样也没有验证。
- **核心方法**：三处改动：让网络学反向方差（在 βₜ 与 β̃ₜ 之间插值），用 Lsimple 加一小份变分下界的混合目标训练；改用余弦噪声日程，因为线性日程在 64×64、32×32 上最后四分之一几乎是纯噪声（附录写明 256×256 上线性日程反而更好）；对变分下界做重要性采样以降低梯度噪声。CIFAR-10 上直接优化下界得到 2.94 bits/dim，但这一行 FID 为 11.47，混合目标为 3.17 bits/dim 与 FID 3.19；学了方差之后 100 步即接近最优 FID，50 步以下则 DDIM 更好。类条件 ImageNet 64×64 上大模型 FID 2.92、召回率 0.71，对照的 BigGAN-deep 为 4.06 与 0.59，作者据此认为扩散模型覆盖的模式更多；FID 随训练算力在对数坐标上近似线性下降。代码公开。
- **为什么在这个库里**：[Baseline 页](../../fields/generation/BASELINES.md)部件 4"训练目标与噪声日程"（学方差、余弦日程）一格，也是"扩散模型随算力平滑变好"的早期证据。同一对作者随后写了 [ADM](../arxiv-2105.05233/README.md)，类条件的注入方式直接沿用。见 [DDPM 精读](../ddpm/reading.md)"局限与后续"第 1–3 条。优先级：选读。
