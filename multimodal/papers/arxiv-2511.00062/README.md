# World Simulation with Video Foundation Models for Physical AI

> 状态：文献卡 · 2025 · [原文](https://arxiv.org/abs/2511.00062)

- **解决什么**：初代 Cosmos 的通用视频底座还需要更好的指令控制、多种条件接口与领域适配。
- **核心方法**：Cosmos-Predict2.5 用流模型统一文本、图像与视频条件生成，加入视频奖励模型的强化学习；Transfer2.5 增加空间控制支路，用深度或分割等约束外观变换。
- **为什么在这个库里**：是 [Cosmos 初代](../arxiv-2501.03575/README.md) 到 [Cosmos 3](../arxiv-2606.02800/README.md) 的中间节点，便于拆清视频后训练和统一多模态架构的区别。优先级：选读。
