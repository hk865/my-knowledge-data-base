# Qwen2.5-VL Technical Report

> 状态：文献卡 · 2025 · [原文](https://arxiv.org/abs/2502.13923)

[返回多模态目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：VLM 的瓶颈在计算复杂度、上下文理解有限、细粒度感知差、不同序列长度下表现不稳；Qwen2-VL 的时间位置编号只与帧数挂钩，不反映事件快慢和绝对时间。
- **核心方法**：重新设计并从零训练 ViT（先 CLIP 式预训练，再对齐与端到端微调）：32 层中只有 4 层全局注意力，其余是 112×112 窗口注意力，计算随图像块数线性增长；RMSNorm、SwiGLU 与 LLM 对齐。定位坐标改用真实像素而非归一化值；M-RoPE 的时间维对齐绝对时间，支持动态帧率。预训练 4.1T token（只训 ViT 1.5T → 全参数 2T → 32K 长上下文 0.6T）；后训练 SFT + DPO，两段都冻结 ViT。
- **为什么在这个库里**：[视觉语言模型方向](../../fields/vlm/README.md)主线第 7 个节点。自述 CoT 中间步骤可能忽略或误读视觉线索，模态对齐仍是挑战。[判断] 它的两项设计被下一代 [Qwen3-VL](../arxiv-2511.21631/README.md) 自己替换：从零训练的 ViT 换成 SigLIP-2，绝对时间编号换成文字时间戳（理由是长视频中编号过大过稀、需要各种帧率均匀采样）。优先级：选读。
