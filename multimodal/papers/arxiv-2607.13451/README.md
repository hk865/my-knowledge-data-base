# Learning Physics-Guided Residual Dynamics for Deformable Object Simulation

> 状态：文献卡 · 2026 · [原文](https://arxiv.org/abs/2607.13451)

[返回多模态目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：可变形物体（绳、纸、毛绒玩具等）的动力学难以准确预测：纯物理模型受简化假设所限，纯学习模型需要大量数据、对没见过的情形泛化差。
- **核心方法**：混合模拟：以参数可优化的弹簧—质点模拟器为骨干，学习一个神经网络预测对物理结果的速度残差修正；用基于速度的形式保证模拟稳定，用滑动窗口 Transformer 聚合时间信息；不要求模拟器可微。在绳、纸、树懒玩具、掸子、旗、泰迪熊六种真实物体上，比纯物理方法（含可微弹簧—质点的 PhysTwin、MPM）和纯学习方法（GBND、PGND 等）更准；用于 MPPI 规划时，把绳穿过窄槽的任务 10 次成功 8 次，调参后的弹簧—质点基线为 2 次；还可结合 3D 高斯泼溅做动作条件的视频预测。
- **为什么在这个库里**：[机器人侧世界模型基线页](../../../robotics-embodied/fields/world-models/BASELINES.md)"② 动力学"一行：显式物理加学习残差，是机器人学"系统辨识 + 残差模型"的做法在可变形物体上的延续，与 [PIN-WM](../doi-10.15607-rss.2025.xxi.153/README.md)（可微刚体物理）形成对照。`[判断]` 代价是数据采集要 4 台 RealSense 深度相机拍多视角点云轨迹，物体和任务的种类也窄。优先级：存档。
