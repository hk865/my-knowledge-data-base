# Qwen3.8-Omni: Towards Native Omni-Modal Agents

> 状态：文献卡 · 2026 · [原文](https://arxiv.org/abs/2609.25611)

- **解决什么**：只会读单张图或一次性读完整视频的模型，难以处理需要反复定位片段、听声音并调用工具的长程任务。
- **核心方法**：以视觉、音频和空间音频编码器接入统一 Thinker，保留时间戳，并通过联合训练、专家教师蒸馏与强化学习扩展多模态工具使用；配套框架负责异步执行与上下文管理。
- **为什么在这个库里**：承接 [Qwen3-VL](../arxiv-2511.21631/README.md) 的视觉理解，展示任务接口如何扩到音视频智能体；与模型本体和外部工具分开阅读。优先级：选读。
