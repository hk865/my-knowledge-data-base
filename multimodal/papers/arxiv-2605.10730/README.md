# Qwen-Image-2.0 Technical Report

> 状态：文献卡 · 2026 · [原文](https://arxiv.org/abs/2605.10730)

[返回多模态目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：引言列出实际创作流程里仍未解决的问题：字数一多就字形扭曲、漏字、版面崩溃；英文与中文以外的文字写不准；2K 以上分辨率出现重复纹理、光照不一致、细节丢失；涉及多个实体或空间约束的提示会遗漏概念或出现幻觉；生成与编辑往往要分两条流水线。
- **核心方法**：相对 [Qwen-Image](../arxiv-2508.02324/README.md)，条件编码器换成冻结的 Qwen3-VL，提示可长达 1K token；VAE 改为 16 倍下采样、64 通道（与 8 倍下采样、16 通道的总瓶颈相同），加残差自编码结构和先强后弱的语义对齐损失（沿用 VA-VAE），并写明大规模 VAE 训练中对抗损失基本多余，去掉以求训练稳定（Sec.3.1）；MMDiT 去掉调制里的偏置、换 SwiGLU。生成与编辑从预训练起就混在一起（文生图与编辑数据先 9:1，后 7:3），分辨率从 256 逐级升到 2048；失败样本按"预训练没见过 / RL 不够 / 提示改写不够"自动分流到三条修复通道（数据飞轮）；五类奖励模型加基于 GRPO 的扩散强化学习；DMD 蒸馏到 4 次网络调用。LMArena 文生图总榜（2026-04-22）排第 9。报告没有自述局限一节，也没有写参数量。
- **为什么在这个库里**：2026 年开放团队图像配方的完整样本，[Baseline 页](../../fields/generation/BASELINES.md)部件 2、6、7 的新行；Sec.3.1 是自编码器去掉对抗损失的直接证据，[入门页](../../fields/generation/README.md)批注把它列为反例。优先级：必读。
