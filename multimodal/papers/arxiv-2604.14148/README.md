# Seedance 2.0: Advancing Video Generation for World Complexity

> 状态：文献卡 · 2026 · [原文](https://arxiv.org/abs/2604.14148)

[返回多模态目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：从"可控性有限的短片段生成"转向支持多种控制信号、可用于实际创作流程的音视频生成。
- **核心方法**：报告称采用统一的大规模音视频联合生成架构，把参考生成、编辑与续写放进同一个模型，接受文本、图像、音频、视频四种输入；结构、参数量与训练数据没有公开。相对 [Seedance 1.0](../arxiv-2506.09113/README.md) 的增量写在能力与评测上，而不是方法上。
- **为什么在这个库里**：[观点页：生成收敛](../../../perspectives/generative-convergence.md)阶段四表中 2026 年的一行，也是"从视频生成到世界模型"一节中编辑失败与物理短板的证据；它示范了"只写能力与评测、不写结构"的公司报告形态。优先级：存档。
