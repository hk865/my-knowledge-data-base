# Does Physics Live in the Activations?：把物理量的可读性、位置与可干预性分开检验

> 状态：技术精读 · arXiv v1 · 未复现

## 一句话

冻结视频生成模型后，物体附近的内部特征能让线性探针读出速度、方向、动量和重力；其中一个保持时空布局的方向探针还能改变生成视频的滚球方向。这篇最有价值的增量，是把“读得到什么”“信息在哪里”和“改它是否影响输出”接成了一条实验链。

## 它要解决的问题

看一个视频里的球沿抛物线运动，只能说明输出接近某种物理现象。要判断模型内部发生了什么，还需要知道：重力是否对应容易读取的特征？它依赖整个视频还是集中在物体上？改变这些特征能否改变生成运动？这些问题分别对应表示、组织方式与因果作用。

此前的 [How Far Is Video Generation from World Model](https://proceedings.mlr.press/v267/kang25g.html) 用受控二维系统检验生成轨迹，在分布外条件下观察到明显失败；[Interpreting Physics in Video World Models](https://arxiv.org/abs/2602.07050) 则进入视频编码器内部研究物理变量的可读性。本篇把后一个问题移到大型视频生成模型，并以连续物理量为主要目标。这里的“探针”是接在冻结特征上的小预测器，只训练读出映射，用它检验现有特征对某个任务的支持程度。

研究对象是 Wan 2.1、CogVideoX-1.5、Open-Sora 2.0 的图生视频模型。它们的主体是 DiT，即在压缩视频特征上反复去噪的 Transformer。作者分别考察无滑动滚球、弹性碰撞、抛体运动，让“物理”落实到有单位、可核对的标签，而不只是一项“视频是否合理”的分类分数。

## 核心想法

方法的增量主要在实验设计，底座结构和参数保持冻结。作者把模拟视频编码、加噪，再执行一次模型前向传播；记录残差流，也就是在各 Transformer 模块之间传递、持续累积更新的特征。随后用岭回归读出物理量。岭回归在线性拟合误差之外惩罚过大的权重，适合特征维数多、视频样本少的设置。

最关键的对照有两组。第一组把同样的读出流程应用到加噪后的视频潜变量与干净首帧条件上，检验 Transformer 是否把输入中的关系变得更容易线性读取。第二组保持预测器和输出特征维数不变，只改变参与平均的 token，也就是视频被分成的时空块：全画面、物体中心、物体周围圆盘，以及远离物体的对照圆盘。这样，物体区域胜出更能归因于信息分布，而非多给了读出器参数。

再往前一步，作者把探针权重送回生成过程。能够预测方向的权重，经过特定注入方式后，还能使部分原本向左滚的球向右滚。这使结论从相关性走向可操纵的生成因素。（本文检验的是物理量的可读性与有限方向干预，不能据此把模型等同于具有显式物体状态和运动方程的物理引擎。）

[判断] 最值得迁移的设计是“固定读出能力，改变信息位置，再检验干预”。它把一个看似抽象的理解问题拆成了可失败的具体假设；高分探针只是起点，跨场景保持程度和干预结果才进一步区分模型。

## 机制

**先让标签与画面对应。** 每种基本场景生成 200 段视频，每段 81 帧。滚球关注速度和单位方向；碰撞关注总动量及碰撞前两条速度的夹角；抛体关注重力大小和发射角。滚球由 Genesis 刚体求解器推进，碰撞与抛体按解析轨迹渲染，因为所用模拟器的刚体接触不适合所需的理想弹性碰撞。物体质量按固定密度由半径三次方确定，使质量与动量具有视觉可辨认的条件。

抛体使用较低的重力区间，让球在片段结束前保持腾空。这个设计使轨迹拟合更干净，也让实验成为一个受控的窄范围参数估计问题。它适合分析特征中的变化规律，并为后续更复杂物理现象提供可检查的起点。

**从视频到读出样本。** VAE，即将视频压缩为连续潜变量、再还原画面的编码器与解码器，先压缩时间和空间。81 个真实帧成为 21 个潜变量帧。Wan 与 Open-Sora 再划分空间块，保留 21 个 token 帧；CogVideoX 还把相邻潜变量帧配对，得到 11 个 token 帧。因此，本文的“单 token 帧”已经可能包含数个真实帧的运动。

作者在六个信噪比下抓取特征，以信号功率相对噪声功率的 dB 数值统一三个模型的噪声轴。模型始终看到干净首帧，文字条件为空。每次只运行一次去噪前向，输入来自带标签视频的人工加噪版本，因而不同噪声点有明确的同一物理标签。

对片段内恒定的量，先在物体区域和时间上平均，再预测一个标量或向量；对随时间变化的量，只平均空间，各 token 帧作为共享线性权重的样本。碰撞中的总动量对多个物体区域取平均；相对入射角则拼接两个区域，保留对象区别。对象位置与投影半径直接来自模拟器，用于构造兴趣区域 ROI，即围绕被研究物体选择的一小片 token。

**线性读出怎样被检验。** 探针可写成 q̂ = wᵀh + b。五折交叉验证按完整视频分组，同一视频的帧不会跨训练和验证集合；标准化参数与正则强度只用训练折确定。R² 衡量相对“预测均值”减少了多少平方误差，越接近 1 越好，负数表示比该基线还差。向量目标分别计算各分量，再等权平均。打乱视频标签后重新训练的对照，检验了高维特征是否会凭空产生可泛化的读出结果。

**示例数值：校准为何能改变迁移结论。** 假设新场景三段视频的真实速度是 1、2、3，原探针输出 3、5、7。真实值均值为 2，总离差平方和是 2；预测误差平方和为 4 + 9 + 16 = 29，故 R² = 1 − 29/2 = −13.5。但预测与真值的相关系数仍为 1。用 a = 0.5、b = −0.5 校准 q̂ = a·原输出 + b，就得到完全正确的 1、2、3。

这个例子说明负 R² 可能来自尺度和偏置失配，也说明使用目标场景标签重新校准是一项真实适配。本篇转移时固定探针方向，用十段目标视频估计这两个数，再报告校准后的结果。要把它用作新场景状态估计器，仍需安排目标域标注与独立测试。

**从读出到干预。** 池化后的探针只有一个全局向量，把它广播到所有 token 会丢掉时空位置。真正用于干预的探针直接拟合完整特征张量，每个 token 有自己的方向。注入使用球面线性插值，即把激活沿方向夹角旋转一部分，保留与普通向量相加不同的几何约束；在一个指定模块、前四分之一去噪步骤施加。

比较时固定随机种子，只选择基线向左滚动的样本：向右探针、反向探针和仅改成向右文字提示，分别生成对应视频。最终由实例分割器跟踪球的质心，按轨迹判为左、右或无法分类。这样直接检查了生成结果中的运动方向，而不是再次用同一个物理探针给自己打分。

## 证据：哪个实验支撑哪个主张

以下数值均按原文表格口径列出；读出成绩与生成干预成绩分别回答不同问题。

| 主张 | 支撑实验 | 怎么读 |
|---|---|---|
| Transformer 特征让重力更容易线性读取 | Table B.1，0 dB、跨十个模块平均：ROI 重力 R² 为 Wan 0.92、CogVideoX 0.90、Open-Sora 0.61；相对各自输入基线提高 0.65、0.69、0.31 | 是指定读出器下的可访问性增益，不能把低分输入读出解释为输入没有相关信息 |
| 有用信号集中在物体周围 | Fig. 3a 与 B.2：只使用约 1–2% token 的物体圆盘优于全局平均；同大小远处圆盘更弱 | 排除了单纯 token 数量和输出维数解释；位置由模拟器给定 |
| 跨时间信息汇入局部特征 | Fig. 3c：单 token 帧重力读出从干净潜变量的 0.07–0.12，上升到激活的 0.41–0.81 | 表明模型增加了局部的时序可读性；注意 VAE 与 token 化已经融合多帧 |
| 部分方向可跨场景复用 | Fig. 4、Table B.2：目标场景校准后，中位 R² 约为 0.876、0.905、0.295，依次对应三模型 | Wan 与 CogVideoX 保留较多信号，Open-Sora 较弱；这是固定方向加目标域校准的转移 |
| 一个物理方向对输出有因果作用 | Fig. 5、Table C.1：向右探针翻转率约 45%、35%、31%，文字提示约 30%、1.7%、4%，反向探针均为 0 | 支持本实验中滚动方向可被操纵，证据范围是被筛选的左滚种子与对应注入配置 |

定位结果里，“读取碰撞前 token 预测碰撞后速度”很容易让人联想到未来预测。实际网络注意力覆盖整个视频，后半段画面也在输入中。这项实验准确回答的是不同时间位置如何保存全片信息，研究的对象是时间组织，而非只给过去时的预测能力。

最能改变实践判断的是池化探针的失败。它们可以有很高的预测分数，广播注入时却先造成背景漂移、画面恶化，而非稳定改变运动。完整分辨率方向才有效。因此，“找到一个高分物理向量”与“获得一个可靠控制接口”之间，还隔着特征布局、注入层与干预强度。

## 局限与后续

[判断] 更强的下一步应同时记录可读状态、状态关系与输出轨迹。例如分别读出两球碰撞前后的动量，检验和量是否保持，再改变其中一个对象的速度，看另一个对象与总动量是否按同一物理关系响应。这样的检验才把“变量可读”推进到“变量之间的规律被使用”。本篇主要提供前者，并在单一方向上补上有限的因果证据。

场景扩展应优先加入不同密度、摩擦和恢复系数，再加入遮挡、相机运动与复杂背景。固定密度下大小能提示质量；真实场景则需要通过交互消除这些歧义。真实部署还需独立跟踪器定位 ROI，并衡量定位误差对读出的影响。作者建议的生成过程中跟踪对象、只在局部施加干预，也正好对应这一缺口。

**硬件成本要分成底座、特征提取和探针三层。** 底座参数量为 14B、5B、11B；冻结它们只免去底座反向传播。由附录的尺寸可算出，Wan 的单个视频包含 21 × 30 × 52 = 32,760 个 token，CogVideoX 因较大输入尺寸有 11 × 48 × 85 = 44,880 个。完整分辨率探针每个输出约有 token 数乘隐藏宽度个权重，池化探针只需隐藏宽度个权重。这解释了小样本下全分辨率拟合和激活保存更困难，也解释了作者为何只成功控制最简单的方向。

[估算] 若仅把 14B 参数按每参数两字节存放，权重约需 28 GB；VAE、注意力中间量、特征缓存与框架开销另计。该计算只是容量量级，不是实测显存要求。原文致谢列出计算设施，但没有给出实际 GPU 型号、峰值显存、GPU 小时或每段耗时，因而无法据此承诺单卡成本。较务实的复现顺序是先单模型、单噪声点、少量层验证 ROI 读出，再扩展全网扫描与生成干预。

## 批注

**易误读**
- “显式”在本文主要指可以用线性读出访问；它没有导出稳定的对象状态表，也未识别负责积分运动方程的模块。线性可读、变量解耦和显式状态更新是不同证据要求（§3–4）。
- “计算了输入没有的信息”应理解为变得更易线性读取。输入基线经过池化，且表示维数与 DiT 特征不同；其低分不足以证明整个视频或条件中没有物理信息（§3.1、B.1）。
- −40 dB 仍是极低而非零信噪比，且有干净首帧与模拟器 ROI 作为条件；项目页的“纯噪声”措辞比实际设置更强（§2.2、A.2）。
- 图中的层间范围不是置信区间；Table B.1 是跨层均值，不能当成最好层性能。不同模型使用各自原生分辨率，也不是等算力比较（Fig. 2、A.2、B.1）。
- 转移中的 gain 允许改变幅度与符号，因此固定的是一维读出子空间；校准后的高分不等于零样本数值预测。球换罐的半径固定，相关汇总只有四个目标（§3.4、Table B.2）。
- 反向探针没有向右翻转，并不意味着视频完全保持正常：仍被判为左滚的比例随模型明显下降，其他样本可能无法分类。方向翻转率与画面质量、物理一致性需分开报告（Appendix C）。

**与其他论文的关联**
- [How Much 3D Do Video Foundation Models Encode?](../arxiv-2512.19949/README.md) 用带注意力的读出器预测点图、深度和相机；本篇使用线性岭回归读连续物理量。二者都冻结底座，但读出器能力和标签不同，应把各自结果看成指定监督和读出预算下的可恢复性，不能直接给“世界理解程度”排统一名次（两文 §3）。
- [The Invisible Hand of Physics](https://arxiv.org/html/2606.05328v2) 通过近似反向积分获取轨迹，并用探针衡量模块扰动后的物理可行性；本篇主要用单步加噪抓取特征，在方向干预后直接跟踪生成运动。两种方法互补地提醒：既要检查特征所在轨迹，也要检查干预结论的最终评价器（前者 §3.1–3.2，本篇 §2.2、Appendix C）。
- [How Far Is Video Generation from World Model](https://proceedings.mlr.press/v267/kang25g.html) 检查新条件下是否继续遵守动力学。本篇揭示可用的内部状态信号，两者可以同时成立：有可读物理状态，仍可能在生成或外推时破坏状态关系。

- Table C.1 写全部配置使用 52 个种子，却给出 CogVideoX 提示基线 0.017，该比例不能直接由 52 个样本的整数计数得到。本文照录报告值，精确分母或额外平均方式需原始记录确认。
