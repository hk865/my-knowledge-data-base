# Qwen-Image Technical Report

> 状态：文献卡 · 2025 · [原文](https://arxiv.org/abs/2508.02324)

[返回多模态目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：引言写道，连 GPT Image 1、Seedream 3.0 这类商用模型，在多行文字、中文这类非字母文字、局部插入文字时仍会出错；编辑时既要只改目标区域（改发色不动五官），又要在大改动（改姿势）时保住身份与场景。
- **核心方法**：条件编码器用冻结的 Qwen2.5-VL（7B，一个能同时读图和文字的语言模型），取最后一层隐状态；去噪主干是 200 亿参数的双流 MMDiT（沿用 [SD3](../arxiv-2403.03206/README.md)）；VAE 沿用 Wan-2.1 的视频 VAE、冻结编码器，只用文档、幻灯片、海报等文字密集图像微调图像解码器，并报告重建变好之后判别器给不出有效指导，于是只留重建与感知损失（Sec.2.3）。写字靠数据合成与由易到难的课程（从无字到段落）；编辑时把输入图同时送进 Qwen2.5-VL（语义）与 VAE（细节）。后训练先做大规模 DPO，再做小规模 GRPO（沿用 Flow-GRPO）。GenEval 总分 0.87，RL 后 0.91，其中位置一项 0.76 → 0.87（SD3 8B 为 0.33–0.40）；3500 个一级常用汉字的单字准确率 97.29%，1605 个三级生僻字只有 6.48%（Table 9）。
- **为什么在这个库里**：[视觉生成方向](../../fields/generation/README.md)主线第 10 个节点"多模态大模型作条件编码器、编辑成为一等任务"的开放权重样本；也是入门页"判别器以损失项留在自编码器里"这一判断的第一个反例。[Baseline 页](../../fields/generation/BASELINES.md)部件 2、6、7。优先级：必读。
