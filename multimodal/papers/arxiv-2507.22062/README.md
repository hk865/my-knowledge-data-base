# Meta CLIP 2: A Worldwide Scaling Recipe

> 状态：文献卡 · 2025 · [原文](https://arxiv.org/abs/2507.22062)

- **解决什么**：MetaCLIP 的英文元数据配方难以覆盖全球图文，同时多语言扩展可能损伤英语能力。
- **核心方法**：将元数据匹配与平衡扩展到多种语言，调整样本曝光量与模型容量，检验英语与非英语数据何时能互相帮助。
- **为什么在这个库里**：接在 [MetaCLIP](../arxiv-2309.16671/README.md) 后，解释数据覆盖、训练预算和容量怎样一起决定多语言收益。优先级：必读。
