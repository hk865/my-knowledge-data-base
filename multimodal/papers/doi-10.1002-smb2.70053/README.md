# World Models for Robotic Manipulation: A Survey

> 状态：文献卡 · 2026 · [原文](https://onlinelibrary.wiley.com/doi/10.1002/smb2.70053)

[返回多模态目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**："世界模型"一词在机器人操作里已涵盖潜空间动力学模型、动作条件视频生成器、三维与四维场景预测器、物理信息模拟器，以及 VLA 内部的预测模块，文献碎片化，掩盖了对操作真正重要的设计选择。
- **核心方法**：用三个问题组织综述：预测的是什么样的未来表示；预测怎样接到动作上；预测在机器人学习流程的哪个阶段使用。把世界模型操作性地定义为"动作条件的预测系统"，与感知模块、逆模型、策略、奖励和价值函数区分开；把现有工作归为五类表示，区分"预测—动作一体的模型"与"显式预测再规划"，并刻画合成经验、候选过滤、基于搜索的评估、学习到的环境、结果验证等基础设施角色；梳理 38 个操作数据集（arXiv 预印本为 34 个），以及预测保真度、任务表现、模拟器可靠性三类评测协议。
- **为什么在这个库里**：机器人侧世界模型方向最新的综述入口；[入门页](../../../robotics-embodied/fields/world-models/README.md)"从任务看"一表的五种用法可以与它的"基础设施角色"对照读。它列出的开放挑战（接触建模、幻觉控制、动作对齐、闭环使用下的基准）也是入门页"当前开放问题"中的几项。优先级：选读。
