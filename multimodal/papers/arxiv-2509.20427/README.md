# Seedream 4.0: Toward Next-generation Multimodal Image Generation

> 状态：文献卡 · 2025 · [原文](https://arxiv.org/abs/2509.20427)

[返回多模态目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：对画质、可控性和多模态能力（文生图加编辑）的要求提高后，现有模型遇到规模化瓶颈：训练和推理都太贵。
- **核心方法**：用高压缩比的 VAE 减少图像 token，配一个高效的 DiT，按算力计比 [Seedream 3.0](https://arxiv.org/abs/2504.11346) 的训练与推理快 10 倍以上，原生生成 1K–4K 图像；在预训练好的 DiT 上，把文生图、单图编辑、多图参考与多图输出放进一次联合后训练（继续训练、SFT、RLHF），用基于 Seed1.5-VL 微调的视觉语言模型做提示工程（任务路由、改写、长宽比估计）。加速用对抗蒸馏（混合判别器）加对抗分布匹配（基于扩散的判别器）、4/8 位混合量化与推测解码，2K 图最快 1.4 秒（不含提示改写模型）。自述：在自建 DreamEval 上"困难"一档掉分，单图编辑尤甚；人评中 GPT-Image-1 指令遵循最好但与原图一致性最差，Gemini 2.5 保持原图最好但遵循不足。v3（2025 年 12 月）加了一节 Seedream 4.5（扩大模型与数据）。参数量与结构细节未公开。
- **为什么在这个库里**：[Baseline 页](../../fields/generation/BASELINES.md)部件 5"对抗蒸馏"与部件 7"生成与编辑合一"的闭源代表；它的蒸馏仍用判别器，说明判别器退出的是自编码器，没有退出蒸馏。前作 Seedream 3.0 把视觉语言模型奖励模型从 1B 扩到 20B 以上。优先级：选读。
