# Mean Flows for One-step Generative Modeling

> 状态：文献卡 · 2025 · [原文](https://arxiv.org/abs/2505.13447)

- **解决什么**：流匹配学习瞬时速度，采样仍需沿轨迹积分；直接大步跳过会引入误差。
- **核心方法**：将预测对象改成一个时间区间的平均速度，利用它与瞬时速度的恒等式训练，使模型可以一次跨完整区间生成。
- **为什么在这个库里**：接在 [Flow Matching](../arxiv-2210.02747/README.md) 后，补上"少步采样"之外"直接学习一步映射"的机制分支。优先级：必读。
