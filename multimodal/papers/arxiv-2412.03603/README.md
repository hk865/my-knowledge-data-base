# HunyuanVideo: A Systematic Framework For Large Video Generative Models

> 状态：文献卡 · 2024 · [原文](https://arxiv.org/abs/2412.03603)

[返回多模态目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：领先的视频生成模型都是闭源的，开源与闭源之间出现明显的能力和算力差距，社区缺少可以在上面做实验的强基础模型。
- **核心方法**：把 DiT 路线做成完整的开源系统：因果 3D VAE（一句话：时间方向只看过去帧的三维卷积自编码器，可同时编码图像和视频）压缩视频；Transformer 先让视频与文本 token 各走一路（双流），再拼接联合处理（单流），共 13B 参数；用 decoder-only 多模态大模型代替 T5 作文本编码器；流匹配训练，分辨率分阶段提高，最后用 100 万条人工挑选的高质量片段微调。
- **为什么在这个库里**：[观点页：生成收敛](../../../perspectives/generative-convergence.md)阶段四表中开源一侧的主要证据：结构、数据流程与评测协议都写得具体，是对照闭源报告"没写什么"的参照；它也是"最强视频模型集中在公司手中"这一判断的直接出处（摘要与 Fig.2）。优先级：选读。
