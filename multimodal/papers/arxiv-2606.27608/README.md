# Qwen-Image-2.0-RL Technical Report

> 状态：文献卡 · 2026 · [原文](https://arxiv.org/abs/2606.27608)

[返回多模态目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：去噪的监督目标不直接反映人的偏好（构图、质感、是否忠于提示）；已有的扩散强化学习框架多在 LoRA 微调下验证，没有处理多个奖励、多种任务、全参数训练，也没有处理怎样把分别为文生图和编辑训出的策略合成一个可部署的模型。
- **核心方法**：用 Qwen 系列视觉语言模型带思维链微调出奖励模型，对比后选逐点打分（回归 1–5 分）而不是成对偏好；文生图奖励分"对齐 → 美学 → 人像"三层，编辑奖励是指令遵循加人脸身份一致。按 Flow-GRPO 把多步去噪当作马尔可夫决策过程，同一提示采一组图，多个奖励在组内各自归一化再加权；采样时用无分类器引导、优化目标不含无条件分支（两处都用会训练崩溃，两处都不用会丢失风格与世界知识）；只在偏高噪声的一部分去噪步上训练，因为在全部 40 步上训练几轮内就出现奖励投机（模型钻奖励模型的空子，分数升、图变坏）。最后用在策略蒸馏把文生图与编辑两个 RL 教师合成一个学生，效果好于混合数据直接做 RL。Qwen-Image-Bench 总分 55.23 → 57.84，竞技场 Elo 文生图 +78、编辑 +93。
- **为什么在这个库里**：[Baseline 页](../../fields/generation/BASELINES.md)部件 7"扩散模型做强化学习"最细的一份工程记录，写出了奖励投机、引导怎么处理、多奖励怎么归一化这些坑；同一张表（Table 1）里 GPT Image 2（64.69）与 Nano Banana 2.0（59.82）仍高于它，是 2026 年开放模型与闭源模型差距的一个自报数据点。优先级：选读。
