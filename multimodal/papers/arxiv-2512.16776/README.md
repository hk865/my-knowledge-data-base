# Kling-Omni Technical Report

> 状态：文献卡 · 2025 · [原文](https://arxiv.org/abs/2512.16776)

[返回多模态目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：现有视频模型把文本/图像到视频、编辑、理解分成割裂的流水线，只靠文字提示描述不了精确的空间关系与视觉参照，也缺乏对物理与逻辑的理解。
- **核心方法**：用一个多模态大模型把用户的文字、参考图和参考视频改写成统一的多模态条件，再由一个在共享嵌入空间里同时处理视觉与文本 token 的生成器完成生成与编辑，最后用多模态超分辨率补细节；训练依次是指令预训练、监督微调与强化学习，推理用蒸馏压到 10 步。参数量与数据规模没有公开。
- **为什么在这个库里**：[观点页：生成收敛](../../../perspectives/generative-convergence.md)阶段四表中快手可灵一行的依据；它自称迈向"多模态世界模拟器"，是"从视频生成到世界模型"一节中公司自我定位的证据之一。优先级：存档。
