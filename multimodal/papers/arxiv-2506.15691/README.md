# What Do Latent Action Models Actually Learn?

> 状态：文献卡 · 2025 · [原文](https://arxiv.org/abs/2506.15691)

[返回多模态目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：潜在动作模型（LAM：从无标注视频里把相邻帧的变化压缩成潜变量，当作"动作"）越来越多地用于具身模型的预训练，但帧间变化既来自可控的动作，也来自外部噪声；潜变量学到的究竟是哪一种，此前没有分析。
- **核心方法**：提出一个可解析的线性 LAM，保留 LAM 训练的本质。结论：在一定假设下线性 LAM 恰好等价于主成分分析（PCA）；噪声小时能恢复真实动作；当帧间变化的主要来源不是可控信号时，潜变量编码的是噪声而不是动作；采集数据的策略随机性不足也会损害潜在动作（作者称此前文献没有记录这一点）；并从理论上解释数据增强、数据清洗、辅助动作预测为什么有效。另在合成数据上用非线性 CNN 加向量量化的 LAM 验证这些结论。
- **为什么在这个库里**：[机器人侧世界模型入门页](../../../robotics-embodied/fields/world-models/README.md)"从内部看"一节的两篇之一，回答"潜变量里是可控变化还是背景变化"。它为 [UniVLA](../arxiv-2505.06111/README.md) 用语言条件和 DINO 特征去除干扰、[Genie](../arxiv-2402.15391/README.md) 用潜在动作驱动世界提供了理论上的提醒。做不好的场景：分析建立在线性模型上，作者承认它与实际 LAM 有差距；非线性验证只用 4×4 像素的小图像合成数据。优先级：选读。
