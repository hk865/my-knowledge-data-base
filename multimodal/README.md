每个资源都有README和source.json，记录官方原文、版本、许可与阅读深度。有实际精读或章节讲解的条目才包含reading.md；文献卡明确标注尚无独立精读。用户本人是否已读不作推断。

## 使用阅读状态

- 技术精读：已完成指定版本的技术阅读，范围与残余边界见正文和证据档案
- 逐步教学版：在已有精读基础上补充逐步说明，不改变原论文结论
- 选定章节讲解：实际读了明确章节，但不宣称全部附录、图表审计
- 文献卡：只有经核验的身份、来源与索引，没有伪造精读正文
