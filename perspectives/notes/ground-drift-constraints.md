# 地面约束能修正哪一种定位漂移

## 我的问题

地面看起来逐渐倾斜或漂移时，利用地面几何能修正哪些状态？把面向轮式机器人的约束移到四足机器人，需要先检查什么？

## 目前的判断

- [建议] 先区分轨迹高度误差、地图表面变形和显示坐标系变化，再选择观测或约束。一个现象可能由不同环节造成，先保存原始传感器、位姿与坐标变换记录。
- [建议] 把地面法向方向的误差与平面内的位置、偏航误差分别评价。单一平面可限制沿法向的位移和部分倾斜，却允许沿平面平移与绕法向旋转；这是几何约束的结构性质。
- [建议] 四足机身会主动升降、俯仰或侧倾，机身姿态与地面法向的关系应由实际运动检查。强行把真实运动解释为估计误差，可能让地图更平但轨迹更错。

## 从 GR-LIO 看约束怎样进入估计

[GR-LIO](https://arxiv.org/abs/2610.05546) 在激光惯性里程计中用机身姿态与机身到地面的高度表示局部平面。地面点直接对该平面构造残差，节省逐点近邻搜索；平面运动更新进一步抑制垂直漂移。[原文 III、IV](https://arxiv.org/html/2610.05546v1#S3)

其建模条件是局部平面运动与机身坐标平面近似平行于地面。地形转换或颠簸破坏条件时，原文通过一致性检查关闭地面更新，回退到常规更新。[原文 IV-D](https://arxiv.org/html/2610.05546v1#S4.SS4)

## 待验证

以下是可选的离线比较设计：

1. 同一段记录分别运行原始 LIO、加入地面观测、再加入运动约束三个版本，固定标定、时间同步与点云输入。
2. 将平地直行、转弯、坡面转换、机身主动起伏分段。记录高度误差、姿态误差与约束启停时刻，检查回退是否恰好发生在模型失效处。
3. 有独立参考轨迹时，分开报告法向误差、平面内误差与整体轨迹误差；仅看地图视觉效果时，保留为定性观察。
4. 对四足先测机身相对地面的高度与夹角变化，再决定哪些约束能够采用、何时关闭。高度在线标定与快速步态变化应分别检验。

## 批注

**易误读**
- GR-LIO 的局部地面约束不提供全局水平位置或偏航锚点；把垂直漂移减小写成全部 SLAM 漂移消失，会超出其机制。
- 四足迁移是待验证建议，文中面向轮式平台的结论不能直接作为四足实验结果。

**未核实 / 待验证**
- v1 HTML 的平面偏移符号值得逐式复核：按 nᵀp+d=0 与 pG=RpB+t 推导，偏移应为 dG=dB−nGᵀt，而式 5 使用加号。此处是公式一致性疑点，尚未检查作者代码，不据此断言实现错误。

**候选阅读**
- Zhixin Zhang 等，2026：[GR-LIO: A Local Ground-Aware LiDAR-Inertial Odometry System Using Body-to-Ground Height](https://arxiv.org/abs/2610.05546)。优先读 III 的假设与 IV-D 的回退，再读实验；详细核验范围见[来源记录](ground-drift-sources.json)。
