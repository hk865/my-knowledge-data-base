# 观点层

[回到仓库首页](../README.md) · [写作规范第 13 节](../STYLE.md)

观点层把跨领域、跨模态的现象串成论证，回答"为什么会这样"，例如语言、视觉和生成为什么先后走向同一套训练配方。它不收录论文：每条证据都链接到领域页、跨方向页、关系页或单篇论文目录，结论标 `[判断]`，支撑论文和反例写在各页批注里。读者默认已经读过 `foundations/` 中的相关讲义。

## 两种页面

- **观点页**（本目录下的 `.md`）：一个跨领域的论点，按"驱动力 → 阶段 → 收敛与分化 → 开放问题"展开，证据来自各领域页的综合表。用户审阅前一律标"草稿"。
- **思考笔记**（`notes/`）：记录用户本人提出的问题和当前判断，每条判断标明来源是用户自己、讨论形成还是助手建议，和观点页不混用。

## 观点页

- [深度学习的规模化](scaling.md)：算力、能随数据增长的训练信号和可预测的训练工程，怎样把语言、视觉表征、生成和训练科学推过三个阶段。
- [CNN 与 Transformer](cnn-vs-transformer.md)：两类主干共用残差，差别在归纳偏置；Transformer 靠通用性与可规模化成为通用主干，CNN 在数据少、算力小和端侧场景仍占优。
- [生成的收敛](generative-convergence.md)：语言、图像、视频的生成为什么收敛到由数据出题的目标、Transformer 主干和规模化，以及生成过程仍按离散与连续分成两类。
