# The Architect Elevator — Visiting the upper floors

> 状态：资料卡 · 2017 · [原文](https://martinfowler.com/articles/architect-elevator.html)

- **解决什么**：架构工作怎样连接业务目标、组织约束和技术交付。
- **核心方法**：架构师连接业务策略、组织约束与技术实施，并在正确层面排除阻碍；用模块化和灵活设计减少早期不可逆决策；用交付结果反馈检验架构选择。
- **为什么在这个库里**：补充[Agent 权限与协作](../../fields/agents/permissions-isolation-collaboration.md)：0到1阶段先澄清目的、约束与可逆性；既有系统阶段看决策是否改善真实交付指标。优先级：选读。
