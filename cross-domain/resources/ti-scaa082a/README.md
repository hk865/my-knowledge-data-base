# High-Speed Layout Guidelines (SCAA082A)

> 状态：资料卡 · 2006 · [原文](https://www.ti.com/lit/an/scaa082a/scaa082a.pdf)

- **解决什么**：高速布局怎样同时考虑快边沿、回流路径与环路面积。
- **核心方法**：快边沿带来高频谐波，信号完整性问题不由基频单独决定；高频回流倾向低阻抗路径；参考平面开槽会绕行并增大环路面积。
- **为什么在这个库里**：作为[高速电子工程探索](../../../perspectives/notes/engineering-exploration.md)中边沿、建立时间和回流路径的历史基础材料；器件参数应另查当前手册。优先级：选读。
