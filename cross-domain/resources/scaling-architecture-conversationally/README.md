# Scaling the Practice of Architecture, Conversationally

> 状态：资料卡 · 2021 · [原文](https://martinfowler.com/articles/scaling-architecture-conversationally.html)

- **解决什么**：团队怎样分散架构决策而仍让影响范围与决策理由可追溯。
- **核心方法**：决策者须咨询受实质影响者和相关专家，记录意见，但不要求达成共识；ADR、架构咨询论坛、团队共建原则和技术雷达，帮助分散决策保持可追溯和方向一致。
- **为什么在这个库里**：补充[Agent 权限与协作](../../fields/agents/permissions-isolation-collaboration.md)：从“谁能决定、必须问谁、如何留下理由”读起，而非复制中央审批层级。优先级：选读。
