# MT-097: Dealing with High-Speed Logic

> 状态：资料卡 · 2009 · [原文](https://www.analog.com/media/en/training-seminars/tutorials/MT-097.pdf)

- **解决什么**：数字信号何时需要按传输线处理，而不能只看时钟频率。
- **核心方法**：是否需要传输线处理取决于走线传播延迟相对最快边沿的比例，而不只看时钟频率；减慢不必要的快边沿可减轻干扰，但增加延迟，必须回到系统时序预算验证。
- **为什么在这个库里**：作为[高速电子工程探索](../../fields/engineering-exploration/README.md)中边沿、建立时间和回流路径的历史基础材料；器件参数应另查当前手册。优先级：选读。
