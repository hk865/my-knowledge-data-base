# High-Speed Interface Layout Guidelines (SPRAAR7J, Rev. J)

> 状态：资料卡 · 2018 · [原文](https://www.ti.com/lit/an/spraar7j/spraar7j.pdf)

- **解决什么**：高速接口怎样控制差分偏斜、过孔反射与参考路径不连续。
- **核心方法**：差分对经历不同介质可产生时延偏差，损伤接收端眼图并增加共模噪声；连续参考平面和短过孔残桩有助于控制回流、反射与插损。
- **为什么在这个库里**：作为[高速电子工程探索](../../../perspectives/notes/engineering-exploration.md)中边沿、建立时间和回流路径的历史基础材料；器件参数应另查当前手册。优先级：选读。
