# MT-046: Op Amp Settling Time

> 状态：资料卡 · 2008 · [原文](https://www.analog.com/media/en/training-seminars/tutorials/MT-046.pdf)

- **解决什么**：模拟输出何时达到采样所需的精度，怎样测量这段等待。
- **核心方法**：建立时间指阶跃后输出进入并保持在指定误差带所需时间，比较时必须对齐阶跃幅度和误差带；测量链自身的脉冲平坦度、寄生与示波器过驱恢复会影响读数。
- **为什么在这个库里**：作为[高速电子工程探索](../../../perspectives/notes/engineering-exploration.md)中边沿、建立时间和回流路径的历史基础材料；器件参数应另查当前手册。优先级：选读。
