## 阅读线索与边界

CI要求成员至少每天集成到共同代码线，每次用自动构建与测试尽早发现集成错误；快速提交测试与更慢的真实依赖/端到端验证可以分层；作者明确指出测试不能证明不存在缺陷

- 实际阅读范围：定义、主线频繁集成、自测试构建、分层验证、未完成工作隐藏；未运行项目CI
