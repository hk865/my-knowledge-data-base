## 先理解什么

Agent研究关注模型怎样利用上下文、调用工具、观察结果并调整下一步。任务分解、记忆、执行和验证可以分开设计，评估应覆盖整个闭环而不仅是一次回答。

## 一个容易混淆的边界

文本工具成功不等于真实机器人执行成功；跨场景借鉴时必须说明动作接口和观察误差的差别。

## 入门任务
