# SciCode: A Research Coding Benchmark Curated by Scientists

> 状态：文献卡 · 2024 · [原文](https://arxiv.org/abs/2407.13168)

[返回跨方向方法目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：语言模型在许多难题上已超过普通人，越来越难造出高质量、贴近真实的评测；作者改测"为真实科研问题写代码"。
- **核心方法**：16 个自然科学子领域（数学、物理、化学、生物、材料等）的科学家出题，80 个主问题拆成 338 个子问题，每个子问题都需要知识回忆、推理与代码合成；附科学家写的标准解与测试用例，按执行结果评分；可选提供科学背景说明。最真实的设定（不给背景）下，表现最好的 Claude3.5-Sonnet 只解出 4.6% 的主问题；给出背景后，最好模型也只有 12.3%。作者说明许多题对模型过难，修订时常简化题设、补充背景。
- **为什么在这个库里**：[分任务能力图](../../fields/evaluation/domains.md)"科研"一节：给背景能提分，说明科学知识本身是瓶颈之一；按执行结果评分，又让这类任务可以进入可验证奖励的训练。与 GPQA 一类选择题形成对照：它测的是把知识落成可运行的数值方法。优先级：选读。
