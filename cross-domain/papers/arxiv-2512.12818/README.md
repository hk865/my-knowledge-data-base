# Hindsight is 20/20: Building Agent Memory that Retains, Recalls, and Reflects

> 状态：文献卡 · 2025 · [原文](https://arxiv.org/abs/2512.12818)

- **解决什么**：会话记忆容易把外部事实、亲历事件、归纳和观点混在一起，检索时难以判断各自用途。
- **核心方法**：相对把历史保留为单段文本，分别组织世界事实、经历、归纳观察与观点，通过保留、召回、反思操作及语义、关键词、图和时间线索使用记忆。
- **为什么在这个库里**：对应[工程记忆闭环](../../fields/agents/memory-evidence-loop.md)的记录与检索环节，可借鉴证据类型和时间关系的区分；跨系统比较须留意评判模型与预算口径。优先级：必读。
