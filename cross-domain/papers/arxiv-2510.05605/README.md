# AutoPentester: An LLM Agent-based Framework for Automated Pentesting

> 状态：文献卡 · 2025 · [原文](https://arxiv.org/abs/2510.05605)

- **解决什么**：授权安全测试中，智能体怎样保留累积发现、利用工具反馈并减少重复失败路径。
- **核心方法**：用持续更新的任务树关联子任务与发现，先验证和摘要工具结果再反馈给规划，另设重复步骤识别。
- **为什么在这个库里**：为[工程记忆闭环](../../fields/agents/memory-evidence-loop.md)提供任务—观察—验证的场景实例；在实验虚拟机上的结果与跨会话通用工程记忆仍是不同问题。优先级：选读。
