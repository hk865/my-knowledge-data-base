# The Illusion of Multi-Agent Advantage

> 状态：文献卡 · 2026 · [原文](https://arxiv.org/abs/2606.13003)

- **解决什么**：自动生成的多 Agent 架构，是否优于足够强的单 Agent 对照。
- **核心方法**：以逐步推理和多次采样的一致性选择构造单智能体对照，并在推理、交互任务及具有分解、上下文隔离和并行潜力的合成诊断集上比较自动与专家设计架构。
- **为什么在这个库里**：给[Agent 协作路线](../../fields/agents/README.md)提供反例：论文批评的是所测自动生成架构，专家设计在诊断集上的结果又说明分解方式值得单独分析。优先级：选读。
