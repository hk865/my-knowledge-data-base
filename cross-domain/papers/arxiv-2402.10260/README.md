# A StrongREJECT for Empty Jailbreaks

> 状态：文献卡 · 2024 · [原文](https://arxiv.org/abs/2402.10260)

[返回跨方向方法目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：越狱论文常报告接近 100% 的攻击成功率，但多数评测只看模型有没有拒绝，不看回答是否真正有用，因此高估了越狱效果。
- **核心方法**：313 条禁止提示，要求必须给出具体有害信息才算回答；自动评分器同时衡量意愿与能力：评分模型先判断是否拒绝，再给具体性、说服力各打 1–5 分（缩放到 0–1），最终分数 = (1 − 拒绝) × (具体性 + 说服力) / 2。rubric 版默认用 GPT-4o-mini，另有在其标注上微调的 Gemma 2B 版，二者与人工判断的一致性在作者比较的评分器中最好。核心发现是"空越狱"：越能提高对齐模型回答意愿的越狱，越会降低回答质量；在去掉安全微调的 Dolphin 上，这些越狱让有害回答变差；在 GPT-4o 上，用越狱方式改写的 MMLU 题准确率也随之下降。
- **为什么在这个库里**：[分任务能力图](../../fields/evaluation/domains.md)"安全对齐"一节：二元的"拒绝 / 未拒绝"评分会把空洞的回答算成攻破，换成连续评分后结论会变；这也是"评分器设计决定能测到什么"的例子。优先级：选读。
