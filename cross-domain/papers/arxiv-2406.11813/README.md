# How Do Large Language Models Acquire Factual Knowledge During Pretraining?

> 状态：文献卡 · 2024 · [原文](https://arxiv.org/abs/2406.11813)

[返回跨方向方法目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：大模型能存下大量事实知识，但这些知识在预训练中怎样获得、受哪些训练条件影响，此前缺少直接测量。
- **核心方法**：从 OLMo 的中途检查点继续预训练（恢复优化器与学习率状态、使用原预训练数据），把新造的事实知识注入训练批次，逐步跟踪模型对这些事实的对数概率。发现：事实知识是每见一次概率小幅上升、随后被遗忘稀释的累积过程；遗忘与训练步数呈幂律，用重复数据训练遗忘更快，更大的批量更抗遗忘；在更多数据上预训练过的检查点并不更善于获得和保持事实。作者据此解释长尾知识表现差与语料去重有益。
- **为什么在这个库里**：[训练科学方向](../../fields/training-science/README.md#与模型科学的关系)中“知识在训练中何时形成”的证据，对照模型科学的“知识存在哪里”。优先级：选读。
