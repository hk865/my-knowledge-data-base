# Humanity's Last Exam

> 状态：文献卡 · 2025 · [原文](https://arxiv.org/abs/2501.14249)

[返回跨方向方法目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：前沿 LLM 在 MMLU 等流行 benchmark 上已超过 90%，饱和让人无法精确测量能力进展（§1）。
- **核心方法**：全球学科专家出题，2,500 道题，覆盖上百个学科，以高难度数学题为重点；约 24% 为多选，其余为精确匹配的短答案，部分带图，全部可自动判分（用 o3-mini 作裁判核对等价格式）。出题时先让当时的前沿模型作答：精确匹配题必须难倒所有模型，多选题允许至多一个模型答对；再经两轮人工审核与发布后的公开纠错。公开 2,500 题，另保留私有测试集以检查过拟合。初版结果：GPT-4o 2.7%，o1 8.0%，DeepSeek-R1 8.5%（仅文本子集），o3-mini (high) 13.4%；所有模型 RMS 校准误差都在 70% 以上。作者自述：低分部分是筛选造成的，接近 0 的小幅变化不代表进展；高分只说明封闭式学术题达到专家水平，不代表自主研究能力。
- **为什么在这个库里**：[评估方向](../../fields/evaluation/README.md)"饱和 → 加难"链的末端（MMLU → MMLU-Pro → GPQA → HLE），也是"用当前模型筛题"这一做法的代表：分数从构造上就被压低，下一代模型的提升部分来自"不是被筛选时的那批模型"。与 [MMLU](../arxiv-2009.03300/README.md) 同一位资深作者（Hendrycks），两次都测校准。优先级：必读。
