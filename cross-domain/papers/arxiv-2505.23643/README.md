# Securing AI Agents with Information-Flow Control

> 状态：文献卡 · 2025 · [原文](https://arxiv.org/abs/2505.23643)

- **解决什么**：Agent 如何在保密性与完整性约束下，安全完成需要读取外部数据才能决定下一步的任务。
- **核心方法**：FIDES 跟踪双轴安全标签，选择性隐藏变量，并通过受约束的查看机制兼顾规划器表达能力与信息流规则。
- **为什么在这个库里**：回应 [CaMeL](../camel/reading.md) 暴露的数据依赖规划瓶颈，属于 Agent 环境与授权接口路线；优先级：必读。
