# Towards a Science of Scaling Agent Systems

> 状态：文献卡 · 2025 · [原文](https://arxiv.org/abs/2512.08296)

- **解决什么**：增加 Agent 数量或协作层级，什么时候能改善任务结果，什么时候主要增加协调成本。
- **核心方法**：当前 v3 在多类任务上受控比较单智能体和不同多智能体架构，分析模型能力、任务结构与协作方式之间的关系。
- **为什么在这个库里**：为[Agent 协作路线](../../fields/agents/README.md)保留单智能体对照和协调成本这一尺度；适用结论依赖所测任务与配置。优先级：选读。
