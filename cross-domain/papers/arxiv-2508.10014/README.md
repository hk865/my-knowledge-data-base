# PersonaEval: Are LLM Evaluators Human Enough to Judge Role-Play?

> 状态：文献卡 · 2025 · [原文](https://arxiv.org/abs/2508.10014)

[返回跨方向方法目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：角色扮演研究常用未经检验的 LLM 裁判给扮演质量打分。作者认为判断"演得像不像"的前提是先认出"这句话是谁说的"，于是把角色识别作为 LLM 裁判可靠性的最低检验：这一步做不好，对扮演质量的判断就没有根基。
- **核心方法**：把角色识别写成受约束的分类（§3.1）：给一段两轮对话，第一轮说话人已知，从 4 个候选角色（Expertise 赛道为 5 个）中选出第二轮的说话人，每个候选附人物简介。对话全部来自人写的材料，分三条赛道（§3.2）：Literary（771 部英文小说，取自 CoSER，26,208 条）、Drama（中文剧本，取自 CharacterEval，1,658 条）、Expertise（Wired "5 Levels" 视频，判断讲解对象是儿童、中学生直到专家中的哪一级，699 条）。干扰项由三个嵌入模型各挑一个与正确角色最相似的错误角色（§3.3）；再删去目标发言不足 25 token 的样本，以及 Qwen-max 给正确答案置信度超过 50% 的样本，从 11 万多条中留下 28,565 条（§3.4）。最好的模型 Gemini-2.5-pro 准确率 68.8%，多数模型在 40%–60%（§4.1、Figure 3）；20 名本科生与博士生平均 90.8%（§4.4）。推理模型整体更好；用角色扮演数据微调的豆包角色版反而比原模型差（§5.1、Figure 4）；few-shot 有提升、到 5-shot 趋于饱和，自洽投票几乎没有提升（§5.2）。
- **为什么在这个库里**：[各领域的评测](../../fields/evaluation/domains.md)第 8 节"角色扮演"的代表评测之一，支撑该节结论"主观质量没有可靠的自动裁判"；也是[评估方向](../../fields/evaluation/README.md)开放问题"不可验证的能力，判分器从哪来"在角色扮演上的一次测量。读数字时注意，人类的 90.8% 与模型的 68.8% 不是同一题集：人类做的是从 DeepSeek-R1 高置信答错的题中抽出的 50 题（§4.4）。优先级：选读。
