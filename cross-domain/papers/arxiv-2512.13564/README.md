# Memory in the Age of AI Agents

> 状态：文献卡 · 2025 · [原文](https://arxiv.org/abs/2512.13564)

- **解决什么**：长期和短期的二分难以说明 Agent 记忆究竟存了什么、怎样改变后续行动。
- **核心方法**：用载体（文本片段、参数、隐状态）、功能（事实、经验、工作记忆）和动态过程（形成、演化、检索）替代单一时间长度分类，并与检索增强生成及上下文组织区分。
- **为什么在这个库里**：提供[工程记忆讲义](../../fields/agents/memory-evidence-loop.md)的术语地图，帮助区分持久经验、当前工作材料与模型权重；分类是分析框架。优先级：选读。
