# Multi-Agent Memory from a Computer Architecture Perspective: Visions and Challenges Ahead

> 状态：文献卡 · 2026 · [原文](https://arxiv.org/abs/2603.10062)

- **解决什么**：多个 Agent 共享或同步记忆时，怎样处理旧读、覆盖、可见性和语义冲突。
- **核心方法**：借计算机体系结构的共享与分布式存储、输入输出与缓存层次组织设计问题，并区分更新时的可见性和顺序与读取时的冲突处理。
- **为什么在这个库里**：对应[工程记忆闭环](../../fields/agents/memory-evidence-loop.md)的多任务共享边界；这是一篇立场与设计议程论文，适合提出问题，尚未给出经实验验证的统一协议。优先级：选读。
