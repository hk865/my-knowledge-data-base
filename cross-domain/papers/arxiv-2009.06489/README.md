# The Hardware Lottery

> 状态：文献卡 · 2020 · [原文](https://arxiv.org/abs/2009.06489)

[返回跨方向方法目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：一个研究想法能否胜出，常常取决于它是否适合当时可用的软硬件，而不一定因为它更好；作者称之为“硬件彩票”。
- **核心方法**：随笔式论证，用历史案例说明：GPU 原为图形设计，被挪用后深度学习才跑得起来；Moore 定律与 Dennard 缩放让 1980–2010 年通用处理器性能提高约三个数量级，这期间专用硬件很快被下一代通用芯片超过；两者放缓后转向为矩阵乘法优化的专用硬件（TPU 等），偏离主流的想法因此更难做，例如胶囊网络在 GPU、TPU 上性能断崖式下降，非结构化剪枝与按权重量化不被当时的硬件和编译内核支持。
- **为什么在这个库里**：[观点：深度学习的规模化](../../../perspectives/scaling.md)中算力线“特化的代价”一格的证据：特化让主流结构更便宜，也让偏离它的结构更贵。优先级：选读。
