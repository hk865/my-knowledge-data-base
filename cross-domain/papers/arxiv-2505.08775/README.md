# HealthBench: Evaluating Large Language Models Towards Improved Human Health

> 状态：文献卡 · 2025 · [原文](https://arxiv.org/abs/2505.08775)

[返回跨方向方法目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：已有医疗评测多是选择题或窄题，与真实对话脱节，缺少与医生判断的对照，而且已被前沿模型做满。
- **核心方法**：5,000 段模型与普通用户或医疗专业人员的多轮对话，每段配一份由医生专门编写的 rubric（评分细则），共 48,562 条不重复的标准，由 262 位、26 个专科的医生在 11 个月里完成；覆盖 7 个主题（全球健康、不确定情况下的回答、按对象调整表达、追问上下文、急症转诊、健康数据处理、回答深度）与 5 个维度（完整性约占 39%，其余为准确性、上下文意识、沟通质量、指令遵循）。GPT-4.1 作为评分模型逐条判断回答是否满足标准；在 34 条医生共识标准上做元评测，它的判定一致性在 7 个主题中的 5 个超过医生个体的平均水平。总分从 GPT-3.5 Turbo 的 0.16 到 o3 的 0.60；各模型最弱的是完整性与上下文意识，o3 的 16 次采样最差得分比平均分低约三分之一。另发布 Consensus 子集与 1,000 例的 Hard 子集（最高 32%）。作者自述：不评估具体工作流与健康结局，只评单个回答。
- **为什么在这个库里**：[分任务能力图](../../fields/evaluation/domains.md)"医疗"一节；也是"rubric 加模型裁判既是评测又是可规模化奖励"的典型。长度分析值得读：o3 对 GPT-4.1 的逐例胜率为 72.9%，只比较长度相差 10% 以内的回答时降到 63.7%，作者据此说明近期分数上涨部分来自更详尽的回答，部分来自长度以外的因素。上接 [Med-PaLM / MultiMedQA](../arxiv-2212.13138/README.md)。优先级：必读。
