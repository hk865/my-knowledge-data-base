# DreamBench-SWE: A Multi-Session Memory-Hygiene Benchmark for Software Agents

> 状态：文献卡 · 2026 · [原文](https://arxiv.org/abs/2608.20664)

- **解决什么**：早期会话中出现、又无法从当前代码重新推导的信息，是否被正确保留并用于后续软件任务。
- **核心方法**：构造后续任务依赖前序证据的跨会话序列，用可执行的隐藏判据评分，并报告预注册的后继审计。
- **为什么在这个库里**：对应[工程记忆讲义](../../fields/agents/memory-evidence-loop.md)的记忆有效性检验；论文明确限制其比较范围，基准发布版本与 arXiv 版本需分别识别。优先级：选读。
