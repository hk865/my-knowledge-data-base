# Qwen3 Technical Report

> 状态：文献卡 · 2025 · [原文](https://arxiv.org/abs/2505.09388)

[返回大语言模型目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：在同一个模型里统一思考模式（多步推理）与非思考模式（快速回答），把多语言覆盖从 Qwen2.5 的 29 种扩到 119 种语言和方言，并用旗舰模型的知识降低小模型的训练成本。
- **核心方法**：预训练数据从 Qwen2.5 的 18T 扩到约 36T token：用微调过的 Qwen2.5-VL 从大量 PDF 中抽取文本，用 Qwen2.5-Math、Qwen2.5-Coder 合成数万亿 token。预训练分三段：S1 在 4,096 长度上训练 30T 以上 token，打下语言能力与世界知识；S2 提高 STEM、代码、推理与合成数据的比例，再训练约 5T 更高质量的 token，并加快学习率衰减；S3 用数千亿 token 在 32,768 长度上训练长上下文，用 ABF 把 RoPE 基频从 10,000 提到 1,000,000，推理时再用 YaRN 与 DCA 把可处理的长度扩大四倍。结构上去掉 Qwen2 的 QKV 偏置、引入 QK-Norm（计算注意力分数前对 Q、K 做归一化）以稳定训练；MoE 版本有 128 个专家、每 token 激活 8 个，不再设共享专家，用全局批次的负载均衡损失鼓励专家分工。学习率调度、批量等超参按三个阶段分别拟合规模定律。旗舰是 235B 总参数、22B 激活的 MoE。
- **为什么在这个库里**：[预训练方向](../../fields/pretraining/README.md)三处证据："损失稳定"（QK-Norm 替代 QKV 偏置）、"更多知识"（PDF 抽取与合成数据）、"预训练与后训练的分工"（S2 的推理数据让预训练末段为后训练准备材料）。它也是 Qwen 团队"持续扩大数据"这一偏好的一环（Qwen2 的 7T、Qwen2.5 的 18T 到 Qwen3 的 36T）。前一代是 [Qwen2.5](../arxiv-2412.15115/README.md)，同团队的注意力研究见 [Gated Attention](../arxiv-2505.06708/README.md)。优先级：选读。
