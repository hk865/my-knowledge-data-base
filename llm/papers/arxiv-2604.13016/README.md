# Rethinking On-Policy Distillation of Large Language Models: Phenomenology, Mechanism, and Recipe

> 状态：文献卡 · 2026 · [原文](https://arxiv.org/abs/2604.13016)

[返回大语言模型目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：on-policy 蒸馏（OPD，学生在自己生成的前缀上对齐教师的逐 token 分布）已成为后训练的核心技术，但它什么时候有效、什么时候失效，缺少系统研究。
- **核心方法**：在 Qwen3 与 DeepSeek-R1-Distill 的 1.5B–7B 师生组合上，用 AIME 2024/2025、AMC 2023 做受控实验。结论有三：OPD 成功需要两个条件，一是师生的思考模式相容，二是教师要带来学生训练中没见过的新能力（同一家族的 1.5B 与 7B 教师在学生看来分布上无法区分，"弱到强"的反向蒸馏能验证这一点）；成功的 OPD 表现为在学生到达的状态上逐步对齐高概率 token，师生共享的一小组 token 集中了 97%–99% 的概率质量；失败时可以用离线蒸馏冷启动、按教师挑选提示来挽救。代价一节指出，逐 token 的密集奖励并不免费：回答在 3K–7K token 时效果最好，超过 10K 后持平或下降；高熵先出现在回答末尾再向前蔓延；前缀越长教师越不可靠，教师相对学生的准确率优势从 1K 前缀时的 +0.37 降到 16K 时的 +0.02。
- **为什么在这个库里**：[SFT 方向](../../fields/posttraining/sft/README.md)"蒸馏能把学生带到哪里"一问的直接证据：它把"教师的上限就是学生的上限"细化成两个可检验的条件，并对长程智能体蒸馏提出疑问。优先级：选读。

## 批注

**易误读**
- 实验规模在 1.5B–7B、以数学为主；DeepSeek-V4 与 Kimi K3 在千亿级模型上用多教师 OPD 合并专家，本文的长度效应能否外推到那里未经检验。
