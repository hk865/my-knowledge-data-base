# Extending Context Window of Large Language Models via Positional Interpolation

> 状态：文献卡 · 2023 · [原文](https://arxiv.org/abs/2306.15595)

[返回大语言模型目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：LLaMA 的上下文上限是 2048。直接把 RoPE 用到更长的位置（外推）会让注意力分数失控：不微调时 LLaMA 7B 在 4096–32768 窗口上 PG19 困惑度都超过 1000；直接在长文本上微调又适应得很慢，训练 1 万个批次后有效窗口只从 2048 增到 2560（§1、Table 1）。
- **核心方法**：位置插值（PI）：把新长度上的位置索引线性压回训练时见过的范围（例如 8192 长度时每个位置乘 1/4），让模型只在见过的位置区间里"内插"；§2.3 的定理给出插值误差上界比外推小约 600 倍。LLaMA 7B–65B 扩到最长 32768，只需约 1000 步微调；7B 在 8192 窗口上 passkey 检索 200 步就达到 8192 的有效长度，直接微调 1000 步只有 2304（Table 4）。代价是原窗口内轻微下降：7B 的 BoolQ 从 76.1 降到 73.2（8192）和 64.7（32768）（Table 5）。
- **为什么在这个库里**：[长上下文方向](../../fields/long-context/README.md)"位置"一环中"插值代替外推"的起点；[YaRN](../arxiv-2309.00071/README.md) 指出它把所有频率等比例压缩、丢掉高频的局部信息，改为分频段处理。优先级：必读。
