# Chain-of-Thought Prompting Elicits Reasoning in Large Language Models

> 状态：文献卡 · 2022 · [原文](https://arxiv.org/abs/2201.11903)

[返回大语言模型目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：单靠扩大模型规模，算术、常识、符号推理这类多步任务仍做不好；给模型写出推理过程（rationale）的微调需要大量标注，普通的 few-shot 提示在推理任务上又表现差（§1）。
- **核心方法**：思维链（chain-of-thought，CoT）提示：在提示的几个示例里，把"问题 → 答案"改成"问题 → 一步步的中间推理 → 答案"，模型不改参数、照着示例先写推理再给答案。PaLM 540B 加 8 个手写示例、贪心解码，GSM8K（小学数学应用题）从标准提示的 17.9% 升到 56.9%，超过此前用微调 GPT-3 加验证器得到的 55%（Table 1）。§3.2 称它是"规模的涌现能力"：约 100B 参数以上才有收益，小模型会写出通顺但不合逻辑的推理链。
- **为什么在这个库里**：[推理时计算方向](../../fields/inference/README.md)主线的起点："让模型多写一些中间步骤"是后来自洽采样、搜索与推理模型的共同前提。§6 自述的局限（不保证推理路径正确、微调用的推理标注成本高、只在大模型上有效因而部署贵）分别被验证器、强化学习和蒸馏接手。优先级：必读。
