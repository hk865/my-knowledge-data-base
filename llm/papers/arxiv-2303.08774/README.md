# GPT-4 Technical Report

> 状态：文献卡 · 2023 · [原文](https://arxiv.org/abs/2303.08774)

[返回大语言模型目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：开发一个接受图像与文本输入、输出文本的大规模模型，并让训练基础设施与优化方法在很宽的规模范围内表现可预测，以便在大规模训练开始之前就知道结果。
- **核心方法**：报告写明 GPT-4 是以下一 token 预测预训练的 Transformer 式模型，之后用 RLHF（基于人类反馈的强化学习）微调；出于竞争格局与安全考虑，不公开结构（含模型大小）、硬件、训练算力、数据构建与训练方法。公开的增量在"可预测扩展"：用算力最多为其万分之一的模型拟合带不可约项的规模定律 L(C)=aC^b+c，在训练刚开始、没有用到任何中途结果时就准确预测了最终损失；用算力最多为其千分之一的模型预测了 HumanEval（Python 函数生成评测）子集上的通过率。
- **为什么在这个库里**：[预训练方向](../../fields/pretraining/README.md)两处证据。"预训练与后训练的分工"：考试能力主要来自预训练，RLHF 的影响不显著；预训练模型校准良好，后训练明显损害了校准（第 5 节）。"中途评估"：可预测扩展的代表，同时给出做不好的场景：在 Inverse Scaling Prize 的 Hindsight Neglect 任务上，较小模型随规模变差，GPT-4 却扭转了这一趋势，说明部分能力仍难预测。它也是"闭源团队 2023 年以后怎样预训练"这一开放问题的起点。优先级：选读（第 2–3 节与第 5 节的校准图）。
