# 2 OLMo 2 Furious

> 状态：文献卡 · 2024 · [原文](https://arxiv.org/abs/2501.00656)

[返回大语言模型目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：做完全开放的语言模型（权重、全部训练数据、训练代码与配方、训练日志和数千个中间检查点都公开），并处理上一代 OLMo 训练中的损失与梯度范数尖峰，提高每个 token 的训练效率。
- **核心方法**：稳定性一侧：把归一化移到注意力与 FFN 的输出上（reordered norm），用 RMSNorm 对 Q、K 做 QK-Norm，加 z-loss，并删除含 32 次以上重复 n-gram（1–13 个 token 的片段）的文档，训练时再屏蔽这类片段的损失。作者发现尖峰批次里常有这类重复序列，但关系不是确定的：同一序列可能在大模型上引发尖峰、在小模型上不会，换一种数据顺序也可能不再出现。课程一侧：训练分两段，约 90% FLOPs 的预训练以网页数据为主；最后 5%–10% FLOPs 的中段训练（mid-training）换成 Dolmino Mix 1124，上采样最高质量的网页与非网页来源，并用合成数学数据修补数学能力，同时把学习率线性降到 0；中段训练用不同的数据顺序做几次，再把得到的模型取平均（souping）；每个中段数据源先用小规模的"微退火"（micro-annealing）单独评估。7B、13B、32B 模型最多训练 6T token。
- **为什么在这个库里**：[预训练方向](../../fields/pretraining/README.md)两处证据：中段训练是"预训练末段为后训练准备材料"的典型（"预训练与后训练的分工"一节，作者写明它用来注入新知识、修补能力短板）；去除重复 n-gram 是"损失稳定"一行"数据组成"一列的条目。前一代是 [OLMo](../arxiv-2402.00838/README.md)。优先级：选读。
