# 架构与生成模型 学习地图

## 先理解架构是在选择什么

给一个模型输入，它要经过哪些计算，才能产生输出？这些计算怎样连接、哪些地方使用相同的参数，就是架构要决定的事。

想象你要从照片中找到一只猫。一种办法是先检查附近的小块图像，再把局部线索组合起来。换成读一段传感器记录，问题就不同了：当前读数可能不够，你还需要保留此前发生过什么。CNN 和 RNN 分别提供了处理这两类结构的办法。下面的讲义会从像素和连续读数开始讲，不要求你先认识这些名字。

![建模问题与结构选择](../../assets/foundations/architecture-map.svg)

这张图先用来找问题，不必一口气记住全部术语。局部结构指附近的输入往往有关；时间状态指处理现在时还要带上过去的信息；内容交互指根据输入本身决定应参考哪些其他位置。正文会把每一种计算拆开。

## 为什么 VAE 和扩散模型也放在这里

还有一类问题是生成：我们想让模型产生一个合理的图像或动作，而不是只判断一个已知输入属于哪类。对同一个条件，合理答案可能有很多个，因此不能总是把所有答案平均成唯一结果。

VAE 和扩散模型提供不同的生成建模办法。不过，“怎样生成”与“内部用什么网络计算”不是互斥选择。比如，扩散模型中的去噪网络可以采用 CNN，也可以采用 Transformer。先区分这两层问题，后面就不容易被模型名称绕晕。

## 每篇要走完什么过程

每篇先说明旧办法在哪个具体例子里不够用，再逐步引入结构。遇到公式时，先解释输入、输出与符号，再手算一次。图中的每条主要路径也会在正文中解释。

传统滤波、状态方程和概率推断可以帮助理解，但数学上相似不自动证明历史上由此发明。关于原始作者的动机，文末有对应的一手来源；教学类比会直接标明。
