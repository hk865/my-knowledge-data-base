# 机器人与IMU目标 从坐标约定到可观测性

[返回任务与目标总览](../../03-tasks-losses.md) · [返回学习导航](../../00-learning-navigation.md)

## 先读两分钟

机器人任务首先要区分“估计状态”和“选择行动”。对IMU而言，单位、时间与坐标系是目标的一部分；对姿态而言，输出空间本身也有几何约束。本模块把短窗监督、几何误差、滤波融合与长期漂移分开。

约定每样本为 `(x,y,m,meta)`。只把推理可得信息作为x；m标记有效监督，meta保存时间戳、坐标方向、单位和数据来源。

![机器人IMU目标总图](../../../../assets/foundations/objectives/robotics-overview.svg)

## 机器人里先分清估计与行动

**状态估计**问“当前在哪里、朝哪、速度多大”。传统估计器可能直接优化本次轨迹的状态；学习型估计器则用训练数据优化网络参数，再预测状态或观测量。两者都能用平方残差，但被优化的未知量不同。

**规划与控制**问“接下来怎么走、施加什么力”。规划代价可能包含目标距离、控制能量和碰撞项，还需动力学、力矩和接触约束。一个可微代价不意味着系统一定在训练神经网络；最优控制也可每次直接求动作。把安全约束写成有限权重惩罚，并不自动保证它永远不被违反。

**模仿学习**从示范学习观察到动作的映射。离散动作可用CE，连续动作可回归或预测分布，也可生成一个动作块。离线动作误差小，未必闭环表现好：一次偏差会把机器人带到示范中少见的状态，随后误差可能累积。DAgger研究的正是这种顺序决策中的分布改变问题。[DAgger原论文](https://proceedings.mlr.press/v15/ross11a.html)

## 标签到底是哪一种量

IMU通常给出三轴角速度和三轴比力。比力不是已经在世界系去除重力的线加速度。陀螺仪与加速度计的bias分别具有 `rad/s` 和 `m/s²` 的单位；把六个分量直接等权求MSE，已经隐含了一个尺度选择。

同一段IMU窗可以监督bias、姿态、速度或位移，但这些任务不同：预测bias是在建模传感器误差；预测速度或位移还会学习训练数据的运动规律。IMU预积分与学习式方法可以组合，不能仅因用了神经网络便忽略bias、重力和坐标变换。[流形上的IMU预积分](https://arxiv.org/abs/1512.02363)

本套讲义的EuRoC小实验采用原始窗 `x[B,200,6]`，输出短窗局部位移 `ŷ[B,3]`。以 `R_WB(t0)` 表示起点从body系到world系的旋转，标签定义为：

```text
y = R_WB(t0)ᵀ [p_WB(t1) − p_WB(t0)]
```

真值位置和姿态只用于制作标签与评价；不把它们暗中拿来校正模型输入。该实验用MSE或Huber学习局部位移，评价以米为单位的向量误差。它没有验证完整轨迹重建；将局部输出接成世界系轨迹，还需要推理时可得的姿态与初始条件，并评估这些误差。

## 姿态不是三个任意实数

平移可以作向量差，旋转属于 `SO(3)`。例如179°和−179°可以只差2°，直接相减却得到358°。欧拉角还有表示奇异性；四元数 `q` 与 `−q` 表示同一旋转，因此未经处理的逐分量MSE会把同一姿态罚成不同。

一个几何上明确的做法是先形成相对旋转，再取旋转向量：

```text
eR = Log(R真值ᵀ R预测)∨
ℓR = ||eR||²
```

这里Log把旋转映到局部李代数，`∨` 把对应的反对称矩阵读成三维向量；其模长对应主旋转角，单位为弧度。实现需处理接近零或π的数值问题，并先保证预测是合法旋转。不同左右误差约定也必须与坐标系一致。[机器人状态估计中的微型李理论](https://arxiv.org/abs/1812.01537)

位姿 `SE(3)` 同时包含旋转和平移，但米与弧度不能只因都写成数字就直接相加。常见做法是按任务容忍误差无量纲化，或使用可信协方差加权。SE(3)本身没有额外尺度自由度；单目系统中的未知尺度是另一个观测问题。

## 鲁棒核与不确定性各做什么

对几何残差 `r`，可先用正定协方差 `Σ` 形成 `s=rᵀΣ⁻¹r`，再优化 `Σ样本 ρ(s)`。前一步表达不同方向和单位上的可信程度；后一步通过鲁棒核减弱大残差影响。最小化这类残差函数属于M估计思想，并不限于神经网络。[Ceres非线性最小二乘建模](https://ceres-solver.readthedocs.io/latest/nnls_modeling.html)

注意库接口可能接收“残差平方范数”，而不是残差本身，不能把[回归模块](./01-regression-robustness.md)的标量Huber公式原封不动套上去。鲁棒阈值也必须对应白化前或白化后的尺度。鲁棒核不能自动修正错误坐标系、整段时间错位或系统性坏标签。

TLIO展示了一种具体组合：网络输出三维位移及不确定性，以高斯似然训练，再把它们用于滤波更新。它是“学习观测量并与估计器融合”的案例，不意味着所有网络置信度都可直接当滤波器协方差。[TLIO原论文](https://arxiv.org/abs/2007.01867)

## 局部loss为何管不住长期漂移

在姿态与重力处理都正确的简化情形下，恒定加速度bias `b` 造成速度误差约 `bt`，位置误差约 `0.5bt²`。例如 `b=0.01 m/s²`，100秒后这个理想化位置误差就是50米。真实系统还会有姿态误差使重力泄入水平加速度，不能把此例当作实际误差预测。

还有比loss选择更根本的信息限制。在常用的无磁力计、无外部定位的局部惯性模型下，全局位置与全局航向没有绝对参考；仅看一个IMU窗口，通常也不能唯一确定初速度。两个不同匀速平移可以给出相同惯性读数，却有不同位移。

![步骤二 初速度歧义与可观测性](../../../../assets/foundations/objectives/robotics-observability-step.svg)

因此，位移监督网络可能利用数据中的运动先验取得统计上有效的预测，但并没有凭空恢复缺失的物理观测。TLIO特意采用局部重力对齐位移，避免向滤波器注入虚假的航向可观测信息。跨设备、携带方式和运动类型测试，是区分“学到了先验”与“普遍有效”所必需的。[TLIO第V节](https://arxiv.org/pdf/2007.01867)

EuRoC的参考状态来自离线估计流程，并非逐时刻完全独立、无噪声的真值。训练能学习参考系统的误差特征；测试报告应写明参考来源。姿态四元数的分量顺序、旋转方向与时间插值必须核对数据说明，而不能凭字段名猜测。[EuRoC原论文§4.1与§5.2](https://doi.org/10.1177/0278364915620033)


## 关键论文段落研读

**研读定位：TLIO §IV-A、§V-D/E和§VI-A，属于目标与系统接口的重点章节研读。** 先读§IV-A：网络预测位移均值与对角协方差，训练不只要求位移准确，还要使分布解释残差。再读§V-D：局部重力对齐的位移作为滤波观测，避免把全局航向误当成可观测信息。[TLIO原文](https://arxiv.org/pdf/2007.01867)

最容易漏掉的两处是：原文为重叠窗相关性将预测协方差放大10倍；实验初始化使用真值速度与roll/pitch并赋大协方差，位置和yaw用于固定规范自由度。因此这篇结果不能被转述为“只输入原始IMU、无初始条件、网络方差拿来就能用”。最后读§VI-A，分别看整段位置误差、相对误差与最终漂移，才知道模型在哪个时间尺度被评价。

上面的EuRoC教学实验只回归起点body系位移；TLIO的局部重力对齐系和完整滤波流程不同。本模块没有复现TLIO，也未覆盖其所有消融与附录推导。
