# IMU窗口怎样对应一个位移标签

[数据模块目录](../../04-data-and-datasets.md) · [总导航](../../00-learning-navigation.md)

## 先读两分钟

只给IMU短窗一般无法唯一知道初速度。这个实验用于理解监督回归如何学习数据分布中的运动先验；它不是任意运动的严格惯导解，也没有宣称消除长期漂移。读完应能解释时间边界、坐标方向、参考标签和推理输入的区别。

## 实验目标与标签


[EuRoC 官方介绍](https://projects.asl.ethz.ch/datasets/euroc-mav/)提供无人机双目、200Hz IMU、标定和运动真值。这里仅规划读取 IMU CSV、对应状态真值与标定；不需要把全量图像载入内存。当前 [ETH 归档](https://www.research-collection.ethz.ch/items/bcaf173e-5dac-484b-bc37-faf97a594f1f)按较大压缩包提供数据，实际获取可能仍需较多磁盘和流量，应先检查归档内容与下载粒度。本篇没有下载这些包。

**目标定义。** 固定约一秒窗口，输入为机体系六轴读数：`[ωx,ωy,ωz,ax,ay,az]`，单位分别是 rad/s、m/s²。令 `R_WB(t)` 把机体系向量转到世界系，`p_WB(t)` 是机体原点位置。标签为起点机体系下的三维位移：

\[
y=\Delta p_{B_0}=R_{WB}(t_0)^\top[p_{WB}(t_1)-p_{WB}(t_0)]\in\mathbb R^3.
\]

GT 姿态只用于制作标签，不用于旋转输入，不作为网络附加特征。必须通过数据表头和标定确认姿态方向、机体是否为 IMU 原点，以及四元数排列；不同传感器原点之间有杆臂，不能只改旋转而忽略平移。

## 第一步 让时间区间与标签一致

![200个区间配201个时间边界，输入取左端点读数](../../../../assets/foundations/data/d-time.svg)

**时间定义。** 在 200Hz 的统一时间网格上，200 个 0.005 秒区间恰为一秒，需要 201 个边界时刻。输入取每个区间左端的 200 条六轴读数，标签用首尾两个边界时刻。这样避免把 200 个采样点本身误说成跨越整整一秒。标签位置插值只能在可靠 GT 范围内；起点姿态用规范的旋转插值。源时间先以整数保存，减去序列起点再转秒，避免大纳秒时间戳转换成 float32 丢精度。

**划分和规模。** 教学可用 MH_01_easy、MH_02_easy 的可靠区间训练，MH_03_medium 验证，MH_04_difficult 测试，并把精确序列名和保留区间写入清单。这是作者设计的同场景跨序列教学划分，不是官方神经网络 split；MH_05 或 Vicon 房间可另做更难分布测试，不能因此宣称跨人或跨设备能力。窗口步长可设 0.1 秒，训练只保留最多 10,000 窗，验证和测试按固定规则覆盖有效区间。

**模型和 loss。** 小型 1D CNN/TCN，输入 `[B,200,6]`，输出 `[B,3]`；起始 batch 64。MSE 或 Huber 都可先试一个，Huber 的阈值必须说明对应米还是标准化单位。先与零位移和训练集平均位移预测比较，再报告位移向量误差的均值、中位数、95 分位数和每条序列结果。分量 MSE 的量纲是 m²；欧氏位移误差的量纲是 m，二者不可混名。

## 第二步 区分标签坐标与部署信息

![世界系位移转换为起点机体系标签，轨迹扩展需额外条件](../../../../assets/foundations/data/d-frames.svg)

**必须理解的边界。** 只给短窗 IMU，一般无法唯一知道初速度；两种不同匀速运动也可能给出相同读数。网络是在训练分布上学运动先验，不会消除惯导的不可观性。此实验没有验证全局轨迹，也不是复现 RoNIN。若后续把局部位移转到世界系，需要推理时可获得的因果姿态估计；用 GT 姿态积分应标为 oracle 诊断。若每 0.1 秒预测一秒位移，也不能把这些重叠位移直接累加。完整轨迹才适合报告约定清楚的 ATE/RPE。

这类输入 batch 本身很小，百万级以内模型预计可在16GB显存中练习；真正风险往往是标签/同步而非显存。官方也提醒 GT 同步存在采集系统限制。当前 ETH 归档标注“In Copyright - Non-Commercial Use Permitted”；这是记录页面事实，不是对具体用途的法律判断。

## 论文精读片段 EuRoC的参考状态从哪里来

关联论文：[The EuRoC MAV Datasets作者稿](https://www.researchgate.net/profile/Michael_Burri2/publication/291954561_The_EuRoC_micro_aerial_vehicle_datasets/links/56af0c6008ae19a38516937c.pdf)，正式版本[DOI](https://doi.org/10.1177/0278364915620033)。这里核对第4节接口、第5节标定/同步与第6节限制，没有运行其标定程序。

第4节约定body位于IMU坐标系，时间用整数纳秒，其余测量用SI单位；四元数为Hamilton、wxyz顺序。第5.2节说明，提供的完整参考状态由离线平滑器结合跟踪与IMU测量估计，并包含时空对齐。因而state_groundtruth_estimate应理解为有处理过程的参考估计，而非逐时刻完全独立、无噪声的直接测量。

将论文约定代入本实验：先读位置p_WB与旋转R_WB，再作位置差，再左乘R_WB(t0)的转置。转置在这里表示旋转逆，不能替换成原矩阵。单位仍为米，因为旋转没有长度量纲。公式必须配合origin一致性检查；若读的是原始Vicon marker姿态，应先用外参转为IMU机体原点，而不是直接拼字段。

第6节提示动态运动下的跟踪精度及时间同步限制。阅读后的合理结论是：小幅度误差改进可能受参考误差影响，必须结合不同序列和稳定区间分析；不能只凭总体均值宣称算法解决了偏置或漂移。

手算自检：若R_WB为单位阵，标签就是世界系位置差；若它是绕z轴正90°旋转，世界系+x方向1米在起点机体系中应为−y方向1米。这个数值检查能发现矩阵方向写反。再问一次：为标签做这个变换不等于部署时拥有真值姿态。
