# 动量与逐坐标自适应优化

## 1. 为什么只听本次梯度的建议可能不够

假设你正在调整模型里的一个参数θ。每一小批数据都会给一个梯度g：正数建议把参数减小，负数建议把参数增大。普通SGD只听本批建议，按Δθ=−ηg更新，η叫学习率。

但小批数据并不完全相同。一批建议向左，下一批可能建议向右。还有另一种困难：某些参数的梯度常常很大，另一些很小。如果所有参数共用一个比例系数，可能一边来回越过合适位置，另一边却走得很慢。

本章用两种记忆解决不同问题。动量记住带正负号的方向，看最近是否一直往同一边；Adagrad和RMSProp记住平方大小，为每个坐标调整尺度。它们不是认识数据的“聪明程度”不同，而是把同一批梯度加工成更新的规则不同。

![动量与自适应优化的分工](../../../../assets/foundations/02b-overview.svg)

图上排前三格可以读成“只看当下”“积累方向”“积累幅度”，下排的RMSProp再让幅度记忆逐渐遗忘。读这张图时，不要把“平方梯度”误读成“二阶导数”：前者只把已经算出的数平方，后者要再求一次导数。

## 2. 先把时间顺序固定下来

设训练开始时参数为θ₀。第1步在θ₀上计算g₁，然后更新到θ₁；第2步在θ₁上计算g₂，再更新到θ₂。下标t表示第t次更新，不是样本编号。

优化器还会存额外的状态。例如mₜ可以保存方向记忆，sₜ可以保存平方大小。它们不是模型面对新输入时要使用的新特征，而是训练时帮助决定参数怎样改的账本。下面所有状态从0开始。

为方便手算，我们先用一个参数。实际模型有许多参数时，相同计算可以逐坐标进行。例如g=(2,−3)，g²表示(4,9)，不是2²+(−3)²；√s和除法也逐坐标计算。需要把坐标加起来时，会明确写出求和。

## 3. 动量先记住上一回合，再加入本次建议

本节采用未归一化的动量写法：

mₜ=βmₜ₋₁+gₜ

θₜ=θₜ₋₁−ηmₜ

β在0和1之间，控制旧记忆保留多少。β=0.5就是上一回合只保留一半，再加上这回的新梯度。m像一条经过历史加工的建议；实际位移是−ηm，不是m本身。

设η=0.1，β=0.5，初始m₀=0。连续三批的梯度都是+1：

第一步：m₁=0.5×0+1=1，位移−0.1。

第二步：m₂=0.5×1+1=1.5，位移−0.15。

第三步：m₃=0.5×1.5+1=1.75，位移−0.175。

普通SGD三步总共走−0.3，动量三步走−0.425。这里连续建议一致，算法愿意走得更有力。若梯度一直为1，m会接近2：因为达到稳定时应满足m=0.5m+1，解得m=2。它不会无限增长。

再看梯度+1、−1、+1：

第一步仍是m₁=1，位移−0.1。

第二步：m₂=0.5×1−1=−0.5，位移+0.05。前一步的正向记忆抵消了一部分反向建议。

第三步：m₃=0.5×(−0.5)+1=0.75，位移−0.075。

![同方向与交替方向的动量计算](../../../../assets/foundations/02b-momentum-steps.svg)

图的上排是持续一致的梯度，下排是交替梯度，两个实验的梯度大小完全相同。区别来自正负方向的历史，不是动量预先知道哪一批更可靠。上排位移逐步增大，下排的部分往返相互抵消。

在狭长山谷里，跨越谷底的陡方向常出现反复变号，而沿谷底的平缓方向可能持续同号，因此这种记忆可能有帮助。但若应当前进的方向突然改变，旧记忆也会拖后腿。动量并不保证每一步的损失都下降，学习率和β仍需选择。[1]

## 4. 两种动量公式为什么不能直接比较学习率

另一些材料写成：

mₜ=βmₜ₋₁+(1−β)gₜ

这叫指数滑动平均。“指数”来自旧梯度的权重会依次乘β：最新梯度的权重是1−β，上一步是β(1−β)，再前一步是β²(1−β)。

如果g一直为1，这个版本的m接近1；前一节不乘1−β的版本接近1/(1−β)。两种形式的历史方向相似，数值尺度却不同。β=0.9时相差10倍，所以不能只凭“两个算法都用学习率0.1”就说步子一样大。

滑动平均也不是只记最近固定十步。更久的历史权重通常不为零，只是越来越小。β越接近1，旧信息衰减越慢，曲线通常更平滑，但响应变化也更迟钝。

这正是阅读实现要核对的内容：它保存的是梯度累计，还是归一化均值？学习率在累计之前还是之后进入？状态初值怎么设？记号不统一时，先把一两步数字算出来，比背算法名称可靠。

## 5. Nesterov怎样在惯性冲过头之前修正

普通动量在当前位置查看坡度，再叠加惯性。Nesterov的一种直观解释是：先估计仅靠惯性将走到哪里，在那个位置查看坡度，再调整本次位移。[1]

为避免正负混乱，这一节用v保存“带方向的位移记忆”。与前面的梯度记忆m不同，v已经朝参数实际移动的方向。示意更新为：

前瞻位置=θ+βv

v新=βv−η∇L(θ+βv)

θ新=θ+v新

∇L表示该位置的梯度。前瞻位置由当前已知的θ和v算出，不是看到了未来样本，也不是预测下一批梯度。

用L(θ)=θ²/2手算，它的梯度就是θ。设θ=1、v=−0.2、β=0.9、η=0.1。

若用经典动量：保留位移βv=−0.18；当前位置梯度为1，因此再减0.1，得到v新=−0.28、θ新=0.72。

若用上述Nesterov形式：前瞻位置1−0.18=0.82；在那里坡度只有0.82，因此再减0.082；v新=−0.262，θ新=0.738。它看见惯性已经把自己送到较缓处，于是稍微减小了本步修正。

这个例子只说明两种规则怎样不同，不证明Nesterov每一步都更好。Sutskever等的论文同时研究初始化和动量调度；其中“加速”的经验结果不能脱离配置单独归给名称。实际库还可能用重排后的等价变量实现，不必机械地每步额外运行一次完整网络。[1]

## 6. Adagrad为什么要给每个参数单独存平方和

再设模型有两个参数。第一个频繁收到较大梯度，第二个很少被触发。我们希望避免前者每次都把步子撑得很大，同时允许后者在出现信号时有机会改变。Adagrad为各参数保存自己的累计平方梯度：[2]

sₜ=sₜ₋₁+gₜ²

Δθₜ=−ηgₜ/(√sₜ+ε)

ε是一个很小的正数，避免分母为零或过小。平方让正负梯度都增加账本；开平方使分母回到与梯度相对应的尺度。η仍是全局学习率，不会因为“自适应”就消失。

取二维梯度g₁=(2,0)，忽略本例非零坐标上的ε。s₁=(4,0)，第一个坐标的更新为−η×2/2=−η；第二个坐标梯度为0，带着ε计算得到更新0，而不是计算0/0。

第二步g₂=(2,1)：s₂=(4,0)+(4,1)=(8,1)。更新为−η(2/√8,1)=−η(0.7071,1)。

第一个坐标持续活跃，累计量较大，同样的梯度2现在只产生约0.7071η的位移；第二个坐标刚出现信号，相对步子更大。这是“稀疏特征可能受益”的具体含义：某些特征大多数时候不出现，它们对应的梯度历史也小。[2]

算法并不知道罕见特征必然重要。重要性仍由数据和损失决定；它只是根据历史频率与幅度调整尺度。若一个坐标一直收到1，s会等于步数t，更新幅度约为η/√t，因此训练很久以后可能小得难以继续适应。

## 7. RMSProp怎样忘记很久以前的一次尖峰

RMSProp保留同样的除法结构，但把“全部历史累加”改为平方梯度的指数滑动平均：[3]

sₜ=ρsₜ₋₁+(1−ρ)gₜ²

Δθₜ=−ηgₜ/(√sₜ+ε)

ρ控制平方历史保留比例。它与动量中的β作用类似，但记的东西不同：m记带正负号的梯度，s记非负的平方幅度。

设ρ=0.9，梯度依次为1、1、10、1。逐步算：

s₁=0.9×0+0.1×1=0.1。

s₂=0.9×0.1+0.1×1=0.19。

s₃=0.9×0.19+0.1×100=10.171。

s₄=0.9×10.171+0.1×1=9.2539。

第三步的10先被平方成100，显著抬高统计量；第四步恢复普通梯度后，统计量开始下降。若后面一直收到1，s会逐渐接近1，而不会永远记住10造成的全部冲击。

同一序列的Adagrad账本为1、2、102、103，永远不会减少。

![一次梯度尖峰后两种历史统计的变化](../../../../assets/foundations/02b-adaptive-history.svg)

图的横轴是步骤，纵轴是s，不是损失，也不是实际步长。Adagrad线较高不能说明它训练较差；两条线的定义不同。要看对更新的影响，还应开平方，再看当前梯度与分母的比值。例如第四步RMSProp分母约3.042，而Adagrad约10.149，在相同η且忽略ε时，相应位移约0.329η和0.0985η。

RMSProp的早期一手来源是Hinton课程讲义，其中介绍Tieleman的未发表工作。这里把它列为课程材料，而不虚构一篇所谓原始期刊论文。[3]

## 8. “自适应”知道什么，又不知道什么

这些方法都从已经观测到的梯度构造统计。它们没有直接测出损失的全部曲率，也没有知道未来数据的真实分布。

以两个参数为例，逐坐标方法会分别维护s₁和s₂，但不显式记录“这两个参数通常怎样一起变化”。若狭长山谷沿斜方向延伸，分别缩放横轴、纵轴不一定完全对准谷底方向。更复杂的预条件方法会利用参数间关系，但计算与存储代价也可能更大。

方向记忆与幅度记忆还解决不了错误标签、错误单位、无效数值或泄漏的测试数据。训练分数降得快，也不代表未见数据表现最好。比较时至少保持数据预算、验证方法、计算资源可比，并分别调学习率，不能用一个通用数字裁定谁优谁劣。

## 自检

1. 未归一化动量中，β=0.5，g永远为1，m为什么接近2？因为稳定时m=0.5m+1。
2. 梯度从+10变成−10，平方统计会抵消吗？不会，两次都贡献100；只有带符号的方向记忆可能抵消。
3. Adagrad为何会越走越谨慎？累计平方只增不减，分母随历史增长。
4. RMSProp为何能重新适应尖峰之后的普通尺度？旧统计每一步都乘ρ，尖峰影响逐渐衰减。

接下来的Adam会同时保存一阶方向平均和二阶平方平均，再解决它们从零开始时的早期偏小问题。本章的数字都是算法机制算例，不是某个任务的实测性能。
