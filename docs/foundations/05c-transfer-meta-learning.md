## 迁移 微调与 LoRA 的关系

“换一个任务，同时复用一部分知识”是理解迁移学习的一个入口。还要把三层概念分开：

- **迁移学习**描述知识复用问题：来源任务或领域学到的东西，怎样帮助目标任务或领域。同一任务换数据分布也可能需要迁移，不一定要换任务。
- **微调**描述适配操作：从已有参数出发继续训练。可以全量更新，也可以只更新部分参数；迁移还可以采用冻结表征、另训任务头等方式。
- **参数高效微调 PEFT**描述减少可训练参数的一类方法，LoRA 是其中一种，adapter 等也在这条线上。[Adapter 原论文](https://arxiv.org/abs/1902.00751)

LoRA 的基本形式是冻结已有权重 W₀，用两个较小矩阵相乘表达更新量：W=W₀+BA。低秩限制的是这一处的权重更新，不是说整个模型或全部知识都是低秩的。它可以减少需训练、保存的适配参数及相关优化器状态，但基础模型和前向计算并未消失，也不保证每个任务都达到全量微调的效果。[LoRA 原论文](https://arxiv.org/abs/2106.09685)

**预训练与适配是一种阶段关系。**预训练通常积累可复用的表征与能力，适配则把它们转向目标数据、任务或行为。继续预训练、监督微调、偏好优化，关注的信号并不相同；LoRA 则是“允许哪些参数怎样变化”的选项，可以与其中多种训练目标组合。比较方案时，先固定目标数据和评估标准，再比较全量微调、LoRA 或冻结表征；“通常先试哪个”是工程选择，不是概念定义。

## 元学习与大规模预训练的交集和边界

元学习关心“如何利用跨任务经验，让新的学习过程更有效”。它不只是一种网络，也不只等于少样本分类。几个典型切面可以帮助定位：

- **MAML 学初始点**：跨多个任务训练，使模型在新任务上经过少量梯度更新，就能在该任务的另一批样本上表现好。内层是任务适配，外层优化适配之后的效果。[MAML 原论文](https://proceedings.mlr.press/v70/finn17a.html)
- **Learned optimizer 学更新规则**：把“给定梯度等信息，下一步怎样改参数”也交给学习系统。它的泛化范围需要检验，不能从训练过的优化问题直接推到所有网络。[学习优化器原论文](https://arxiv.org/abs/1606.04474)
- **上下文学习 ICL**：模型通过提示中的示例调整当前行为，通常不在推理时更新权重。GPT-3 展示了这类少样本能力；这与通过跨任务经验获得适应能力的研究问题有联系。[GPT-3 原论文](https://arxiv.org/abs/2005.14165)

所以，“大数据预训练吸收了一部分学会学习的能力”有依据；“只要数据和模型够大，就基本解决元学习”则过强。下一 token 预训练的目标，与“少量适配后在新任务上泛化”的外层目标并不相同。某些理论在特定数据生成假设下，把 ICL 解释为隐式贝叶斯推断；它们没有证明任意规模模型都能适应任意新任务。[ICL 理论论文](https://arxiv.org/abs/2111.02080)

判断这条线是否有用，应看具体约束：新任务与旧任务相差多远，能提供几个样本，能否改权重，需要多快适应，以及适应后能否保持可靠。规模给出了强基线；元学习仍提供问题定义、训练目标与评估方法。是否“热门”不应代替这些判断。

## 后续精读怎么接

- [LoRA 原论文 待专项精读](https://arxiv.org/abs/2106.09685)：低秩约束放在哪里？节省的是哪些训练状态？与全量微调的比较条件是否一致？
- [MAML 原论文 待专项精读](https://proceedings.mlr.press/v70/finn17a.html)：内层训练样本与外层评估样本如何分开？测试时遇到的任务是否真的未见？
- [已有 GPT-3 精读笔记](https://github.com/hk865/my-knowledge-data-base/blob/main/docs/deep-readings/gpt3.md)：可从无梯度更新的 few-shot 实验继续理解 ICL。
- [ICL 理论原论文 待专项精读](https://arxiv.org/abs/2111.02080)：结论依赖什么数据生成假设？哪里不能外推到任意模型、任意新任务？
