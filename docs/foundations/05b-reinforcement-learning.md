## 核心问题与概念接口

### 游戏是好入口 但不是唯一历史起点

用下棋或贪吃蛇理解 RL 很直观，但历史不能画成“先游戏，后控制与机器人，最后语言”的单一路线。Bellman 在 1957 年已研究马尔可夫决策与动态规划；Barto、Sutton、Anderson 的 1983 年论文直接研究倒立摆控制，并讨论强化反馈与动物学习的联系。控制、动态规划、试错学习都是理解这段历史的重要线索。[Bellman 原文首页](https://iumj.s3-us-west-2.amazonaws.com/abstracts/56038_abs.pdf)；[1983 年控制论文](https://ieeexplore.ieee.org/document/6313077/)

把 RL 放在进阶篇是合理的，但原因不只是要搭环境、写复杂损失。它新增了一个闭环：**策略决定行动，行动改变后续经验，经验又用于更新策略**。环境可以是真实系统、模拟器或交互接口；离线 RL 也可以使用既有交互记录。RL 本身也不要求神经网络，表格方法就能学习策略。

### 从 MDP 到策略梯度只需先抓住四个量

学习目标通常是提高预期累计回报。用马尔可夫决策过程（MDP）描述问题时，需要状态、动作、转移规律和奖励。策略 π(a|s) 表示在状态 s 选择动作 a 的规则。马尔可夫假设要求状态包含预测下一步所需的信息；若观测不够，可能需要历史或记忆。

1. **回报 return**：从某一步起累计的后续奖励，可用折扣因子降低较远奖励的权重。奖励是一次反馈，回报描述一段未来。
2. **状态价值 V**：从这个状态出发，继续按当前策略行动，预期得到多少回报。
3. **动作价值 Q**：在这里先做某个动作，再按当前策略行动，预期得到多少回报。
4. **优势 advantage**：A(s,a)=Q(s,a)−V(s)，表示这个动作比当前策略在此处的平均表现好多少。

这些量把“一段行动好不好”拆成可估计的预测问题。[Sutton 与 Barto 教材草稿第 3 章](https://web.stanford.edu/class/psych209/Readings/SuttonBartoIPRLBook2ndEd.pdf)

因此，“给轨迹打分，再让分数影响训练”的直觉抓住了一部分核心。策略梯度把它变成可计算的更新：提高优势为正的已采样动作的概率，降低优势为负的动作的概率。一个示意性代理损失是 −平均[优势估计 × log π(已选动作|状态)]；在策略更新中把优势估计作为固定权重。奖励或环境无需能够直接反向传播，但采样分布、折扣和权重必须与所求目标匹配。[策略梯度原论文](https://papers.neurips.cc/paper_files/paper/1999/hash/464d828b85b0bed98e80ade0a5c43b0f-Abstract.html)

### 打分之外还有三道关

**信用分配**问“结果究竟该归功于哪一步”：整条轨迹成功，不代表每个动作都好。**探索**问“没尝试过的好策略怎样被发现”：只奖励当前已经会的行为，可能困在局部选择。**分布变化**问“更新后还在什么数据上学习”：策略改变了，遇到的状态和动作也会改变，旧样本不能总按当前策略样本直接使用。

在语言模型里，可把已有上下文看作状态，下一个 token 看作动作，整段回答获得反馈。轨迹评分能作为训练信号，但“评分提高”还要和任务成功、真实性等独立指标核对；奖励设计有漏洞时，模型可能学会利用漏洞。

“不要破坏已有知识”同样重要，只是它属于**能力保持与持续学习**问题，不能当成 RL 的唯一核心难点。KL 惩罚可约束模型在某种输入分布上偏离参考策略的程度；回放或混入旧数据可补充旧任务信号。二者都不是“所有旧能力绝不下降”的保证：约束或样本没有覆盖的区域仍可能变化。因此必须保留旧任务测试集，并同时评估新收益与旧能力变化。持续学习中的参数保护方法也正是为缓解这类干扰而提出。[EWC 原论文](https://arxiv.org/abs/1612.00796)

### PPO 与 DPO 各解决哪一段

**PPO**属于策略优化方法：使用采样经验与优势估计，通过概率比率的裁剪代理目标等方式抑制过大的更新。裁剪不是严格保证整个策略始终处于某个 KL 区间，更不是安全性或不遗忘证明。[PPO 原论文](https://arxiv.org/abs/1707.06347)

**DPO**从偏好对直接优化策略。在特定偏好模型与 KL 正则化目标的推导下，它不必先单独训练奖励模型，再运行 PPO 式 RL 循环。原始离线 DPO 训练也不要求每步在线探索。因此“做偏好优化”不能直接等同于“跑 PPO”，DPO 也不能替代一般环境中的探索和长程信用分配。[DPO 原论文](https://arxiv.org/abs/2305.18290)
