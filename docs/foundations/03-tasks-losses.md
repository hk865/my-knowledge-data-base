## 先读两分钟

先定义要输出什么，再解释怎样罚错。架构、任务、监督来源和训练目标是不同维度；同一种架构能采用不同loss，同一种loss也会出现在不同任务。

## 贯穿所有模块的样本约定

每样本记为 `(x,y,m,meta)`：x是推理可得输入，y是学习目标，m是有效监督位置，meta记录时间、坐标、单位和来源。标签来自人类、传感器参考或数据自身，不改变“必须说清楚目标”的要求。

## 先签好输入输出的约定

假设一个样本写成 `(x, y, m, meta)`：`x` 是推理时可以获得的输入，`y` 是训练目标，`m` 指出哪些目标位置有效，`meta` 记录时间戳、坐标系、单位和来源。`y` 不一定由人标注；遮挡重建可把原始数据的一部分作为目标。`meta` 也不应不加选择地送入网络，真值姿态或测试集身份可能造成泄漏。

模型写成 `ŷ = fθ(x)`。`θ` 是可训练参数，`ŷ` 是预测。它可能是一个数、每类的分数、一幅深度图、一组框、一段动作，也可能是概率分布的参数，而非唯一答案。

| 要区分的问题 | 在问什么 | 一个例子 |
|---|---|---|
| 任务 | 最终需要完成什么 | 从IMU估计短窗位移 |
| 架构 | 信息怎样组合、参数怎样共享 | 1D CNN、RNN或Transformer |
| 监督方式 | 用什么来源提供学习信号 | 外部定位真值、重建目标、交互奖励 |
| 训练目标 | 怎样给预测打分 | 位移MSE、概率NLL、动力学一致性 |

这些是不同维度，不表示它们毫无约束地独立。自回归模型要限制可见未来信息，分割输出要对应空间位置。它们也没有一对一关系：CNN和Transformer都能做交叉熵分类；Transformer骨干配合不同输出头和掩码，可以学习分类、重建或对比表征。

实际操作顺序是：先定义输出的含义与合法范围，再问适合什么误差模型，最后确定网络如何产生这个输出。不要先复制一个loss，再倒推自己的任务。

## 视觉任务由输出的结构分开

| 任务 | 输出和目标的含义 | 常见训练目标与评价 |
|---|---|---|
| 图像分类 | 每张图一个互斥类别 | CE；准确率、分类型召回 |
| 目标检测 | 可变数量的类别与框 | 分类项加框回归项；AP与召回 |
| 语义分割 | 每个有效像素一个类别 | 像素CE，可配重叠类损失；mIoU |
| 深度估计 | 每像素正的距离或逆深度 | 有效区回归或重建项；米制误差、相对误差 |
| 光流估计 | 每像素二维图像位移 | 向量回归；端点误差EPE |

CIFAR-10教学接口为 `x[B,3,32,32] → logits[B,10]`，标签 `y[B]`。分割常把logits排成 `[B,C,H,W]`，目标为 `[B,H,W]`；不能把类别维与像素维平均错位。

检测还有“哪个预测对应哪个真值”的问题。框的数组顺序往往不是物体身份；DETR用集合匹配再计算监督，是一种具体解决方法，并非所有检测器都如此。[DETR原论文](https://arxiv.org/abs/2005.12872)

深度中的无效读数、光流的遮挡区都要有明确评价协议。像素重建损失还依赖光照、遮挡等假设，不天然等于几何误差。任务定义、有效区域和相机尺度一变，同名loss也可能在罚不同的东西。

## 最后用什么证明模型真的更好

训练loss是优化信号，metric是评价定义，两者可能相同，也可能不同。准确率只看选中的类别；CE还看概率。检测AP依赖排序与匹配；机器人成功率、碰撞率依赖完整闭环。为优化方便采用的代理目标，需要用真实任务指标检验。

就算目标不变，也要统一计量方式。例如有长度2和长度100的两条序列：按词元平均让长序列贡献更多，先按序列平均再平均则让两条等权。对有效掩码常用 `Σ(m·ℓ)/Σm`，但必须说明元素指样本、词元、像素还是坐标；没有有效标签的批次应显式跳过或处理。

多任务总损失 `Σk αkℓk` 中，各项量纲、数量和梯度规模都可能不同。把“米”换成“厘米”，未归一化平方误差就扩大一万倍；这不是任务突然重要了一万倍。协方差或不确定性加权是一类方法，仍需检查其假设与真实评价目标。[多任务不确定性加权原论文](https://arxiv.org/abs/1705.07115)

开始实验前回答六个问题：

1. 输出是类别、连续量、集合、分布还是流形元素？合法范围是什么？
2. 标签和输入的时间、单位、坐标及可见信息是否一致？有没有偷看真值？
3. loss基于何种误差或概率假设？异常点是真错标，还是必须学会的难例？
4. 求和与平均的分母是什么？不同任务的权重依据是什么？
5. 测试是否按独立人、设备或整段序列划分？是否覆盖部署时的新情况？
6. 除局部平均误差，是否检查长时漂移、尾部失败、校准或闭环结果？


掌握这条线后，阅读论文时可以先找“输入、目标、有效位置、输出空间、损失、评价”六项。架构图告诉你网络怎样算；这六项告诉你它究竟在学什么，以及证据能支持到哪里。
