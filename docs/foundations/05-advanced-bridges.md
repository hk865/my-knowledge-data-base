# 05 从基础进入进阶

[返回学习导航](./00-learning-navigation.md)

## 先读两分钟

进阶继续沿用四条基础轴：模型架构、优化与训练方法、任务与损失、数据。本次以基础篇为主；以下三个入口提供概念定位、浓缩图、分步图和后续精读问题，不作为一套完整进阶课程。

## 三个导读入口

1. [分布式训练](./05a-distributed-training.md)：同一个目标怎样分布到多张卡；数据/张量/流水线并行、梯度累积与混合精度如何互相配合。包含一张浓缩图和两张分步图。
2. [强化学习](./05b-reinforcement-learning.md)：从 MDP、回报、价值、优势走到策略更新；补上信用分配、探索、分布变化与能力保持，区分 PPO 和 DPO。包含一张浓缩图和一张分步图。
3. [迁移与元学习](./05c-transfer-meta-learning.md)：区分迁移、微调、PEFT 与 LoRA；定位 MAML、学习优化器、ICL 和预训练的关系。包含一张浓缩图和一张分步图。

数据清洗、训练/测试划分、采样与管线先回到[数据基础](./04-data-and-datasets.md)，无需在进阶部分重复建立另一套概念。

## 阅读顺序

先完成小模型的训练与评估闭环，再用分布式模块检查更新是否等价；随后比较冻结表征、全量微调与 LoRA。RL 从小型表格 MDP 入手即可，元学习从明确区分训练任务与测试任务的小实验入手。

每次进入新方法都问：架构哪里变了？更新规则哪里变了？任务与损失哪里变了？经验从哪里来？
