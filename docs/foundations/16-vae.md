# VAE 从潜变量模型到可训练后验推断

## 先读两分钟

VAE先定义隐藏原因如何生成观测，再训练近似后验推断。ELBO不是随意拼出的重建加正则，而是数据似然的下界；编码器用于推断，生成新样本时从先验采样再解码。

![VAE 从潜变量模型到可训练后验推断总览](../../assets/foundations/vae-summary.svg)


## 1 问题不是单纯压缩图片

一张图像可能由姿态、物体形状、光照等未观测因素共同产生。潜变量模型写成 p_θ(x,z)=p(z)p_θ(x| z)：先采样隐藏因素，再产生观测。传统概率图模型、因子分析、概率PCA与变分推断提供了重要背景；VAE把非线性生成模型和快速近似后验推断结合起来。

困难是 pθ(x) = ∫ p(z)pθ(x|z) dz 和 p_θ(z| x)往往算不出来。Kingma与Welling在2013年预印本、2014年会议工作中提出AEVB；同期Rezende等研究随机反向传播与近似推断。它不是“先有普通自编码器，再随意加一项KL”的任意配方。[AEVB](https://arxiv.org/abs/1312.6114)；[Rezende等](https://proceedings.mlr.press/v32/rezende14.pdf)

## 2 ELBO到底在优化什么

设 x∈ℝ^D，z∈ℝ^k。引入编码器 q_φ(z| x)近似难算的后验。由KL非负性：

log pθ(x) = ELBO(x) + KL(qφ(z|x) || pθ(z|x))

ELBO(x) = E_q[log pθ(x|z)] − KL(qφ(z|x) || p(z))

因此最大化ELBO是在提高数据对数似然的下界。第一项让采样的潜变量能解释观测；第二项约束编码分布与先验的关系。剩余KL揭示近似推断差距，不是训练时直接可算的第三项损失。

常设 qφ(z|x) = N(μφ(x), diag(σφ²(x)))，编码器输出两组 k 维量。重参数化写成：

ε ~ N(0,I_k)；z = μφ(x) + σφ(x)⊙ε

随机性放在与参数无关的 ε 中，路径对 μ,σ可微，重建项就能反向传播。解码器输出观测分布的参数，不必直接输出一幅确定图像；固定方差Gaussian解码器的负对数似然对应缩放后的平方误差。

**最小例子。** 把 28×28灰度图展平为784维，编码成二维Gaussian的均值和尺度；采样二维 z，解码出784个像素分布参数。训练既要求重建，又约束潜空间。生成新图时，从先验采样 z再解码，不需要提供原图；给定图推断隐藏表示时才用编码器。潜变量维度可比观测低，但“每一维自动对应姿态或光照”没有保证。

## 3 与SLAM的联系和边界

SLAM也从观测推断隐藏状态和地图，所以“生成模型与后验”是共同语言。但经典几何SLAM的潜变量常有明确物理意义，VAE的潜空间一般不可直接辨认。把环境压入一个潜码，再学习转移 p(z_(t+1)| z_t,a_t)，才开始走向潜空间世界模型；单帧VAE本身不包含运动规律。

**何时选。** 需要概率化表示、快速编码解码、可采样的连续潜空间时，VAE很有价值，也常作为后续生成模型的压缩器。局限包括后验近似偏差、潜变量被强解码器忽略的posterior collapse，以及重建与先验约束的权衡。简单像素似然下的模糊现象不是“一切VAE必然模糊”；更复杂的解码器与似然会改变结果。把KL权重改为任意 β可改变表示权衡，但此时不宜再把整个目标未经说明地叫作原始对数似然的标准ELBO。

## 相关论文精读

### AEVB 2013至2014 从概率模型读起

[原文](https://arxiv.org/abs/1312.6114)先看图1中的生成模型与近似后验，再读第2.2节的ELBO分解、第2.4节重参数化和第3节VAE例子。重点区分模型参数θ、推断参数φ、每个样本的随机潜变量z；它们不是同一层面的“待优化变量”。

### Rezende等2014 看同期随机反向传播路线

[原文](https://proceedings.mlr.press/v32/rezende14.pdf)将近似推断与神经生成模型结合。它帮助理解为什么重点是让随机变量路径上的学习变得可行，而不是只把网络画成沙漏形。比较两篇的模型、估计器与实验，避免把同期工作写成单一独占的发明故事。

## 自测与最小实验

给标准正态先验和一维后验q=N(μ,σ²)，KL=0.5×(μ²+σ²−1−logσ²)。μ=0、σ=1时KL为0，为什么不能仅最小化这一项？因为所有输入都得到同样潜分布，可能完全不含重建所需信息。实验中把KL权重逐步调大，分别记录重建、潜变量使用和生成样本，不要只看总损失。
