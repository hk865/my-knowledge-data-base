# LSTM 怎样选择记住 写入和读出

## 先读两分钟

LSTM增加可加性记忆通路，用门分别控制旧记忆、新内容与输出。1997原始LSTM与后来包含forget gate的常见版本要分开；门控改善学习长依赖，不保证无限记忆。

![LSTM 怎样选择记住 写入和读出总览](../../assets/foundations/lstm-summary.svg)


## 1 它解决的是记忆更新和梯度通路

普通RNN每步都对整个状态做非线性变换。若某个线索需要保留很久，反复变换可能破坏它。LSTM增加一条可加性更新的记忆状态 c_t，再让门决定旧内容保留多少、新内容写入多少、哪些内容用于当前输出。

历史上，Hochreiter与Schmidhuber的1997年论文以保持误差传播的记忆单元和门控机制处理长依赖；今天常画的“三门标准LSTM”包含后来加入的遗忘门。Gers等《Learning to Forget》的2000年期刊论文专门提出自适应重置的forget gate，因此不能把现代全部公式原样归给1997年。[LSTM 1997](https://direct.mit.edu/neco/article/9/8/1735/6109/Long-Short-Term-Memory)；[遗忘门论文](https://pubmed.ncbi.nlm.nih.gov/11032042/)

## 2 现代常用无peephole形式

把 u_t=[x_t;h_(t-1)]∈ℝ^(m+d) 拼接。四组矩阵均为 d×(m+d)，门、候选、记忆和隐藏状态均为 d 维：

f_t = sigmoid(W_f u_t+b_f)；i_t = sigmoid(W_i u_t+b_i)；o_t = sigmoid(W_o u_t+b_o)
g_t = tanh(W_g u_t+b_g)；c_t = f_t⊙c_(t−1) + i_t⊙g_t；h_t = o_t⊙tanh(c_t)

f是保留旧记忆的比例，i控制写入，o控制读出，g是候选内容。门由输入和历史共同计算，不是人工写的if语句。名字叫forget gate，但数值越大其实保留越多。

**最小例子。** 设某维 c_(t-1)=0.7。若本帧没有新线索，f_t=0.99,i_t=0，得到 c_t=0.693；若发生场景切换，f_t=0.1,i_t=0.9,g_t=-0.6，得到 c_t=-0.47。同一单元既可以缓慢保持，也可以迅速改写。

沿直接记忆连接、暂时不计门值对旧状态的间接依赖，有 ∂ c_t/∂ c_(t-1)=diag(f_t)。当 f_t≈1，出现比较畅通的梯度路径；完整网络的总导数还包含其他路径。因此正确结论是“改善长依赖的可学习性”，不是“LSTM绝不会梯度消失或永远记住信息”。

## 3 与滤波的关系及适用边界

“保留预测，再吸收新信息”的形式让人联想到滤波更新，这是有用类比；但LSTM门通常不由观测噪声与状态协方差推出，i_t也不等于Kalman增益。若想要可解释融合，应明确保留物理模型与概率假设，再决定哪些项由网络学习。

输入输出可与普通RNN相同，训练仍使用BPTT，推理必须携带 h_t,c_t。后续GRU等门控递推进一步调整了状态与门的配置；不同门数是在容量、训练性和成本之间选择，并非门越多越好。[GRU相关原始工作](https://arxiv.org/abs/1406.1078)

**何时选。** 需要在线处理、记忆时间尺度不固定、数据或算力不足以支撑大注意力模型时，LSTM/GRU值得比较。代价是参数和计算多于简单RNN，仍有顺序依赖及固定状态容量。机器人日志训练还要特别注意状态清零、跨episode边界与部署初始状态一致，否则离线指标可能虚高。

## 相关论文精读

### LSTM 1997 先找它要保护的梯度路径

[原文](https://direct.mit.edu/neco/article/9/8/1735/6109/Long-Short-Term-Memory)关注constant error flow、记忆单元、输入和输出门。读图时用不同颜色标“状态前向流”和“误差后向流”。不要拿今天的三门公式逐项认领为1997全部设计。

### Learning to Forget 读新增遗忘门的具体问题

[2000期刊原文](https://pubmed.ncbi.nlm.nih.gov/11032042/)讨论持续输入流没有预先划定重置点时的困难，再引入自适应forget gate。它不是仅仅“多一个参数让效果更好”，而是让模型能自己选择何时释放旧状态。

## 自测与最小实验

将候选写入设为0，比较f=0.9与f=0.99连续100步后的直接保留系数：约0.0000266与0.366。门已接近1仍可能在足够长时间后衰减。再比较相同隐藏维度与相同参数预算下的RNN、GRU、LSTM：两个比较问的是不同问题，不能只凭隐藏维度相同就说规模公平。
