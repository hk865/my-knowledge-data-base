# 深度学习基础模块讲义

从[学习导航](00-learning-navigation.md)开始，或直接进入一个概念模块。

## 本包内容

- 24 个独立模块：架构 8、优化 4、任务与损失 5、数据 4、进阶导读 3
- 其中 20 个基础概念模块、1 个架构扩展导读、3 个进阶导读；导读不等同于完整专题精读
- 6 份总导航与分区目录，另有 15 个代表数据集的选型说明及 CSV、JSON 目录
- 71 组原创图解，公开仓库保留可编辑 SVG，完整下载包另含 PNG；图中的示例为教学示意或手算，不是训练实验结果
- 各模块包含动机、机制、例子、边界、自检以及原始论文重点章节研读或深入阅读入口

## 怎么读

每次只选一个模块。先读“先读两分钟”，看总图，再沿步骤图读正文。原始论文重点段落研读与已有完整精读入口分别标明；没有把所有引用文献都宣称为全文精读。

## 使用边界

本包没有下载原始论文PDF、完整数据集，也没有重跑模型训练。数据规模、格式、访问条件和未确认许可证事项以各条来源及核验日期为准。数据与代码的使用权限仍应以原始提供方条款为准。

Markdown与SVG相互使用相对路径，解压后保留文件夹结构即可离线阅读。公式以纯文本和Unicode为主，避免依赖特定数学渲染器。部分SVG使用字体文本，系统缺少字体时可以查看完整下载包中的对应PNG。
