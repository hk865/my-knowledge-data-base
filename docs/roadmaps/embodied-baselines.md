# 具身与世界模型基线路线图

这三篇回答不同问题，不是一条新模型替代旧模型的排行榜。它们分别是2023年潜在世界模型RL、2023年视觉动作扩散模仿、2024年开放VLA的重要基线，本组不声称覆盖截至2026年的全部最新方法。

## 三条路线的接口

- [DreamerV3](../deep-readings/dreamerv3.md)：真实观测与奖励→潜在状态/动力学→想象rollout→actor/critic。世界模型是用于学策略的可预测环境表征；部署actor不做在线MPC。可研究的问题是：模型误差、任务相关表征、探索与价值学习
- [Diffusion Policy](../deep-readings/diffusion-policy.md)：观测历史与示范动作→条件去噪器→动作序列→执行一段再观测。重点是多峰动作与时间一致性；没有显式语言理解、奖励改进或未来世界预测。可研究的问题是：动作参数化、动作块长度、示范覆盖与延迟
- [OpenVLA](../deep-readings/openvla.md)：图像/语言预训练→跨机器人动作token微调→目标任务适配→单步控制。重点是语义先验与跨任务/平台数据；原版没有历史/本体感知输入和动作块。可研究的问题是：语言定位、输入接口、动作解码、数据混合与适配成本

三者共同接到机器人低层控制栈，但学习信号不同：Dreamer从环境奖励改善行为；后两者从示范监督动作。动作模型、世界模型、视觉语言表征是可组合的设计维度，不应由一个热门名称替代系统分解。

## 适合仿真与传统控制背景的阅读顺序

第一站读Diffusion Policy。先拿熟悉的状态空间系统理解单步策略，再看动作序列为什么隐含闭环动力学；画清楚T_o、T_p、T_a与扩散k。把“滚动执行”与“求解模型约束下最优控制”区分开，再读真实机器人QP和插值控制栈。这样可以把新学习模块放到已有控制框架里，而不丢掉单位、坐标系与安全边界。

第二站读DreamerV3。用状态估计的预测/校正类比RSSM先验与后验，再看世界模型如何连接reward/continue和critic。把真实环境循环、回放训练循环、想象循环分别画出来。最后检查各任务独立训练、环境预算与训练比例，理解“算法通用”与“单个通用权重模型”的区别。

第三站读OpenVLA。此时注意力应放在语言和预训练增添了什么，而不是重新把网络当物理控制器。重点比较完整Diffusion Policy与matched版本，核对语言改变而画面不变时目标是否跟着改变，并把token精度与闭环成功分开测量。

## 最小验证路线

1. 接口检查：固定相机、坐标系、位置/速度定义、旋转表示、时间戳与归一化，先跑动作编码/反编码的往返检查。输出一份可复用的数据契约
2. 策略比较：在同一安全仿真任务、同一示范划分与评估初态上，比较单步回归与动作扩散；报告成功率、扰动恢复、轨迹平滑度与端到端延迟。不要把更大输入、更长历史或更好低层控制器的收益全算作网络创新
3. 模型学习：给同一环境加入可核对奖励，先检查一步与多步预测，再检查actor是否利用模型漏洞获得虚假的想象高回报。样本效率、算力与最终任务表现分开报告
4. 语言适配：若任务确实需要指令选择目标，再评估VLA预训练与目标任务微调。设计成对指令测试，并记录陌生物体、背景与目标关系，不只测熟悉摆放位置
5. 实机迁移：在已有位置伺服、限速、工作区、碰撞检查和急停保护内验证；先测延迟导致的闭环偏移，再谈模型泛化。以上是建议实验顺序，本次没有执行
