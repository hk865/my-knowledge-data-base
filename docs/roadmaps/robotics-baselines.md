# 传统机器人基线之间的路线关系

本组解决四个不同问题：姿态与惯性误差如何表示、历史观测如何形成可复用地图、给定地图中怎样寻找低成本路径、给定参考与接触安排后怎样施力。下面的箭头表示建议阅读顺序和工程接口，不表示历史首创关系，也不意味着四篇已经组成一个经验证的完整机器人产品。

## 推荐顺序

1. [Solà ESKF](../deep-readings/eskf.md)：先建立坐标、旋转扰动、IMU传播、协方差及观测更新基础。验收重点是能区分名义状态与误差，解释为什么注入后还要重置协方差
2. [ORB-SLAM3](../deep-readings/orb-slam3.md)：再看视觉观测与IMU如何联合约束多个时刻的状态，理解关键帧、共视、回环、地图恢复与融合。它是优化式SLAM，阅读ESKF只是数学准备，不是算法组件依赖
3. [RRT*](../deep-readings/rrt-star.md)：在地图和碰撞查询已给定时，学习采样、父节点选择及重连。它可与第二步并行阅读，只要求概率、图与几何基础；原始半径证明的后续审计必须一起保留
4. [Convex MPC](../deep-readings/convex-mpc.md)：理解状态估计之后如何在短时域分配接触力、处理欠驱动与约束，再由腿部控制执行。它与RRT*不是上下级的必然搭配，四足接触力规划和几何路径规划解决不同变量

## 按接口串起来

传感器到估计：IMU、图像及标定进入估计器，输出位姿、速度、偏置或地图。不确定性、时间戳、坐标方向和失效标志是接口的一部分。只传一个“看起来平滑”的位姿会隐藏初始化失败或漂移。

地图到规划：稀疏SLAM地图不自动等于可安全通行的自由空间。必须补上机器人几何体、障碍表示、未知区域规则、定位误差余量及可靠碰撞查询，才能把地图交给几何规划器。

路径到控制：几何路径还缺时间、速度、接触安排和可执行性。MPC用最新状态滚动解有限时域问题；它优化的接触力不能与RRT*的构型样本、Diffusion Policy的动作序列或VLA的动作token视为同一种对象。

执行再到估计：动作改变世界，接触与传感数据回到估计器。规划可行不等于真实安全，尤其当执行延迟、接触滑动、地图过期或定位不确定性超出假设时。

## 与学习式路线交叉阅读

- 接[DreamerV3](../deep-readings/dreamerv3.md)：比较显式物理状态和潜在状态、手写动力学和学习世界模型。区别在模型及优化目标，不能把一切滚动预测都叫同一种MPC
- 接[Diffusion Policy](../deep-readings/diffusion-policy.md)：比较生成动作序列与在线优化接触力。二者都可滚动执行，但训练来源、变量及约束保证不同
- 接[OpenVLA](../deep-readings/openvla.md)：区分语义任务条件与几何状态估计；语义能力不能替代碰撞检测或状态可信度
- 接[RMA](../deep-readings/rma.md)：比较显式质量／摩擦假设与历史观测适应。相同硬件、感知、延迟与高层指令下才有公平比较

以上是机制层面的交叉联系，不是这四篇已验证这些组合的实验结论。

## 第一轮仍然缺什么

本组覆盖旋转与惯性滤波、特征式视觉惯性SLAM、采样式几何规划、固定接触安排下的四足MPC。仍缺LiDAR定位、动态物体与语义地图、风险／信念空间规划、动态避障、完整非完整／动力学规划、接触时序优化、WBC与人形多接触、PID/LQR全谱系。不能用四篇的存在把这些子方向标为已充分覆盖。

## 统一复现验收

- 估计：误差、失败率、初始化条件、真值覆盖、对齐自由度、协方差一致性
- 规划：首解时间、固定墙钟预算下的成本、随机种子分布、碰撞调用与内存
- 控制：真实／预测约束违反、状态估计与延迟、扰动范围、执行器饱和、成功与失败尝试
- 理论：把算法描述、原文定理、证明条件、后续审计和本人的推论分开；渐近性质不等于有限时刻安全证书
