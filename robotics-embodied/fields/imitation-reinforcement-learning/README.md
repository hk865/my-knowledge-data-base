# 模仿学习与机器人强化学习

> 状态：领域入门页 · v3 · 依据 [synthesis.csv](synthesis.csv)（13 篇）
>
> 速览：
> 1. 机器人策略有两种训练信号：模仿用示范（"人在这个状态下这样做"），强化用奖励（"这样做的结果有多好"）。`[判断]` 操作任务以模仿为主，因为示范容易给、奖励难写；腿足以仿真强化学习为主，因为奖励容易写、关节力矩的示范给不出。但腿足同样绕不开模仿：从零开始的 RL 探索不到好状态、奖励写不出自然，于是动作捕捉的运动学轨迹被用作跟踪目标或风格奖励，仿真里的特权教师被学生模仿。同一个人形学生，模仿教师成功率 94.1%，直接做 RL 只有 47.1%（OmniH2O）。
> 2. 模仿的坑是复合误差与分布外。DAgger 证明行为克隆的代价上界随任务长度的平方增长；ACT 不分块时成功率 1%，分块后 44%；RT-1 只能组合已见过的概念，做不出全新动作。
> 3. 强化的坑是奖励设计与样本效率。HIL-SERL 不给示范、从零做 RL，三项真机任务全部 0%；SimpleVLA-RL 在基座成功率为 0 的任务上无法起步；Extreme Parkour 换成普通速度奖励后，策略学成"撞上去再重试"。
> 4. 2024–2026 年，RL 回到了模仿之上。同样多的人类数据，HIL-SERL 平均成功率 100%，人工纠正版 DAgger 为 49.7%；π*0.6 把最难任务的吞吐量提高一倍以上；SimpleVLA-RL 在 LIBERO-Long 单示范设定下从 17.3% 提到 91.7%。`[判断]` RL 补的是模仿的两个短板：示范之外的状态，以及超过示范者的速度。
> 5. 评测目标在迁移：仿真 benchmark（RoboMimic、LIBERO）接近饱和，SimpleVLA-RL 在 LIBERO 上平均 99.1%；2025 年以后的工作改报真机吞吐量（每小时成功次数）和连续运行时长。

本页是[机器人与具身](../../README.md)领域的模仿与强化学习方向。机制与算例在讲义[模仿学习与机器人强化学习入门](../imitation-reinforcement-learning.md)（行为克隆的数据怎么来、为什么误差越走越大、多峰动作的平均为什么错、扩散策略怎样训练与部署、回报与优势、PPO 限制了什么、六类工作怎样分开诊断）；回报、价值、优势与 PPO 的基础在 [05b 强化学习](../../../foundations/lessons/05b-reinforcement-learning.md)。本页只讲领域地图。腿足的强化学习主线在[运动控制方向](../control-locomotion/README.md)，VLA（视觉语言动作模型，一句话：以图像和语言指令为输入、直接输出机器人动作的大模型）的模型结构在 [VLA 方向](../vla/README.md)。

## 这个领域在解决什么

结论：用一个具体任务看，问题是"训练信号从哪来、错了怎么改"。

让双臂机器人把 T 恤叠好放进筐里：
- 一种做法是请人遥操作（teleoperation，一句话：人用主手或手柄实时操纵机器人）叠几百次，让网络学"看到这个画面就这样动"，这是模仿学习；
- 另一种做法是让机器人自己试，叠好了给正分，用强化学习提高好动作的概率。

前者的问题是机器人一旦叠歪，就进入人从没示范过的状态；后者的问题是"叠好了"很难自动判断，真机上试几千次也太慢。四足行走正好相反：奖励（速度跟踪、不摔倒）几行代码就能写，仿真里可以并行试几千台，但人给不出"每个关节此刻该用多大力"的示范。不过，狗和人的动作捕捉能给出"身体该经过哪些姿态"的运动学示范，仿真里能看到地形真值的教师策略也能随时给出动作标签，所以腿足同样离不开模仿，只是模仿的对象不同。

### 模仿与强化的分工

结论：信号从哪来，决定了一个任务用哪种方法；两种方法组合时，通常是一方给另一方提供专家或起点。

| 做法 | 训练信号 | 适合的任务 | 代表 | 主要的坑 |
|---|---|---|---|---|
| 行为克隆（BC） | 遥操作示范 | 操作：示范容易给，成功难自动判断 | [RT-1](../../papers/arxiv-2212.06817/README.md)、[ACT](../../papers/arxiv-2304.13705/README.md)、[Diffusion Policy](../../papers/diffusion-policy/reading.md) | 复合误差；最多和示范者一样好 |
| 动作模仿（只有状态的示范） | 动作捕捉、动画或人体视频重定向得到的运动学轨迹，作为跟踪奖励或判别器给的风格奖励，再用 RL 优化 | 腿足与人形：给不出关节力矩，能给姿态序列 | [DeepMimic](../../papers/arxiv-1804.02717/README.md)、[AMP](../../papers/arxiv-2104.02180/README.md)、[Escontrela 2022](../../papers/arxiv-2203.15103/README.md)、[ExBody](../../papers/arxiv-2402.16796/README.md)、[H2O](../../papers/arxiv-2403.04436/README.md) | 动作要机器人做得到（H2O 筛掉约 15%）；数据之外的行为做不好 |
| 交互式模仿（DAgger 一类） | 在策略自己到达的状态上向专家要标签 | 有可随时查询的专家：人、规划器、仿真里的特权教师 | [DAgger](../../papers/arxiv-1011.0686/README.md)；腿足与人形的教师-学生：[Lee 2020](../../papers/arxiv-2010.11251/README.md)、[OmniH2O](../../papers/arxiv-2406.08858/README.md) | 专家要一直在线；人工纠正质量不稳定；蒸馏丢信息 |
| 仿真强化学习 | 可编程的奖励 | 腿足的教师训练：奖励能写，仿真可并行 | [PPO](../../../llm/papers/ppo/reading.md)、[Rudin 2021](../../papers/arxiv-2109.11978/README.md) | 奖励设计；sim-to-real 差距；从零探索难（ExBody 去掉从动作数据抽起始状态这一步，平均回合长度 16.87 → 0.23） |
| 真机强化学习 | 奖励分类器或人工标签，加示范与纠正 | 精度、速度要超过示范者的单个任务 | [HIL-SERL](../../papers/arxiv-2410.21845/README.md) | 奖励来源；人工重置；长时域未知 |
| 模仿预训练 + RL 微调 | 先示范，后奖励 | 已有能力不错、要进一步提高的策略 | 操作：[DPPO](../../papers/arxiv-2409.00588/README.md)、[SimpleVLA-RL](../../papers/arxiv-2509.09674/README.md)、[π*0.6](../../papers/arxiv-2511.14759/README.md)；腿足：[Peng 2020](../../papers/arxiv-2004.00784/README.md)（模仿真狗后在真机上用 RL 适应）、[AME-2](../../papers/arxiv-2601.08485/README.md)（学生同时用 PPO 与动作蒸馏） | 基座能力为 0 时 RL 起不了步 |

`[判断]` 腿足和操作的组合方向相反：
- 腿足先用参考动作或课程给 RL 一个起点，在仿真里练出一个能看特权信息的教师，再用模仿（DAgger）把它蒸馏成只用真机传感器的学生；
- 操作先用模仿学出一个能用的策略，再用 RL 把它磨快、磨稳。

两种组合都把 RL 放在信号容易得到的那一侧：腿足的奖励在仿真里随手可得；操作的奖励直到有了奖励分类器、价值函数和人工标签才变得可用。两边也有一个共同点：RL 都不是从零开始的，它的起点来自模仿。

### 为什么运动控制也绕不开模仿

结论：`[判断]` 从零开始的 RL 在腿足和人形上探索不到高奖励状态，奖励也写不出"自然"和"能上真机"；没有模仿给的起点，采到的数据大多是摔倒、抖腿和钻空子。三处原文证据最直接：
- **探索**：[DeepMimic](../../papers/arxiv-1804.02717/README.md) 去掉从参考动作抽起始状态这一步，后空翻只学成一个小后跳；[ExBody](../../papers/arxiv-2402.16796/README.md) 去掉这一步，策略学会尽快"自杀"以避开负奖励；[Lee 2020](../../papers/arxiv-2010.11251/README.md) 的引言写明直接用 RL 训练崎岖地形策略没有成功。
- **奖励**：[ASE](../../papers/arxiv-2205.01906/README.md) 中从零训练的策略在 5 个任务里 4 个回报更高，作者写明靠的是不自然的动作；[BeyondMimic](../../papers/arxiv-2508.08241/README.md) 说手写的奖励每个新行为都要重新设计。
- **模仿教师胜过自己做 RL**：[OmniH2O](../../papers/arxiv-2406.08858/README.md) 中同一个带长历史输入的人形学生，按 DAgger 模仿教师 94.10%，直接做 RL 47.11%。

边界：四足在一般地形上行走可以不用动作数据（Rudin 2021），Robot Parkour 靠允许穿透的课程而不是模仿解决攀爬的探索。三种形式（参考动作、教师-学生、先模仿后强化）的对照表、做不好的场景和公司的做法，见[运动控制方向的"为什么绕不开模仿学习"](../control-locomotion/README.md#为什么绕不开模仿学习)。

## 四个坑

结论：用户关心的复合误差、奖励设计、样本效率、分布外，分别是两种方法各自的软肋；后来的方法几乎都在用一种方法补另一种的坑。

### 复合误差：示范只覆盖专家走过的状态

- **问题**：DAgger 论文（2011）给出这个坑的定量形式。在专家的状态分布上错误率为 ε 时，T 步任务里行为克隆的总代价最多比专家多 T²ε，而且这个界是紧的。原因是策略一偏离，后面看到的状态就不在训练分布里，错误会累积。改为在策略自己的状态分布上训练后，界降为 uTε，u 是"犯一次错后专家要多付出的代价"。
- **做不好的例子**：Super Tux Kart 中，行为克隆加再多数据也不改善，因为训练圈都很相似，学不会怎样回到赛道；Super Mario 中，专家总在很远处起跳，学习者没见过贴着障碍的状态，于是卡在障碍前。
- **后来的三种修法**：
  - **补数据**：DAgger 一类，在策略自己的状态上要标签。代价是专家一直在线。
  - **缩短有效时域**：[ACT](../../papers/arxiv-2304.13705/README.md) 一次输出 100 步动作，不需要在线专家。不分块时成功率 1%，分块后 44%（4 个仿真设定平均）。
  - **用 RL 在失败状态上学**：[HIL-SERL](../../papers/arxiv-2410.21845/README.md) 中，翻物体任务的行为克隆示范从 20 条加到 200 条，成功率仍是 47% 和 46%；同样数据量的 RL 达到 100%。这说明示范多了只是在专家状态上更密，并没有覆盖失败状态。

### 奖励设计：写出来的奖励和想要的行为之间有缝

- **结论**：奖励写得粗，策略找到捷径；写得细，惩罚项多到难以调和；在真机上，"成功了没有"本身就要单独训练一个模型来判断。
- **仿真里的例子**：
  - [Extreme Parkour](../../papers/arxiv-2309.14341/README.md) 把"速度与指向下一路标方向的内积"换成普通速度跟踪后，策略绕开栏杆，或在台阶上学成撞上去、弹回、再往前；
  - [CaT](../../papers/arxiv-2403.18765/README.md) 的引言说，腿足 RL 的十几项惩罚权重难调，折中也不保证约束成立。
- **真机上的例子**：
  - HIL-SERL 每个任务训练一个二分类奖励分类器，用约 200 个正样本、1000 个负样本，误报漏报时还要补数据；
  - π*0.6 的成功与失败靠人工标注，作者把这列为系统不是全自主的第一条原因。
- **只给成功/失败奖励时**：[SimpleVLA-RL](../../papers/arxiv-2509.09674/README.md) 的策略在"把罐子移到锅边"这类任务上学会了示范里没有的"推过去"，作者称之为 pushcut，当作新能力。`[判断]` 同一现象也可以读成结果奖励不约束过程：推过去在仿真里算成功，在真机上是否可接受取决于任务。

### 样本效率：强化学习在真机上贵

- **结论**：仿真里样本几乎免费（[Rudin 2021](../../papers/arxiv-2109.11978/README.md) 用 4096 台并行，20 分钟练完腿足策略），真机上每个样本都要时间、人力和硬件损耗，所以真机 RL 都要借示范起步。
- **证据**：
  - HIL-SERL 不给示范、从零做 RL，三项任务全部 0%；多数任务 1–2.5 小时练成，同步带组装用了 6 小时。
  - [DPPO](../../papers/arxiv-2409.00588/README.md) 自述主要局限是样本效率低于离策略方法。
  - π*0.6 每轮迭代在纸箱任务上采 600 次自主试验加 360 次带人工干预的试验。

### 分布外：训练没见过的状态、物体和机器人

- **模仿**：
  - [RT-1](../../papers/arxiv-2212.06817/README.md) 自述只能把已见过的概念重新组合，不能泛化到全新动作。它的背景变化测试只有 59%；只用另一种机器人（Kuka）的数据训练、在自家机器人上测，成功率 0%。
  - [Open X-Embodiment](../../papers/arxiv-2310.08864/README.md) 自述没有研究向新机器人的泛化。
- **强化**：分布外主要表现为 sim-to-real。DPPO 中，高斯策略在仿真家具装配上 88%，零样本上真机 0%；扩散策略 20 次成功 16 次。腿足上的 sim-to-real 来源见[运动控制方向](../control-locomotion/README.md)的"sim-to-real 的差距从哪里来"一节。

## 主线历史

结论：六个节点。前三个奠定两种方法和它们的组合方式，后三个是"模仿的规模化"和"RL 回到模仿之上"。

### 1 行为克隆的复合误差被写成定理：DAgger（2011）

[Ross、Gordon、Bagnell](../../papers/arxiv-1011.0686/README.md)（CMU）把模仿学习归约为在线学习：
- 每轮用当前策略采样；
- 向专家查询这些状态上的正确动作；
- 把新标签并入数据集重训。

它改变的是"示范数据应该从哪个分布来"：从专家的分布，换成学习者自己的分布。

做不好的场景：
- 每轮都要能随时查询专家；Mario 实验的专家是能读游戏内部状态的规划器，真实机器人上很难有这样的专家。
- 对混合系数敏感：早期策略太差时会产生大量"卡在原地"的数据，拖慢收敛。
- 在手写识别上只比行为克隆高约 2 个百分点。

站在现在看过去：
- `[判断]` DAgger 在机器人上的主要落地形式不是人当专家，而是仿真里的特权教师。腿足的 [Lee 2020](../../papers/arxiv-2010.11251/README.md)、[Agarwal 2022](../../papers/url-https-proceedings.mlr.press-v205-agarwal23a-agarwal23a/README.md)、[Extreme Parkour](../../papers/arxiv-2309.14341/README.md) 都用它蒸馏学生，因为仿真里的教师可以无限次查询。
- 人当专家的版本（HG-DAgger，一句话：人在旁监视，只在策略要出错时接管并纠正）在 2024 年成了 HIL-SERL 的对照组，在同样多人工数据下输给了 RL。
- π*0.6 明确指出人工纠正质量不一致，也改善不了速度这类细节，达不到理论上的最优监督。

### 2 深度 RL 有了稳定好用的同策略算法：PPO（2017）

[PPO](../../../llm/papers/ppo/reading.md)（OpenAI）把"新策略不要离旧策略太远"从约束改成裁剪目标，只用一阶优化器，同一批数据可以多用几轮。之后，它成为仿真腿足 RL 和 LLM 的 RLHF 的默认算法：RMA、Rudin 2021、Miki 2022 都用 PPO（更早的 Hwangbo 2019、Lee 2020 用的是 TRPO）。

做不好的场景：
- 裁剪只管更新稳定，不管探索：Venture 这类稀疏奖励游戏上，PPO、A2C、ACER 都是 0 分。
- MuJoCo 与 Atari 的超参差别很大。

站在现在看过去：
- `[判断]` PPO 在机器人上成功的前提是仿真能提供海量同策略样本。[Rudin 2021](../../papers/arxiv-2109.11978/README.md) 专门研究了几千台并行时 PPO 的批量与时间视野怎样设置；到了真机上，同策略算法太费样本，HIL-SERL 改用离策略 RL。
- π*0.6 把 PPO 作为策略提取的对照：只有把信任域设得很小时才稳定，但效果差。

### 3 仿真 RL 出教师，模仿出学生（2020–2023）

腿足方向把前两个节点接在了一起：先用 RL 训练能看到地形、摩擦等特权信息的教师，再用 DAgger 蒸馏出只用本体感知或深度图的学生。细节见[运动控制方向](../control-locomotion/README.md)第 3、5、6 节。

做不好的场景：
- 蒸馏会丢信息：[Robot Parkour Learning](../../papers/arxiv-2309.05665/README.md) 攀爬成功率从教师的 95% 降到学生的 86%。
- [Extreme Parkour](../../papers/arxiv-2309.14341/README.md) 蒸馏时不混合教师的朝向，归一化前进距离从 0.92 跌到 0.12。

站在现在看过去：
- [PIE](../../papers/arxiv-2408.13740/README.md)（2024）把两阶段训练会丢信息作为出发点，改成单阶段；
- [DTC](../../papers/arxiv-2309.15462/README.md) 用非对称 actor-critic（critic 看特权信息、actor 不看）代替教师-学生，鲁棒性与之相当。

- 人形上的对照更直接：[OmniH2O](../../papers/arxiv-2406.08858/README.md) 的学生只看头和手的位姿，按 DAgger 模仿教师 94.10%，同一个学生直接做 RL 47.11%；作者写明稀疏输入让 RL 优化变得困难。
- [AME-2](../../papers/arxiv-2601.08485/README.md)（2026）把两者合在一个损失里：只蒸馏不加 RL，在没见过的地形上泛化差；只用 RL 不要教师，学生难以探索。

`[判断]` 教师-学生的价值在于把"仿真里可见、真机上不可见"的信息变成训练信号。蒸馏这一步有时可以省掉（PIE 单阶段训练、DTC 非对称 actor-critic、AME-1 单网络 PPO）；但学生的输入越稀疏、历史越长，模仿教师相对直接 RL 的优势越大（OmniH2O 带长历史时差约 47 个百分点，不带历史时约 3 个）。

### 4 大规模真实示范：数据、动作块与多峰（2022–2023）

三篇工作分别回答了模仿规模化的三个问题：

- **数据**：[RT-1](../../papers/arxiv-2212.06817/README.md)（Google）用 13 台机器人、17 个月采集约 13 万条示范，训练 Transformer 策略。已见任务 97%、未见指令 76%，同数据训练的 BC-Z 为 72% 和 19%。
- **动作块**：[ACT](../../papers/arxiv-2304.13705/README.md)（Stanford 等）用低于 2 万美元的双臂硬件和每任务 50 条示范，学会装电池（96%）这类毫米级任务；四个基线在真实任务上最终成功率都是 0。
- **多峰**：[Diffusion Policy](../../papers/diffusion-policy/reading.md)（Columbia、TRI 等）用扩散模型表示动作分布，解决"同一画面下两种都对的走法被平均成错误走法"的问题，真机 Push-T（把 T 形积木推进桌上的目标轮廓）20 次成功 19 次。

做不好的场景：
- **RT-1**：背景变化测试 59%；最难的泛化级别 50%，与 BC-Z 持平；只用 Kuka 数据训练、在自家机器人上测为 0%。
- **ACT**：穿扎带 20%（黑色扎带在黑色桌面上看不清）；拆糖纸 10 次全部失败。
- **Diffusion Policy**：
  - 作者自述继承行为克隆的局限，示范不足时表现欠佳；多步去噪使推理延迟高于简单方法。
  - 状态输入的 BlockPush 上，Transformer 去噪器 0.94，CNN 去噪器只有 0.11。
  - 表格报告"最佳检查点 / 最后 10 个检查点平均"两个数，例如视觉 ToolHang 为 0.95 / 0.73。

站在现在看过去：
- 动作块被后来几乎所有 VLA 继承：Octo 的扩散动作头输出动作块，π0 的动作块长度为 50。
- `[判断]` 三篇都把成功率提得很高，但在 RL 微调的论文里，它们一起成了被超过的基线：HIL-SERL 的 Table 1(b) 中，Diffusion Policy 平均 34%、行为克隆 31%，HIL-SERL 100%。
- 原因写在 RT-1 的局限里：模仿学习可能无法超过示范者的表现。

### 5 跨机器人数据与 VLA：模仿换成大模型（2023–2025）

- [Open X-Embodiment](../../papers/arxiv-2310.08864/README.md) 汇集 22 种机器人、60 个数据集、100 万条以上轨迹。
- [Octo](../../papers/arxiv-2405.12213/README.md)（Berkeley 等）在其中 80 万条上训练开放的通用策略，约 100 条示范、单卡不到 5 小时即可适配新机器人。
- [π0](../../papers/arxiv-2410.24164/README.md)（Physical Intelligence）在约 1 万小时数据上训练，接视觉语言模型底座和 flow matching 动作专家（flow matching，一句话：学习一个把噪声连续推向数据的速度场，生成连续动作块；动作专家是与底座分开权重的一小组参数）。

训练信号仍然是模仿；变化在模型规模、数据规模和跨本体。模型结构的细节见 [VLA 方向](../vla/README.md)。

做不好的场景：
- Open X-Embodiment 中，RT-1-X 在小数据域 5 个数据集里有 4 个优于原方法，在大数据域上欠拟合。
- Octo 自述腕部相机处理差，语言条件弱于目标图像条件。
- π0 自述预训练数据该怎样配比尚不清楚。

站在现在看过去：`[判断]` 这一阶段把"模仿能覆盖多少任务"推到了很远，但没有改变模仿的上限。π*0.6 的引言正是从这里出发：要让 VLA 真正熟练，需要能纠正它实际所犯错误的自主经验数据。

### 6 RL 回到模仿之上（2024–2026）

结论：四篇工作从仿真到真机、从单任务到通用模型，都把 RL 接在一个已经能用的模仿策略后面。

| 工作 | 起点 | RL 信号 | 结果 |
|---|---|---|---|
| [DPPO](../../papers/arxiv-2409.00588/README.md)（Princeton、MIT、TRI 等，2024） | 扩散策略 | 仿真奖励，把去噪链当作 MDP 用 PPO 微调 | 像素输入 Transport：高斯策略的 PPO 一直是 0%，DPPO 超过 50%；家具装配零样本上真机 16/20 |
| [HIL-SERL](../../papers/arxiv-2410.21845/README.md)（Berkeley，2024） | 20–30 条示范 | 奖励分类器 + 人工纠正，真机离策略 RL | 同等人类数据下成功率 100% 对 49.7%，完成时间 5.4 s 对 9.6 s |
| [SimpleVLA-RL](../../papers/arxiv-2509.09674/README.md)（清华、上海 AI Lab 等，2025） | 监督微调后的 OpenVLA-OFT | 仿真 0/1 成功奖励 + GRPO（一句话：同一任务采多条轨迹，以组内平均成绩为基线算优势，不需要价值网络） | LIBERO-Long 单示范 17.3% → 91.7%；真机 4 任务 17.5% → 38.5% |
| [π*0.6](../../papers/arxiv-2511.14759/README.md)（Physical Intelligence，2025） | 离线 RL 预训练 + 监督微调的 VLA | 价值函数算优势，作为条件输入；数据含自主执行与人工纠正 | 多样衣物与咖啡任务吞吐量翻倍以上、失败率降到一半以下；连续做咖啡 13 小时 |

做不好的场景：
- **DPPO**：样本效率低于离策略方法；在需要激进探索的任务上略低于高斯策略。
- **HIL-SERL**：作者不确定能否扩展到长得多的时域，每个任务从零训练。
- **SimpleVLA-RL**：基座成功率为 0 的任务上 RL 无法起步；真机绝对成功率仍低，放空杯 10%。
- **π*0.6**：依赖人工标签、干预与重置；纸箱任务第一轮迭代吞吐量先降后升；把策略提取换成 AWR（优势加权回归，一句话：按优势的指数给示范动作加权做监督回归）或 PPO 后，两者都难以超过起点。

站在现在看过去：`[判断]` 这一阶段与 LLM 后训练同构：先用监督数据得到一个有非零成功率的策略，再用结果奖励强化。证据有两条：
- SimpleVLA-RL 直接搬用了 [DeepSeek-R1](../../../llm/papers/arxiv-2501.12948/README.md) 一类的 GRPO 配方，并把 pushcut 类比为 R1 的"顿悟时刻"；
- 它的失败条件（基座零能力时 RL 起不了步）也是结果奖励 RL 的共同前提：没有成功样本就没有正的优势。

区别在奖励来源。LLM 的数学、代码有自动验证器；机器人要么在仿真里，要么靠奖励分类器和人工标签，这是机器人 RL 扩展的瓶颈（π*0.6 自述）。

## 主要路线与团队偏好

结论：满足"两篇以上重复同一选择"条件的有 Berkeley（Levine 等）、Physical Intelligence、Google 三组；其余各只有一篇，只写押注。

| 团队 | `[判断]` 押注 | 代表工作 | 代价与做不好的地方 |
|---|---|---|---|
| Google（Robotics at Google / DeepMind） | 规模化的真实示范 + Transformer 行为克隆，再接网页知识 | RT-1、Open X-Embodiment、RT-2 | 不能超过示范者；新动作、新机器人泛化差 |
| UC Berkeley（Levine、Finn 等，常与 Stanford 合作） | 开放的通用模仿策略，同时坚持真机 RL | ACT、Octo、HIL-SERL | 真机 RL 每任务从零训练，依赖奖励分类器 |
| Physical Intelligence | VLA 底座 + 连续动作生成，再用优势条件化的 RL 从部署中改进 | π0、π*0.6（另见 VLA 方向的 π0.5、π0.7） | 数据与训练配方不公开；RL 依赖人工标签和重置 |
| Columbia / TRI（Song、Tedrake 等） | 生成式动作分布 | Diffusion Policy、DPPO（TRI 参与） | 推理延迟；示范不足时欠佳 |
| 清华、上海 AI Lab 等 | 把 LLM 的结果奖励 RL 搬到 VLA | SimpleVLA-RL | 仿真奖励；基座零能力时无效 |
| CMU（Ross、Bagnell） | 交互式模仿的理论 | DAgger | 需要在线专家 |

`[判断]` 团队偏好的依据：
- Google 在 RT-1、RT-2、Open X-Embodiment 中都选择扩大真实示范数据；
- Berkeley 系作者在 SERL 与 HIL-SERL 中两次坚持真机离策略 RL，同时参与 Octo、ACT 的模仿路线；
- Physical Intelligence 从 π0 到 π*0.6 都在同一个 VLA 底座上迭代。

`[判断]` 收敛的部分：动作块成为默认；RL 只在已有能力之上做。分化的部分：RL 用仿真（SimpleVLA-RL、DPPO），还是用真机加人工（HIL-SERL、π*0.6）。

## 用什么衡量进展

结论：仿真 benchmark 测可复现的成功率，真机测吞吐量与连续运行；仿真 benchmark 正在饱和，评测重心转向真机，口径问题也随之变多。

| benchmark 或场景 | 测什么 | 现状 |
|---|---|---|
| RoboMimic、Push-T、Franka Kitchen | 示范学习的成功率，含多峰与长序列 | Diffusion Policy 的主战场；DPPO 用来测 RL 微调 |
| LIBERO | 语言条件的桌面操作，四个套件 | SimpleVLA-RL 平均 99.1%，接近饱和 |
| RoboTwin 1.0/2.0 | 双臂仿真操作 | SimpleVLA-RL 68.8%，仍有空间 |
| 真机逐任务成功率 | 每任务 20–100 次 | ACT 25 次，Diffusion Policy 20 次，HIL-SERL 100 次 |
| 真机吞吐量与连续运行 | 每小时成功次数、能连续工作多久 | π*0.6：连续做咖啡 13 小时 |

`[判断]` 目标迁移：从"在 benchmark 上成功率多少"变成"在真实部署中每小时完成多少、能连续跑多久"。这正是 RL 微调的用武之地，因为模仿学习不优化速度。

口径陷阱：
- Diffusion Policy 的表格同时报最佳检查点与最后 10 个检查点的平均，两个数差距可达 0.2 以上；RoboMimic 评测实际只用了 22 个初始条件。
- 以下论文的正文与表格自相矛盾，引用时以表格为准并注明：
  - HIL-SERL：Diffusion Policy 在仪表盘任务上正文写 28%、表中为 18%；同步带训练时间 6 小时，与摘要的"1–2.5 小时"不符。
  - RT-1：未见任务数正文写 21 条、附录写 53 个。
  - SimpleVLA-RL：真机实验的正文与表 6 不一致。
- π*0.6 的成功由人工标注，吞吐量的具体柱值只在图中。

## 当前开放问题

1. **奖励从哪里来。** 真机上的奖励依赖分类器（[HIL-SERL](../../papers/arxiv-2410.21845/README.md)）或人工标签（[π*0.6](../../papers/arxiv-2511.14759/README.md)）；仿真里的 0/1 奖励会诱发示范里没有的行为（[SimpleVLA-RL](../../papers/arxiv-2509.09674/README.md)）。
2. **RL 能否扩展到长时域与通用模型。** HIL-SERL 自述不确定能否扩到长得多的时域；π*0.6 是在通用 VLA 上做的，但仍按任务迭代，并依赖人工重置。
3. **人工纠正该怎样用。** DAgger 理论假设专家给最优标签；π*0.6 发现人工纠正质量不一致、改善不了速度，所以只把它当作一种数据来源。
4. **不更新权重的适应。** 上下文模仿把示范当作提示（[ICRT](../../papers/arxiv-2408.15980/README.md)、[Behavior Prompting Policy](../../papers/arxiv-2606.30457/README.md)、[RoboTTT](../../papers/arxiv-2607.15275/README.md)），它与 RL 微调是"在推理时适应"还是"在训练时改进"两条路。
5. **失败后的恢复。** 示范里很少有失败后怎样恢复的片段，RL 的失败重置又让这些状态进不了数据；与用户的四足卡住问题同源，见[思考笔记](../../../perspectives/notes/quadruped-recovery.md)。

## 阅读顺序

1. [讲义](../imitation-reinforcement-learning.md)第 3–6 节与第 11–13 节：先把复合误差、多峰动作、PPO 的作用范围理顺。
2. [DAgger](../../papers/arxiv-1011.0686/README.md)：复合误差的定理与第一种修法，后面所有"纠正"类方法都是它的变体。
3. [PPO 精读](../../../llm/papers/ppo/reading.md)：RL 一侧的基线，注意它的局限（探索、超参）。
4. [Diffusion Policy 精读](../../papers/diffusion-policy/reading.md)与 [ACT](../../papers/arxiv-2304.13705/README.md)：模仿一侧的两个基线，一个解决多峰，一个解决复合误差。
5. [HIL-SERL](../../papers/arxiv-2410.21845/README.md)：同样多的人类数据，用来模仿和用来做 RL 的直接对照。
6. [π*0.6](../../papers/arxiv-2511.14759/README.md)与 [DPPO](../../papers/arxiv-2409.00588/README.md)：RL 怎样接到大模型或生成式策略上。

## 批注

**易误读**

- DAgger 的 T²ε 中，ε 是在专家状态分布上测得的错误率，代价有界于 [0,1]；uTε 的 u 最坏也可以是 O(T)，此时 DAgger 并不优于行为克隆（定理 2.1–2.2）。
- ACT 的 1% 对 44% 是关闭时间集成时、4 个仿真设定的平均；真实任务的成功率是每任务 25 次试验（§VI、§V）。
- HIL-SERL 表 1(a) 中名为"BC"的对照列实际是 HG-DAgger，Jenga 与翻物体两个任务除外（Table 1(a) 说明）。
- π*0.6 的"吞吐量翻倍"对照的是"离线 RL + 监督微调"的中间版本，不是 π0.5 或 π0.6；只在多样衣物折叠和意式咖啡两个任务上（§VI-C1）。
- SimpleVLA-RL 的 17.3% → 91.7% 是每任务只给 1 条示范的设定；正常数据量下 LIBERO-Long 是 86.5% → 98.5%（Table 2、Table 5）。
- RT-1 与 Gato、BC-Z 的比较中，基线也在 RT-1 的数据上训练，作者自己说这种比较对基线"相当有利"（§6.2）。
- DPPO 的 16/20 是零样本 sim-to-real；高斯策略加行为克隆正则后，仿真 53%、真机 50%（§5.4）。

**判断的支撑论文**

- 操作以模仿为主、腿足以 RL 为主：本方向与[运动控制方向](../control-locomotion/README.md)的综合表。操作侧 RT-1、ACT、Diffusion Policy、Octo、π0 都以示范为主要信号；腿足侧 Hwangbo 2019、Lee 2020、Rudin 2021、Miki 2022 都以仿真奖励为主要信号。边界：腿足的学生一侧是模仿（Lee 2020、Miki 2022），人形的运动跟踪（ExBody、H2O、BeyondMimic）以人类动作数据为参考；操作的 DPPO 在仿真中做 RL。
- 运动控制绕不开模仿：DeepMimic §6 与 §10.4、ExBody 表 IV、Lee 2020 引言、ASE 表 1、BeyondMimic 引言、OmniH2O 表 1a、AME-2 图 16。反例：Rudin 2021 与 Agarwal 2022 第一阶段不用参考动作；Robot Parkour 用课程解决探索（§4.1）。
- RL 补的是示范之外的状态与超过示范者的速度：HIL-SERL Table 1(a)（成功率与完成时间）与 §4.5（示范加 10 倍不改善）；π*0.6 §II 与 §VI-C1；RT-1 §7。边界：SimpleVLA-RL 的提升主要在少示范设定下，数据充足时提升较小（98.5% 对 86.5%）。
- 与 LLM 后训练同构：SimpleVLA-RL §1、§6.1–6.2；对照 [DeepSeek-R1](../../../llm/papers/arxiv-2501.12948/README.md)。边界：π*0.6 不用 GRPO，而用价值函数加优势条件化，作者明确报告 PPO 类方法难以改进。
- 教师-学生的蒸馏步骤有时可以省掉：PIE Introduction、DTC Methods（非对称 actor-critic）、AME-1（单网络两段 PPO）。反例：AME-2（2026）在深度建图输入下又用回教师-学生加表征对齐；OmniH2O 在稀疏输入下 RL 训练的学生只有 47.11%。
- 团队偏好：Google 在 RT-1、RT-2、Open X-Embodiment 中都扩大示范；Berkeley 在 SERL、HIL-SERL 中都做真机离策略 RL；Physical Intelligence 在 π0、π*0.6 中沿用同一底座。SERL 本身未收录，依据是 HIL-SERL §2 的自述。

**与其他论文的关联**

- [HIL-SERL](../../papers/arxiv-2410.21845/README.md) 与 [π*0.6](../../papers/arxiv-2511.14759/README.md) 都以 HG-DAgger 为对照或数据来源，引用 [DAgger](../../papers/arxiv-1011.0686/README.md) 的复合误差作为出发点。
- [DPPO](../../papers/arxiv-2409.00588/README.md) 以 [Diffusion Policy](../../papers/diffusion-policy/reading.md) 为预训练策略、以 [PPO](../../../llm/papers/ppo/reading.md) 为优化器；π*0.6 把 DPPO 类的 PPO 作为策略提取的对照。
- [ACT](../../papers/arxiv-2304.13705/README.md) 以 [RT-1](../../papers/arxiv-2212.06817/README.md) 为基线之一；[π0](../../papers/arxiv-2410.24164/README.md) 在微调实验中以 ACT 和 Diffusion Policy 为基线。
- 腿足中的同一组合（RL 教师 + DAgger 学生）见[运动控制方向](../control-locomotion/README.md)第 3 节；DTC 以非对称 actor-critic 替代蒸馏。
- 动作模仿一支（[DeepMimic](../../papers/arxiv-1804.02717/README.md) → [AMP](../../papers/arxiv-2104.02180/README.md) → [ASE](../../papers/arxiv-2205.01906/README.md)，四足 [Peng 2020](../../papers/arxiv-2004.00784/README.md)、[Escontrela 2022](../../papers/arxiv-2203.15103/README.md)，人形 [ExBody](../../papers/arxiv-2402.16796/README.md)、[H2O](../../papers/arxiv-2403.04436/README.md)、[OmniH2O](../../papers/arxiv-2406.08858/README.md)）在[运动控制方向](../control-locomotion/README.md#为什么绕不开模仿学习)。AMP 的判别器只看状态转移、不需要示范者的动作（AMP §5.1），这正是腿足能用动作捕捉做模仿的原因。
- [SimpleVLA-RL](../../papers/arxiv-2509.09674/README.md) 的 GRPO 来自 LLM 后训练，见 [PPO 精读](../../../llm/papers/ppo/reading.md)的"局限与后续"。同期的 VLA-RL（[arXiv:2505.18719](https://arxiv.org/abs/2505.18719)）用 PPO 加 VLM 过程奖励模型，并把避免奖励被钻空子列为设计目标；它在 LIBERO 上平均 81.0%，比监督微调高 4.5 个百分点（未建卡）。
