# 导航与规划 从目标地点到可执行路线

“去厨房”首先是一个语义目标，还不是一条运动路径。机器人需要把厨房对应到地图区域，在可以通行的空间中寻找路线，再把路线转换成能跟踪的运动指令。任务规划决定做哪些事情，路径规划决定怎样走，局部避障处理突然出现的人或障碍物；这几个问题相关，却有不同输入和时间尺度。

把房间画成网格，可以直观理解路径规划。每个格子标记能否通行，搜索算法在相邻格子之间寻找从起点到终点的连接。连续空间里不可能列出每一个位置，于是采样式规划先抽取候选位置，再尝试连接它们。RRT一类方法生长一棵探索树；RRT*还会调整局部连接以改进路径代价。数学上的渐近性质有前提，不能解释成有限时间里一定找到全局最优路线。

真实机器人还要考虑体积和运动约束。地图上的一点能穿过门缝，不代表带底盘的机器人能通过；小车也不能像棋子一样瞬间横移。因此，规划时应使用与本体相符的状态和动作约束，执行时持续检查地图是否变化。

语言导航增加了另一个难点：目标可能是一段相对描述，例如“经过沙发，在第二个门左转”。系统必须把语言中的参照物与观察对应起来，并在走动过程中维护进度。VLN是视觉语言导航的简称，评估时要区分见过的房间和新环境，也要区分到达目标与严格遵循指定路径。

具身Agent可以调用导航作为技能，但调用返回的“执行结束”不应自动等同于目标已找到。更稳妥的闭环还包括目标验证、找不到时扩大搜索范围以及无法继续时报告原因。
