# 模仿学习与机器人强化学习 怎样学会一个动作

教机器人把积木推到目标位置，可以有两种不同的起点。第一种是给它人类或控制器示范：某个观察下做了什么动作。第二种是让它尝试，根据最终距离或是否成功给予反馈。前者对应模仿学习的重要形式，后者对应强化学习的基本问题。

行为克隆把观察当输入、示范动作当目标，训练一个预测器。问题在于，部署时机器人可能走到示范没覆盖的状态。一次小偏差导致下一次输入更陌生，错误便会累积。动作还有多种合理方式：从障碍物左边和右边绕过去都可以，简单平均两条路线却可能正好撞上障碍物。Diffusion Policy从动作分布而非唯一平均动作入手，是学习这个问题的合适案例。

强化学习中，策略决定怎样选动作，环境决定动作以后出现什么状态，奖励表达哪些结果值得追求。一次任务从开始到结束产生轨迹，其中可能有许多中间动作。最终成功了，哪些动作真正有贡献？这个问题叫信用分配。奖励设计得不合理时，策略也可能学会利用评分漏洞，而不完成人的真实目标。

在机器人上，试错还受样本成本和安全约束。仿真能增加训练机会，但会带来现实差异；离线数据便于复用，却不能随意把数据中没有的动作后果当成已知。世界模型提供另一种思路：先学习预测，再在预测中训练，但这会引入模型误差。

因此，比较方法时需要把交互预算、示范数量、奖励信息、特权状态、控制频率和测试扰动对齐。一个方法训练时知道地形真值，另一个只看相机，结果不能直接归因于算法名字不同。下方三篇分别对应动作分布、策略优化和适应，不是可互换的三个品牌。
