# 扩展阅读：与主线相邻，但解决的是不同问题

这些条目不计入本库 21 份 PDF 和 21 篇原文解读，也未在本目录保存其全文。这里只保留主题定位和必要边界，不把它们标为本次全文精读。后续有明确研究问题时再扩展，避免用更多论文名称代替理解。

| 方向 | 条目与原文入口 | 阅读这条分支时要区分什么 |
|---|---|---|
| 多模态代码工具 | [Instruct2Act（2023，2305.11176v3）](https://arxiv.org/abs/2305.11176v3) | 图文指令经程序调用视觉与操作模块；该版本实验为 VIMABench 仿真，不应写成已有真机证明；勿与 2026 同名条目混淆 |
| 奖励代码连接控制 | [Language to Rewards（2306.08647v2）](https://arxiv.org/abs/2306.08647v2) | 配置奖励/残差目标并交给 MPC，不等于必须训练 RL，也不等于 LLM 直接高频控制关节 |
| 奖励搜索连接训练 | [Eureka（2310.12931v2）](https://arxiv.org/abs/2310.12931v2) | LLM 写奖励后仍要训练机器人策略；灵巧手转笔的仿真证据，不能被真实 hopping 演示改写成实机转笔 |
| 代码生成模型训练 | [RoboPro（2501.04268）](https://arxiv.org/abs/2501.04268) | Video2Code 数据与代码生成模型训练；与冻结通用 Agent 推理时写程序，成本发生的位置不同 |
| 运行期代码监控 | [Code-as-Monitor（2412.04455v3）](https://arxiv.org/abs/2412.04455v3) | 生成约束用于监控；监控能发现问题，不意味着能独立完成任意恢复 |
| 动作前验证 | [TeV（2609.39038v1）](https://arxiv.org/abs/2609.39038v1) | 训练时序编码器与 energy verifier；动作筛选与语言反思不同，真机子步骤评分不应当作完整任务成功率 |
| 程序向动作模型输送数据 | [EmbodiedSWE（2609.27308v2）](https://arxiv.org/abs/2609.27308v2) | 验证程序、扰动采轨迹再训练 VLA，是数据与训练路线，不能仅看成运行时 Agent |

本页依据原文摘要/项目入口和并行文献核查整理；未在本目录为这些条目开展完整方法与实验复核。因此不抄录成功率或将其纳入横向比较。主线内对应的详细阅读可从 [VoxPoser](../../../papers/arxiv-2307.05973/reading.md)、[HELM](../../../papers/arxiv-2604.18791/reading.md)、[ENPIRE](../../../papers/arxiv-2606.19980/reading.md) 和 [AgenticRoboRL](../../../papers/arxiv-2610.28589/reading.md) 开始。
