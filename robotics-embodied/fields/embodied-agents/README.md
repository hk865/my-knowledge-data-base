## 先理解什么

本方向的教学讲义面向已有基础深度学习、物理与运动学知识的读者，串联前向过程、变量与公式、具体算例、训练或优化过程以及适用边界。

## 一个容易混淆的边界

真实机器人中的观察、状态估计、计划与执行各有误差。跨方向的方法关联不表示相同实验环境或直接历史继承。
