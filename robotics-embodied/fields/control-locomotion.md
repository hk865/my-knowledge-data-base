# 运动控制 怎样把想去的位置变成稳定运动

计划器说“把机械臂移动到杯子上方”，控制器还要不断决定怎样驱动关节。由于模型误差、载荷变化和外部扰动，实际状态通常不会完全符合计划。反馈控制反复测量误差，再据此调整输入。

最简单的直觉是：离目标远时用力大，快到目标时减小输入。但仅看位置差可能造成来回摆动；速度、响应延迟和系统惯性也会影响结果。PID把当前误差、累计误差和误差变化结合起来，LQR则在一个特定的模型和代价结构下权衡状态偏差与控制努力。理解这些名字时，首先要问它们假设了怎样的动力学，而不是把它们排成谁永远更先进。

模型预测控制简称MPC。它反复设想未来短时间内采取几组动作的后果，选出满足约束且代价较好的序列，执行开头一部分，再根据新状态重新计算。这种滚动更新和一次性规划整段运动不同。四足机器人还要处理哪条腿接触地面、接触力限制以及机身姿态等问题。

学习控制可以从数据或试错中得到动作策略。策略在仿真里表现很好，并不保证真实地面的摩擦、电机延迟和质量分布也符合训练设置。RMA研究通过近期经历进行适应；它是理解训练期额外信息与部署期可用观测差异的一个baseline。

高层具身Agent适合决定“走到桌边”或“改用另一种抓取方式”，而高速姿态稳定应由满足实时要求的执行系统承担。这里的分工是工程上的时间尺度分析，不是对所有学习架构的定律。读论文应看控制频率、推理延迟、动作接口、扰动测试以及是否真正部署到硬件。
