# 运动控制与腿足运动的基线

[回到入门](README.md) · [阅读路线](ROADMAP.md) · [全部文献](PAPERS.md) · [综合表](synthesis.csv)

## 基线是谁、为什么是它

本方向有两条并行的基线，后续工作要么改其中一条的部件，要么把两条接起来。

| 基线 | 定义了什么 | 为什么是它 |
|---|---|---|
| [Convex MPC](../../papers/convex-mpc/reading.md)（MIT Cheetah 3，2018） | 接口：机身状态估计 + 速度命令 → 未来约 0.5 s 各支撑脚的地面反作用力 → τ = JᵀRᵀf；范式：单刚体模型、预定接触时序、凸 QP 在线滚动求解；评估：同一组权重下多种步态的实机演示 | 模型控制路线的代表，它当作已知输入的接触时序、摩擦和地形，正是学习路线后来要去估计或绕开的量 |
| 仿真 RL 流水线：[Rudin 2021](../../papers/arxiv-2109.11978/README.md)（legged_gym + [PPO](../../../llm/papers/ppo/reading.md)），部署结构取 [Lee 2020](../../papers/arxiv-2010.11251/README.md) 的特权教师-学生 | 接口：本体感知（及其历史）+ 速度命令 → 12 个关节的目标角 → 关节 PD；范式：GPU 上数千台并行仿真、地形课程、域随机化，零样本部署；评估：仿真地形等级与成功率 + 实机逐项试验 | 2021 年以后的腿足 RL 基本按这套流程训练；Lee 2020 的教师-学生是外部感知、跑酷等工作沿用的部署结构 |

## 基线的结构拆分

把两条基线合起来看，可以拆成六个可替换的部件：

1. **观测**：只用本体感知、本体感知历史、特权信息（只给教师或 critic），还是外部感知（高程图、深度图）。
2. **动作接口**：关节目标角、足端轨迹生成器的残差、振荡器（CPG）参数、接触力，还是"跟踪给定落脚点"。
3. **训练信号**：速度跟踪奖励加惩罚项、约束、参考动作模仿、风险敏感目标。
4. **训练分布**：域随机化、地形课程、对抗扰动、初始状态（例如倒地姿态）。
5. **仿真器保真度**：执行器模型、地形几何、接触模型。
6. **系统结构**：单一策略、教师-学生、分层（行为选择器）、规划器 + 跟踪策略。

## 批注

**易误读**

- Rudin 2021 不是"更好的策略"，而是"更快的训练流程"，作者明说目标不是得到最鲁棒的策略（§5）；把它当作基线，取的是它的工具链与默认设置。
- 表中"训练分布"一行的 PER、Go-Explore、PLR 来自游戏与通用 RL，放进本表是因为[思考笔记](../../../perspectives/notes/quadruped-recovery.md)把它们作为恢复问题的候选解法，它们本身没有在腿足上验证。
- MGDP 只核实了元数据与摘要，改法一格是摘要级的描述。

**与其他论文的关联**

- 同一篇论文可能改了不止一个部件：DTC 同时改了动作接口和系统结构，AME-2 同时改了观测与训练信号（目标到达代替速度跟踪）。表中按主要贡献归类。
- 模仿与强化在本方向的组合（RL 教师 + DAgger 学生）见[模仿学习与机器人强化学习的基线](../imitation-reinforcement-learning/BASELINES.md)。
- 参考动作进入训练信号的三步：[DeepMimic](../../papers/arxiv-1804.02717/README.md) 逐片段跟踪 → [AMP](../../papers/arxiv-2104.02180/README.md) 分布匹配 → [ASE](../../papers/arxiv-2205.01906/README.md) 预训练可复用的技能嵌入（ASE 仍归在"用 RL 跟踪参考动作"一行）；四足上的应用先是 [Peng 2020](../../papers/arxiv-2004.00784/README.md) 的逐帧跟踪，后是 [Escontrela 2022](../../papers/arxiv-2203.15103/README.md) 的风格奖励；人形上是 [ExBody](../../papers/arxiv-2402.16796/README.md)、[H2O](../../papers/arxiv-2403.04436/README.md)、[BeyondMimic](../../papers/arxiv-2508.08241/README.md)。失败场景见[入门页](README.md)主线历史中的插叙。
- 表中有三处是模仿学习：训练信号里的参考动作各行、系统结构里的 OmniH2O、观测里各教师-学生工作的学生一侧。为什么运动控制绕不开它们，见[入门页](README.md#为什么绕不开模仿学习)；观测各行沿"从本体状态到环境状态"的排列见[入门页](README.md#从本体状态到环境状态)。
- 各格的失败场景与"站在现在看过去"的分析在[入门页](README.md)的主线历史一节。
