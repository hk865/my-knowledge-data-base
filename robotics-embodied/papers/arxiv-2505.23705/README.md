# Knowledge Insulating Vision-Language-Action Models: Train Fast, Run Fast, Generalize Better

> 状态：文献卡 · 2025 · [原文](https://arxiv.org/abs/2505.23705)

[返回机器人与具身目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：在预训练视觉语言模型（VLM）上接一个随机初始化的连续动作专家（π0 的做法），动作专家的梯度会破坏 VLM 已学到的知识，语言跟随变差、训练变慢；改用离散 FAST token 自回归输出又太慢，π0-FAST 在 RTX 4090 上推理一个 1 秒动作块要 750 ms（§2、§4）。
- **核心方法**：相对 [π0](../arxiv-2410.24164/README.md)，改训练目标与梯度路径。VLM 骨干用 [FAST](../arxiv-2501.09747/README.md) 离散动作 token 做交叉熵，并与网页图文数据联合训练；动作专家（flow matching，一句话：学习一个把噪声逐步推成动作的速度场）读取骨干的表示生成 50 步连续动作块，但在注意力里对骨干的 K、V 做 stop-gradient，梯度不回流骨干（式 5–6）；部署时只用动作专家，不做自回归解码。π0 要用约 7.5 倍训练步数才达到相近表现（图 6b）；DROID 零样本进度分 0.55，π0 为 0.49，π0-FAST 为 0.45（§6）。作者自述同时训练两种输出使训练计算增加约 20%，语言跟随仍远非完美（§7）。
- **为什么在这个库里**：[VLA Baseline 表](../../fields/vla/BASELINES.md)中"训练目标 = 离散 token 与连续动作联合、梯度隔离"一格；它把 [π0.5](../arxiv-2504.16054/README.md) 的两阶段配方改成单阶段，此后 [π*0.6](../arxiv-2511.14759/README.md) 与 [π0.7](../arxiv-2604.15483/README.md) 都沿用这套配方。原文 Fig.2 中 π0 不理会"把勺子放进收纳盒"的指令而去抓垃圾，是"连续动作头损伤语言能力"的直接案例。优先级：必读。
