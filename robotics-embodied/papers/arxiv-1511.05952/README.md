# Prioritized Experience Replay

> 状态：文献卡 · 2016 · [原文](https://arxiv.org/abs/1511.05952)

[返回机器人与具身目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：经验回放（experience replay，一句话：把过去的状态转移存进缓冲区，训练时反复抽样复用）原本均匀抽样，罕见但信息量大的转移和普通转移被复用的次数一样多。
- **核心方法**：按 TD 误差（一句话：当前价值预测与「一步奖励加下一状态价值」之差）的大小给每条转移设优先级，按优先级做随机抽样，以免只反复重放少数转移而失去多样性；再用重要性采样权重修正抽样分布改变带来的偏差。用在 DQN（深度 Q 网络）上，49 个 Atari 游戏中有 41 个优于均匀回放。
- **为什么在这个库里**：[四足故障后恢复](../../../perspectives/notes/quadruped-recovery.md)四类解法中「算法与损失」一类的经典做法：让更新更多地来自模型还没学好的样本，对应「让损失在长尾场景中依然显著」；重要性采样修正则用来控制这种偏重对整体目标的影响。[Prioritized Level Replay](../arxiv-2010.03934/README.md) 把同样按 TD 误差打分的思路用在训练关卡上。优先级：选读。
