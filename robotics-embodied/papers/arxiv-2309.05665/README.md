# Robot Parkour Learning

> 状态：文献卡 · 2023 · [原文](https://arxiv.org/abs/2309.05665)

[返回机器人与具身目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：跑酷需要一个既看得见障碍、又能在攀爬、跳跃、钻低栏、侧身挤过窄缝和奔跑之间自主选择的策略；攀爬和跳跃这类技能直接用强化学习训练，探索很难找到成功的动作序列。
- **核心方法**：每个技能分两阶段强化学习。预训练阶段施加「软动力学约束」：允许机器人穿过障碍物，用穿透奖励（穿透体积与深度乘以前进速度）逐步惩罚穿透，并按自动课程提高障碍难度；接近收敛后，在不允许穿透的「硬动力学约束」下微调（§3.1）。之后用 DAgger（一句话：由教师在学生实际到达的状态上给动作标签的模仿学习）把五个技能蒸馏成一个以深度图为输入的 GRU（门控循环单元，一种带记忆的循环网络）策略，部署到 A1 和 Go1 两款四足（§3.2）。仿真对比中，不做软约束预训练的版本和 RND（一种用预测误差作为好奇心奖励的探索方法）都学不会攀爬和跳跃；把 GRU 换成无记忆的 MLP 也学不会这两项，作者的解释是攀爬时后腿要用到之前深度图里看到的障碍尺寸（§4.1）。
- **为什么在这个库里**：[四足故障后恢复](../../../perspectives/notes/quadruped-recovery.md)四类解法中「解除限制」一类的直接例子：先放宽物理约束，让探索找到可行动作，再收紧回真实物理；GRU 的消融同时属于「加时间感知」。优先级：必读。
