# A Survey of Behavior Foundation Model: Next-Generation Whole-Body Control System of Humanoid Robots

> 状态：文献卡 · 2025 · [原文](https://arxiv.org/abs/2506.20487)

[返回机器人与具身目录](../../README.md) · [原文版本与阅读记录](source.json)

- **解决什么**：人形全身控制（WBC，一句话：同时协调全身关节完成平衡、移动与操作）动力学复杂、欠驱动、任务多样；学习型控制器每换一个场景就要重新训练，代价高。
- **核心方法**：综述：把行为基础模型（BFM，一句话：用大规模行为数据预训练、可零样本或少量适配到多种下游控制任务的策略）按预训练流程梳理，讨论应用、当前局限和挑战，并维护一份持续更新的论文列表。与库内更宽的[人形运动与操作综述](../arxiv-2501.02116/README.md)相比，本篇只聚焦"预训练行为模型"这一条路线。
- **为什么在这个库里**：[运动控制与腿足运动](../../fields/control-locomotion/README.md)方向人形分支的路线地图，读 [BeyondMimic](../arxiv-2508.08241/README.md)、[Scaling BFM](../arxiv-2607.15163/README.md) 前用来对齐术语。优先级：存档。
