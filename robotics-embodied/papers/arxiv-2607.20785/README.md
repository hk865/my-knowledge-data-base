# Robostral Navigate

> 状态：文献卡 · 2026 · [原文](https://arxiv.org/abs/2607.20785)

[返回机器人与具身目录](../../README.md) · [原文版本与阅读记录](source.json)

- **解决什么**：视觉语言导航系统多依赖深度相机、激光雷达或多相机，换一种机器人就要重新标定；只用单目 RGB 的方法成绩又落后。
- **核心方法**：Mistral AI 的 8B 视觉语言模型只看单目 RGB 图像流和语言指令，以"在当前图像上指出目标位置并给出期望朝向"的形式输出航点（目标不在视野内时退回机器人坐标系下的位移指令）。它约 0.5 Hz 运行，下面接一个 121M 参数的扩散策略以 10 Hz 生成稠密轨迹，再由运动控制器转成 100 Hz 的电机指令。训练全部在仿真里：240 万条轨迹、35 万个场景，用前缀缓存把整段回合打包成一条训练序列；最后在困难子集上用 CISPO 做在线 RL。R2R-CE 未见验证集成功率 77.4%（arXiv v3），比最好的单目方法高 10.5 个百分点、比用深度或多相机的方法高 5.3 个百分点；在 Galaxea R1 与 Hiwonder JetAuto 两台形态差别很大的机器人上用同一权重演示，没有报告真机成功率，也没有局限一节。
- **为什么在这个库里**：[导航与规划方向](../../fields/navigation-planning/README.md)阶段 6"双系统导航基础模型"的又一个实例，而且来自一家大语言模型公司：上层在图像上指点、下层扩散策略出轨迹，接口与 [DualVLN](../arxiv-2512.08186/README.md)、[ABot-N1](../arxiv-2607.10383/README.md) 一致；纯仿真数据训练又接回了 [DD-PPO](../arxiv-1911.00357/README.md) 一系的仿真规模化。优先级：选读。
