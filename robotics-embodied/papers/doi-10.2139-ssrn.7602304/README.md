# RT-LIVO: Semantic and Motion-Aware LiDAR-Inertial-Visual Odometry for Robust Mapping in Dynamic Environments

> 状态：文献卡 · 2026 · [原文](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=7602304)

- **解决什么**：限制动态物体对 LiDAR、视觉融合观测及地图的干扰。
- **核心方法**：语义候选经光流验证、时间平滑和深度一致性筛选，再以经验可靠性评分调整滤波器视觉协方差。
- **为什么在这个库里**：直接覆盖动态筛选与视觉调权的组合，需要优先辨析新增方法与其差别。优先级：必读。
