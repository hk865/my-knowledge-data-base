# Learning Universal Policies via Text-Guided Video Generation

> 状态：文献卡 · 2023 · [原文](https://arxiv.org/abs/2302.00111)

[返回机器人与具身目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：不同控制环境的状态与动作空间各不相同，难以共享知识；能否以图像为通用接口、以文本描述任务。
- **核心方法**：把决策写成文本条件的视频生成：扩散模型以首帧和任务文本为条件生成未来视频，逆动力学模型从相邻帧解出动作（UniPi）。组合泛化任务上明显超过基线；生成一段高真实度视频约需一分钟，部分可观测时会幻觉。
- **为什么在这个库里**：[世界模型](../../fields/world-models/README.md)用法 (e)"预测未来再出动作"的起点。优先级：选读。
