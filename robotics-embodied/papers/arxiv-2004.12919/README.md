# First return, then explore

> 状态：文献卡 · 2021 · [原文](https://arxiv.org/abs/2004.12919)

[返回机器人与具身目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：奖励稀疏或具有欺骗性时，强化学习很难探索到关键状态。作者认为主要障碍有两个：算法忘了怎样回到曾经到过的有希望的状态（detachment），以及在探索之前没有先回到那个状态（derailment）。
- **核心方法**：提出 Go-Explore：维护一个状态档案，按启发式挑出一个有希望的状态，先回到那里（在仿真中直接恢复仿真器状态，或运行一个目标条件策略），再从那里探索，并把新到达的状态加入档案（图 1）。靠恢复仿真器状态得到的轨迹对随机性很脆弱，再用一个「稳健化」阶段，以这些轨迹为示范训练出鲁棒策略。在 Montezuma's Revenge、Pitfall 等难探索 Atari 游戏上大幅超过此前方法；在一个奖励极稀疏的仿真机械臂抓放任务上，PPO 训练十亿帧都没有拿到一次奖励，Go-Explore 稳健化后的策略在四个目标位置上都能在 99% 的试验中完成（图 4）。
- **为什么在这个库里**：[四足故障后恢复](../../../perspectives/notes/quadruped-recovery.md)四类解法中「算法与损失」一类（与「场景」相通）：把罕见的困难状态记下来，直接从那里开始探索，对应「把卡住状态存成仿真初始状态再训练」的做法。优先级：选读。
