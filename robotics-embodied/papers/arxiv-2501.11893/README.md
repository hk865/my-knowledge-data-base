# DynoSAM: Open-Source Smoothing and Mapping Framework for Dynamic SLAM

> 状态：文献卡 · 2025 · [原文](https://arxiv.org/abs/2501.11893)

- **解决什么**：在定位过程中保留并估计外部物体运动，而不只是删掉动态点。
- **核心方法**：用统一因子图融合静态与动态观测，联合估计相机位姿、静态结构、对象运动与对象结构。
- **为什么在这个库里**：作为自身运动与对象运动联合估计的对象级路线参考。优先级：必读。

[官方代码](https://github.com/ACFR-RPG/DynOSAM)
