# Towards Robust Sensor-Fusion Ground SLAM: A Comprehensive Benchmark and A Resilient Framework

> 状态：文献卡 · 2025 · [原文](https://arxiv.org/abs/2507.08364)

- **解决什么**：系统评估多传感器 SLAM 在观测退化情况下的鲁棒性。
- **核心方法**：提出包含多种受控退化的 M3DGR 数据集，比较多种系统，并提出模块化融合框架 Ground-Fusion++。
- **为什么在这个库里**：提供真实动态与退化场景的评估入口；数据集不是运动分割真值或控制输入的默认来源。优先级：必读。

[官方数据集](https://github.com/sjtuyinjie/M3DGR)
