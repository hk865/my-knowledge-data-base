# VLA-REPLICA: A Low-Cost, Reproducible Benchmark for Real-World Evaluation of Vision-Language-Action Models

> 状态：文献卡 · 2026

- **解决什么**：真机评测成本与场景差异妨碍各实验室重复比较。
- **核心方法**：用 SO-101、灯箱和场景标定规范搭建可本地复现的域内/域外任务集。 [1]
- **为什么在这个库里**：[VLA 评测地图](../../fields/vla/README.md#用什么衡量进展)的“实验室能否复搭”；计数任务连接[具身 Agent](../../fields/embodied-agents/README.md)的进度记录。优先级：选读。
