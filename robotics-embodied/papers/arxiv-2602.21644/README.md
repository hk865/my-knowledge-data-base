# DAGS-SLAM: Dynamic-Aware 3DGS SLAM via Spatiotemporal Motion Probability and Uncertainty-Aware Scheduling

> 状态：文献卡 · 2026 · [原文](https://arxiv.org/abs/2602.21644)

- **解决什么**：降低动态 RGB-D 场景中逐帧分割与光流处理的开销。
- **核心方法**：为每个三维高斯维护时空运动概率，融合实例语义和几何，并按不确定性触发语义计算。
- **为什么在这个库里**：对应连续运动概率和按需语义计算的竞争方向。优先级：选读。
