# CaT: Constraints as Terminations for Legged Locomotion Reinforcement Learning

> 状态：文献卡 · 2024 · [原文](https://arxiv.org/abs/2403.18765)

[返回机器人与具身目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：腿式强化学习通常把力矩上限、关节速度上限和步态风格写成一打左右的奖励惩罚项，权重靠反复调参，得到的策略也只是各项之间的折中，不保证约束总被满足。
- **核心方法**：把约束改写成「随机终止」：每个约束的违反量除以近期的最大违反量、乘上该约束的最大终止概率，再在所有约束中取最大，得到终止概率 δ；此后的所有奖励按 (1−δ) 缩小（§III-B，式 6）。这里的终止只截断未来奖励，不重置环境。δ 取 0 到 1 之间的值，使智能体在违反约束之后仍得到「怎样回到约束内」的稠密信号，也允许在违反区域里有一定探索。在 PPO 上只需几行改动：奖励乘以 (1−δ)，并把 δ 当作终止信号（算法 1）。在开源轻量四足 Solo-12 上，配合高度扫描观测走楼梯、陡坡并爬上高台。
- **为什么在这个库里**：[四足故障后恢复](../../../perspectives/notes/quadruped-recovery.md)四类解法中「解除限制」一类：把「一出现某种状态就整回合终止重置」换成「按违反程度部分截断回报、环境继续运行」，违反之后的状态仍留在训练数据里，硬约束也不必再靠大量惩罚项调出来。优先级：选读。
