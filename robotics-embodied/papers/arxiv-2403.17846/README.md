- **解决什么**：机器人如何在多楼层三维环境中依照语言寻找物体。
- **核心方法**：构建楼层、房间、对象层次图，并用开放词汇特征检索目标。
- **为什么在这个库里**：分析多楼层层次地图与导航检索。
