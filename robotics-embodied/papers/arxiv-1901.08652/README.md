# Learning agile and dynamic motor skills for legged robots

> 状态：文献卡 · 2019 · [原文](https://arxiv.org/abs/1901.08652)

[返回机器人与具身目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：在仿真里用强化学习训练的腿足策略搬不到真机上；ANYmal 的 12 个串联弹性执行器（SEA，一句话：电机与关节之间串一个弹簧，力控好但动力学复杂）没有足够准确的解析模型，前人方法依赖准确的解析执行器模型（Introduction）。
- **核心方法**：用真机上约 4 分钟采集的数据训练一个"执行器网络"（3 层、每层 32 单元的 MLP，输入最近三个时刻的关节位置误差与速度，输出关节力矩），把它接进刚体仿真器，替代理想或解析执行器模型；再对惯量做随机化，用 TRPO 训练速度跟踪、高速奔跑和倒地起身三个策略，直接部署（Method）。用理想或解析执行器模型训练的对照策略在真机上"一步都没走出来就摔倒"；执行器网络版本速度跟踪误差比同机的模型控制器（Bellicoso 等）更低、力矩与功率更小，最高速度 1.5 m/s，比 ANYmal 此前纪录高 25%（Results）。作者自述每个任务的代价函数和初始状态分布要人工调（行走约 2 天、起身约 1 周），一个网络只会一种行为（Discussion）。
- **为什么在这个库里**：[运动控制方向](../../fields/control-locomotion/README.md)"从仿真到真机"一段的起点：它把 sim-to-real 的差距拆成执行器动力学、延迟、关节柔顺、惯量误差几项，并说明执行器是第一大项。Baseline 表中"仿真器保真度"一格的代表。优先级：必读。
