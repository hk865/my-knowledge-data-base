# π*0.6: a VLA That Learns From Experience

> 状态：文献卡 · 2025 · [原文](https://arxiv.org/abs/2511.14759)

[返回机器人与具身目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：只靠模仿学习训练的 VLA（视觉语言动作模型，一句话：以图像和语言指令为输入、直接输出机器人动作的大模型）会累积误差，最多做到和示范一样好；要让它在真实部署中越练越好，需要一种能吃下自主执行数据和人工纠正数据的强化学习方法（§II）。
- **核心方法**：RECAP（RL with Experience and Corrections via Advantage-conditioned Policies）。先用带成功/失败标签的回合训练一个多任务的分布式价值函数（预测还要多少步完成），再用它算出每个动作的优势，把"优势是否为正"二值化后作为条件输入给策略，监督训练时同时用示范、自主执行回合和专家遥操作纠正三类数据（§IV-A–C）；相对 π0.6 的纯监督版本，改的是训练目标与数据来源，网络结构基本不变。评测任务是叠衣、组装纸箱和做意式咖啡；在其中的"多样衣物折叠"与"意式咖啡"上，加入真机数据后，最终模型相对"离线 RL 预训练 + 监督微调"的中间版本，吞吐量（每小时成功次数）提高一倍以上，失败率降到一半以下（§VI-C1，图 7–8）。作者自述系统仍依赖人工打成功标签、介入纠正和重置环境，探索基本是贪心的，更新方式是分轮的离线更新而不是并发的在线 RL（§VII）。
- **为什么在这个库里**：[模仿与强化学习 Baseline 表](../../fields/imitation-reinforcement-learning/BASELINES.md)中"策略改进 = 在大规模模仿之上用 RL 微调"一格的公司级代表，与 [DPPO](../arxiv-2409.00588/README.md)（仿真中直接对扩散策略做策略梯度）和 [HIL-SERL](../arxiv-2410.21845/README.md)（单任务真机 RL）对照，回答"大模型策略怎样从部署经验中改进"。优先级：必读。
