# RoboDojo: A Unified Sim-and-Real Benchmark for Comprehensive Evaluation of Generalist Robot Manipulation Policies

> 状态：文献卡 · 2026

- **解决什么**：短程、单一能力与仿真/真机割裂的评测难以诊断通用操作策略。
- **核心方法**：按五类能力组织仿真，并用统一部署接口和标准化真机环境补充测试。 [1]
- **为什么在这个库里**：[VLA 评测地图](../../fields/vla/README.md#用什么衡量进展)的“能力覆盖与真机接口”；另连接具身 Agent 的记忆和长程问题。优先级：选读。
