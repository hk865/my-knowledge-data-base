# Speaker-Follower Models for Vision-and-Language Navigation

> 状态：文献卡 · 2018 · [原文](https://arxiv.org/abs/1806.02724)

[返回机器人与具身目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：R2R 基线在没见过的建筑里成功率只有约 21%，人写的指令少、粒度不一，逐 30° 转向的动作接口与指令的粒度对不上。
- **核心方法**：相对 [R2R](../r2r/reading.md) 改三处：用"说话者"模型（路线 → 指令）合成指令扩充训练数据；推理时用说话者给候选路线打分，选最能被描述成这句指令的路线（语用推断）；把动作空间换成全景视角下直接选相邻视点。R2R 测试成功率从 20.4% 提到 53.5%，代价是提交版的路线搜索让平均轨迹长达 1257 m。
- **为什么在这个库里**：[导航与规划](../../fields/navigation-planning/README.md)主线第 3 步：R2R 之后的第一轮修补，全景动作空间成为后续 VLN 的默认接口。优先级：选读。
