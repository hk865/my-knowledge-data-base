# World Models

> 状态：文献卡 · 2018 · [原文](https://arxiv.org/abs/1803.10122)

[返回机器人与具身目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：能否先学一个环境的生成模型，再完全在模型生成的"梦"里训练控制器。
- **核心方法**：VAE 压缩画面（V）、MDN-RNN 预测下一步潜变量的分布（M）、线性控制器（C）。CarRacing 得分 906；VizDoom 中控制器在梦里训练后迁回真实环境。控制器会钻模型的空子：温度 τ = 0.10 时梦中 2086、真实 193。
- **为什么在这个库里**：[世界模型](../../fields/world-models/README.md)主线第 1 步：在想象中学策略的起点，也是"策略利用模型误差"的第一个清楚案例。优先级：必读。
