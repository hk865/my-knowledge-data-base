- **解决什么**：缓解四旋翼仅依赖惯性积分时的速度及位置漂移。
- **核心方法**：用实测旋翼转速与惯性数据预测速度并融合其不确定性。
- **为什么在这个库里**：研究气动先验如何改进飞行器惯性里程计。
