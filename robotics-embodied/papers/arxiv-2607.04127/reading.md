# LiDAR-GS-SLAM：让跟踪与建图复用同一份协方差

> 状态：技术精读 · v1 · 未复现

## 一句话

把 G-ICP 跟踪已算出的局部协方差变为高斯初始化、观测可靠性和地图预算，再让优化后的高斯反哺跟踪，以较低重复计算成本维持在线几何建图。

## 它要解决的问题

[3D Gaussian Splatting](https://repo-sam.inria.fr/fungraph/3d-gaussian-splatting/)把场景表达为具有空间范围的显式基元，便于快速渲染。把它放进长期 SLAM 时，关键难点变成地图如何持续更新：关键帧越多，高斯越多，显存、渲染与配准搜索成本都会增加；错误基元还可能影响下一次定位，使局部错误持续传播。

LiDAR-only 场景依靠距离与几何而非密集 RGB 纹理。[Splat-LOAM](https://arxiv.org/abs/2503.17491)已经探索球面 LiDAR 投影上的高斯重建，本文进一步把跟踪和建图的几何计算打通，并显式管理长期基元数量。它的输出是在线估计轨迹和连续几何地图，适合讨论定位、表面与地图规模，而外观训练是另一项任务。见 §1–3，PDF p.1–4。

## 核心想法

普通拼接式系统可能在跟踪中估一次协方差，在 mapping 再估法向/尺度，然后对全地图重复做邻域搜索。本文选择复用同一份信息：源扫描的局部协方差初始化新增高斯；优化后的高斯直接构造下一帧跟踪的目标协方差；同一组特征值和配准残差又决定哪里合并冗余、哪里增加细节。

协方差在这里描述局部点沿不同方向的分布：平面上两个方向变化大、法向变化小，其特征向量与特征值自然给出切平面方向和相对尺度。G-ICP（一种用源/目标局部协方差加权配准残差的 ICP）已经需要这些量，复用比另加几何估计模块更适合固定实时预算。见 §3.2–3.3、Fig.2。

## 机制

### 球面面片地图与跟踪活跃集

地图为二维各向异性高斯面片，每片保存中心 μ、方向 q、两个面内尺度和透明度 α，外加 LiDAR confidence 与几何 control score。面片位于三维世界，在球面投影下渲染距离、opacity 和法向图，与 LiDAR 扫描的同一图像网格比较。球面投影把每个测量按方位角/俯仰角组织，匹配旋转式 LiDAR 的采样形式。见 §3.1。

扫描先体素降采样。跟踪只用近期、opacity 合格且 mask 允许的高斯子集，以其中心作目标点，减少完整历史地图的搜索开销。每个源点在 kNN 邻域估协方差并缓存特征分解；新关键帧插入时，这些结果直接初始化高斯。

下一帧的目标协方差可以从高斯参数理解为：

C_t=R(q)diag(s_x²,s_y²,ε²)R(q)ᵀ。

ε 是法向小厚度。由参数构造目标协方差只需常数复杂度，省去地图侧重做邻域搜索。随后求解加权 G-ICP：

min_T Σ_i w_i d_iᵀ(C_t,i+R C_s,i Rᵀ)⁻¹d_i。

d_i 是匹配点残差，R 是当前刚体位姿的旋转部分。协方差使切向与法向残差具有不同权重。本文还由面内长短轴比的归一化值构造匹配权重，强调较稳定的平面结构；该权重最高截断为 10。见 Eq.(1)–(5)，p.4–6。

### 为什么协方差初始化还需要乘距离

G-ICP 的协方差常为数值稳定而归一化，它的特征值能表达相对各向异性，却未必保留绝对采样间距。LiDAR 具有固定角分辨率，远处的表面点更稀。本文用：

s_i^(0)=clip(κ_range·r_i·[σ_0,σ_1],0,s_max)，r_i=max(||p_i||,1)，

初始化面内尺度，再优化 log-scale。σ_0/σ_1 是较大的两个标准差，方向由特征向量给出。见 Eq.(6)，p.6。

**示例数值。** 设 κ_range=0.01、切向标准差为 (1,0.5)，暂不触发 s_max 截断。r=10 m 时初始尺度为 (0.10,0.05) m；r=30 m 时为 (0.30,0.15) m。长短轴比保持不变，覆盖范围扩大三倍。这说明协方差复用解决方向/相对形状，range 再补回角采样带来的绝对间隔。

### 可靠性与预算分数分别做什么

观测 confidence 结合 range 衰减与入射角：距离远、擦过表面时置信度较低。由它设置初始 opacity，并与优化后的 opacity 相乘形成 trackability confidence，服务于跟踪筛选。见 Eq.(7)–(8)。这里 opacity 的解释更接近 LiDAR 观测可靠性。

control score 则服务于资源分配。给定协方差特征值 λ_0≥λ_1≥λ_2，线性程度为 (λ_0−λ_1)/(λ_0+ε)，曲率代理为 λ_2/(λ_0+λ_1+λ_2+ε)。把这两者与配准残差归一化后，按 0.55、0.30、0.15 加权到 [0,1]。低分趋向平面冗余，高分趋向边角或复杂结构。见 Eq.(9)，p.7。

平面压缩采用多个正交投影分组，在低分、可靠的基元中选高 opacity 代表，扩张其面内覆盖，删除被覆盖的冗余片，并限制单次删除比例。复杂区则沿面内主轴对称偏移生成两个子高斯，限制 split 比例，让子基元在后续梯度中分别适应不同局部形状。见 §3.5，p.8–9。

这个分数让“哪里值得花基元”成为显式设计，而非一边持续插入、一边等显存不够再处理。大墙面可以稀疏，边角与细结构保留较高容量。

### mapping 怎样改进下一次跟踪

损失只在 LiDAR 有效距离像素上计算，包含 masked L1 range 误差、有效观测位置的正例 opacity BCE、两类法向一致性和过大尺度惩罚。两类法向来自 G-ICP 邻域以及渲染深度差分；后者在 densification 开始后才启用，以免早期不稳。见 Eq.(10)–(13)，p.7–8。

优化更新中心、旋转、尺度和透明度；这些参数随后直接形成跟踪目标协方差。因此 mapping 的作用既是表面更好看，也是目标分布更可信。若更好的目标减少 G-ICP 迭代与失配，增加一些 mapping 工作反而可能降低全系统时间。

回环采用与 KISS-SLAM 相同的检测/pose graph 后端，优化后按源关键帧位姿变化对所属高斯作分段刚性校正。它以低开销维持地图一致性，而不是每次大回环都全局重新训练全部高斯。见 §3.2，p.6。

## 证据：哪个实验支撑哪个主张

KITTI 是车载长序列；Newer College 与 Oxford Spires 为较慢的手持采集，并有参考 mesh，便于同时测轨迹与表面。实验平台为 Ryzen 9 7900X、64 GB RAM、RTX4090，扫描按估计 ego-motion 插值去畸变。ATE 衡量轨迹误差，几何用双向距离及 20 cm 阈值 F-score（不能与其他论文的 2 cm 阈值直接比较）。见 §4.1，p.9–10。

| 主张 | 支撑实验 | 怎么读 |
|---|---|---|
| 几何初始化是固定预算下的重要条件 | Table 3：Quad 完整 F=86.776%，方向/尺度均改 identity 后为 48.688% | 好初值不仅影响早期收敛，也影响最终覆盖 |
| 优化后地图可以提高跟踪效率 | Table 5：完整反馈 ATE 0.079 m/23.70 tracking FPS；冻结 GS 无反馈为 0.099 m/17.69 FPS | 少做 mapping 不保证整个闭环更快 |
| 平面压缩显著减少持久基元 | Table 4：Quad 从 239,175 GS/9.6 MB/F87.179 到 129,885/5.0 MB/F86.776 | 存储近减半，质量有轻微代价 |
| 模型大小与峰值显存不是一回事 | 同一 Table 4：上述两配置峰值 VRAM 为 2.9 GB 与 4.5 GB | 压缩的中间操作也占内存 |
| 在线几何的质量/速度折中较强 | Table 2：四序列平均 F69.51、21.24系统FPS；Quad 为 F86.78/22.15 FPS | 系统 FPS 包含 tracking+mapping，非 RGB 外观训练 |

Table 2 中 Oxford 两序列实际低于 20 FPS，说明实时性仍取决于场景；Table 1 的定位也并非处处最佳，例如 Math 的 PIN-SLAM 优于本文。用 GT pose 的 mapping-only 对照则获得理想位姿输入，帮助观察表面上限，任务条件与在线 SLAM 有差别。

## 局限与后续

作者明确指出：几何退化、稀疏返回、植被和动态物体会使 G-ICP 协方差/法向变得不可靠；体素分辨率、尺度上限、关键帧阈值依赖传感器与场景。回环按关键帧刚性修正，大校正后可能留下局部不一致。见 §5，p.15。

对于 FAST-LIVO2，最值得借的是重复计算的消除：保存上游局部法向/协方差作为高斯初值，限制每次优化的活跃区域，按平面覆盖与复杂度控制长期基元增长。若已决定使用 FAST-LIVO2 前端，研究这些设计时可以保留前端，以便归因后端收益。

更强连续几何提示可以参考 [GS-SDF](../arxiv-2503.10170/README.md)，更完整的 LiDAR-camera-IMU 与 RGB 场景可参考 [Gaussian-LIC2](../arxiv-2507.04004/README.md)。这些方法解决了相邻但不同的目标，后续比较需要固定传感器、轨迹、输入位姿和质量指标。

可做的最小消融是逐步加入：几何初始化、上游统计缓存、局部活跃集、预算压缩。分别记录初始化耗时、每步 mapping、跟踪迭代、最终模型 MB 与峰值 VRAM，判断收益来自省了哪一笔工作。

## 批注

**易误读**
- 四序列平均是 21.24 系统 FPS；摘要的 F86.78 是 Quad，Oxford 两序列为 17.99/19.58 FPS（Table 2）。
- 本文是纯 LiDAR 几何 SLAM，面片位于三维空间、在球面图渲染；它没有可直接比较的球谐 RGB 训练成本（§3.1）。
- Eq.(4) 写 T C_s Tᵀ，按 3×3 协方差应取位姿的旋转部分；面内轴比和特征值“curvature”也是不同的启发式代理（§3.2–3.3）。
- Keble 的 Table 1 ATE 0.177 与消融 Full 0.212 不同；引用时保留表格上下文，不拼成额外精确改善率。
- KITTI00 的压缩结果只报告资源，数据没有 GT mesh；地图更小本身不构成几何无损的证据（p.15）。

**与其他论文的关联**
- [GS-SDF](../arxiv-2503.10170/README.md)同样使用面片高斯和几何法向，但训练连续 SDF 并施加整片形状约束；本文以缓存协方差和在线预算管理减少开销。
- [Gaussian-LIC2](../arxiv-2507.04004/README.md)将几何与 RGB 外观、光度跟踪结合；本文去掉相机监督后专注 LiDAR 几何闭环，可比较的是几何初始化和计算复用，而非直接按 FPS 排名。
- [Splat-LOAM](https://arxiv.org/abs/2503.17491)提供纯 LiDAR 球面高斯建图的相邻基线，本文强调跨 tracking/mapping 的协方差双向复用和长期地图预算。

**未核实 / 待验证**
- 未本地复现，未验证 Livox 非重复扫描、动态环境或用户地图上的默认配置表现。
- 冻结高质量 FAST-LIVO2 中心、仅训练 RGB 是不同任务；本文的冻结反馈消融不能直接判定它一定更慢或更差。
- 没有独立复核全系统 FPS 的并发计时和所有数据集配置；正式复现应保存实际参数、输入序列和重复运行统计。
