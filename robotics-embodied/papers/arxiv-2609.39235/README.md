# The Planning Limits of Latent World Models

> 状态：文献卡 · 2026 · [原文](https://arxiv.org/abs/2609.39235)

- **解决什么**：预测误差低，是否意味着能给远期目标选对动作？[V-JEPA 2](../arxiv-2506.09985/README.md) 式规划还缺少对可用时域的诊断。
- **核心方法**：固定短 rollout（模型向前预测的动作步数），改变目标距离，并用真实仿真动力学替换预测器来隔离误差；结果显示预测更准本身不能补足规划看得太短，延长展开或给近处子目标更有帮助。
- **为什么在这个库里**：给[世界模型](../../fields/world-models/README.md)的长期规划问题一个可检验实验。优先级：选读；闭环是单机械臂仿真，真实机器人数据只作离线诊断，子目标来自同回合专家轨迹，属于特定协议下的经验范围。
