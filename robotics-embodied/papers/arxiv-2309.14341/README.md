# Extreme Parkour with Legged Robots

> 状态：文献卡 · 2023 · [原文](https://arxiv.org/abs/2309.14341)

[返回机器人与具身目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：让一台执行器不精确、只有一个低频且有噪声的前向深度相机的低成本四足（Unitree A1）完成跳上高台、跨越间隙、倒立等极限跑酷动作。
- **核心方法**：两阶段训练。第一阶段在仿真中用 scandots（一句话：机器人周围地形高度的稀疏采样点，只在仿真中可得的特权信息）和由地形上路标点算出的目标朝向训练强化学习策略；第二阶段用 DAgger（一句话：让学生策略自己执行，由教师在学生实际到达的状态上给出动作标签的模仿学习）蒸馏成以深度图为输入的策略，深度经卷积网络和 GRU（门控循环单元，一种带记忆的循环网络）处理，并让策略自己预测朝向（§3.2、3.3）。各种障碍共用一条奖励：机器人速度与指向下一个路标的方向的内积（§3.1）；换成普通的速度跟踪奖励后，策略在台阶地形上学成了「撞上去、弹回、再往前走」的反复尝试行为（§4.3.1）。实机上能跳上约 2 倍自身高度的障碍、跨过约 2 倍自身长度的间隙。
- **为什么在这个库里**：[四足故障后恢复](../../../perspectives/notes/quadruped-recovery.md)四类解法中「加维度」一类：深度视觉加循环记忆，让策略在碰到障碍之前就看见它；那条「撞上去再重试」的消融也是卡住行为在奖励设计上的一个来源。优先级：选读。
