# Precise and Dexterous Robotic Manipulation via Human-in-the-Loop Reinforcement Learning

> 状态：文献卡 · 2024 · [原文](https://arxiv.org/abs/2410.21845)

[返回机器人与具身目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：真实世界的强化学习受样本复杂度、奖励设计和优化稳定性限制，靠视觉高效学会物理上复杂的操作技能一直很难（§1）。
- **核心方法**：HIL-SERL 在真机上直接做离策略 RL：
  - 先用 20–30 条示范和一个二分类奖励分类器（约 200 个正样本、1000 个负样本）起步；
  - 训练中人可以随时接管并纠正，纠正数据和自主数据一起进入回放缓冲。
  
  覆盖插内存条、装同步带、Jenga 抽块等十几个单臂与双臂任务，每任务 100 次试验。与用同样多人类数据训练的 HG-DAgger（人工纠正版 DAgger）相比，平均成功率 100% 对 49.7%，平均完成时间 5.4 s 对 9.6 s（Table 1(a)）。消融：
  - 没有示范和纠正、从零 RL，三项任务全部 0%；
  - 只给示范、不纠正时，仪表盘装配 0%；
  - 翻物体任务的行为克隆从 20 条示范加到 200 条，成功率 47% 和 46%，没有变化（§4.5）。
  
  作者自述：不确定能否扩展到长得多的时域；没有做大范围随机化，也没测非结构化环境中的泛化；每个任务从零训练（§6）。
- **为什么在这个库里**：[模仿与强化学习方向](../../fields/imitation-reinforcement-learning/README.md)中"真机 RL"一格的代表，直接回答"同样多的人类数据，用来模仿还是用来做 RL"；与 [π*0.6](../arxiv-2511.14759/README.md) 都把 [DAgger](../arxiv-1011.0686/README.md) 式人工纠正接进 RL。优先级：必读。
