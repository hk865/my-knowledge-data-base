# Scan Context: Egocentric Spatial Descriptor for Place Recognition Within 3D Point Cloud Map

> 状态：技术精读 · 2018 · [原文](https://doi.org/10.1109/IROS.2018.8593953)

[返回领域目录](../../README.md) · [技术精读](reading.md) · [来源记录](source.json)

- **解决什么**：从三维激光观测中识别曾经到访的地点。
- **核心方法**：把点云编码为极坐标描述子，通过候选检索与循环列移比较获得地点和粗航向。
- **为什么在这个库里**：为三维地图重定位提供候选生成基线。
