# ESKF 教程：大运动交给四元数名义状态，小误差交给三维切空间里的卡尔曼滤波

> 状态：技术精读 · v2 · 未复现 · 原文 [arXiv:1711.02508v1](https://arxiv.org/abs/1711.02508) · [证据档案](../../../docs/deep-readings/evidence/eskf.json)

![ESKF的双轨传播与注入重置](figures/eskf.svg)

## 一句话

Solà 的这份 95 页教程从四元数的约定讲起，推导出 IMU 驱动的误差状态卡尔曼滤波（ESKF）的完整公式链：名义状态传播 → 误差协方差传播 → 观测更新 → 注入 → 重置，并给出"局部误差"和"全局误差"两套成套公式。它的价值在于把每一个约定选择都显式写出来，使一个实现可以逐项核对。

## 它要解决的问题

[定位与建图讲义](../../fields/localization-mapping.md)第七节已经用旋转矩阵讲过 ESKF 的骨架：名义状态承载大运动，15 维误差状态承载小偏差，观测到来时先估误差、再注入、再重置协方差，并算过"1° 倾角误差 10 秒积出约 8.56 m"的量级例子。

把这套骨架写成代码时，会碰到讲义没有展开的三类问题：

- **约定混乱**。姿态在程序里通常用四元数存储，而四元数至少有四个二元选择：分量顺序（标量在前还是在后）、乘法规则、旋转的主动或被动解释、"局部到全局"还是"全局到局部"。两种主流约定是 Hamilton 和 JPL。Trawny 与 Roumeliotis 2005 年的间接卡尔曼滤波教程与本文目标几乎相同，但只用 JPL 约定，Li、Mourikis、Roumeliotis 等人的视觉惯性论文沿用了它；而 Eigen、ROS、Ceres 等机器人常用库用的是 Hamilton。混用两边的公式，就会出现难以追查的符号错误。
- **推导分散**。旋转扰动、雅可比、误差动力学、注入和重置的公式分散在不同文献里，各自的约定不一定一致。
- **离散化细节**。连续时间模型怎样变成每个 IMU 采样间隔的转移矩阵和噪声协方差，教科书常一笔带过，而这些细节直接决定滤波器是否过度自信。

作者引用 Madyastha 等（2011）总结了选择误差状态形式的理由：姿态误差只用 3 个参数，没有冗余参数导致的协方差奇异；误差始终在原点附近，线性化总是有效，也远离万向锁一类参数奇异；二阶项可以忽略，雅可比简单；大信号动力学都在名义状态里积分，误差变化慢，所以观测修正的频率可以低于预测频率。[§5.1]

## 核心想法

这不是一个新算法，增量在"把做法讲清楚并保持自洽"：

1. **统一采用 Hamilton 约定**，并把它与 JPL 的每一处差别列成表（表 2），给出相互转换关系。
2. **误差定义在切空间**：真值姿态 = 名义姿态 ⊗ Exp(δθ)，δθ 是 3 维小旋转向量。从这个定义出发，系统推导误差动力学、观测雅可比、注入和重置。
3. **局部与全局两套公式成套给出**：误差右乘（局部）还是左乘（全局），会同时改变误差方程、观测雅可比、注入方向和重置矩阵，表 4 把差别并列。
4. **附录补齐离散化**：名义状态的数值积分、转移矩阵的闭式和截断近似、测量噪声与随机游走扰动的不同离散化方式。

在[定位与建图的基线](../../fields/localization-mapping/BASELINES.md)中，它是状态估计的数学底座：VIO、SLAM 里的旋转扰动、预积分和协方差公式，都可以对照它来检查。

## 机制

### 四元数与扰动的约定

四元数（一句话：用四个数 q = [w, x, y, z] 表示旋转，单位长度时与三维旋转一一对应到正负号）的乘法记作 ⊗。本文用 Hamilton 乘法、标量在前，并让 q 把局部向量变到全局：a_G = q ⊗ a_L ⊗ q*。

旋转向量 φ = θu（u 是单位旋转轴，θ 是角度）到四元数的指数映射是 Exp(φ) = [cos(θ/2), u sin(θ/2)]，含半角；到旋转矩阵则是 exp([φ]×)。q 与 −q 表示同一个姿态，称为双覆盖。小角时 Exp(δθ) ≈ [1, δθ/2]。

**示例数值**：绕 z 轴转 90°，q = [cos 45°, 0, 0, sin 45°] = [0.7071, 0, 0, 0.7071]；−q = [−0.7071, 0, 0, −0.7071] 旋转同一个向量的结果完全相同。一个 0.02 rad 的绕 z 小修正 Exp((0, 0, 0.02)) ≈ [1, 0, 0, 0.01]，第四个分量是角度的一半。

两种误差定义：

```text
局部误差：q_true = q ⊗ Exp(δθ_L)      （右乘，误差在机体系）
全局误差：q_true = Exp(δθ_G) ⊗ q      （左乘，误差在世界系）
二者关系：δθ_G = R δθ_L
```

对姿态求导时，导数是对 3 维的 δθ 求，而不是对四元数的 4 个分量各自求。右雅可比 J_r（一句话：把旋转向量参数上的增量换算成当前姿态切空间里的增量的矩阵）满足 Exp(φ + δφ) ≈ Exp(φ) Exp(J_r(φ) δφ)，许多预积分和优化公式中多出来的 J_r 就来自这里。[§2–4]

### 状态与 IMU 模型

名义状态 x = (p, v, q, b_a, b_g, g)，存储 3+3+4+3+3+3 = 19 个数；误差状态 δx = (δp, δv, δθ, δb_a, δb_g, δg) 是 18 维，因为姿态误差只有 3 个自由度。讲义里的 15 维是把重力当作已知常量、不去估计的版本。作者还讨论了一种建模选择：把初始姿态设为确定，把初始倾斜的不确定性转给重力方向。[§5.3，表 3]

IMU 模型：

```text
a_m = R_trueᵀ (a_true − g_true) + b_a + n_a      （加速度计测比力）
ω_m = ω_true + b_g + n_g                         （陀螺仪测机体系角速度）
```

偏置按随机游走（一句话：每一步加一个独立的小随机增量，长期可漂移到任意值）建模。滤波器把 IMU 读数称为"输入 u"，它们是测量值；GPS、视觉等互补传感器通过观测 y = h(x_true) + n 进入更新。

### 误差动力学：从真值方程减去名义方程

名义传播：ṗ = v，v̇ = R(a_m − b_a) + g，q̇ = ½ q ⊗ (ω_m − b_g)，偏置与重力的名义导数为零。把真值写成"名义 ⊕ 误差"代入，只保留误差的一阶项，得到局部误差动力学：

```text
δṗ = δv
δv̇ = −R [a_m − b_a]× δθ − R δb_a + δg − R n_a
δθ̇ = −[ω_m − b_g]× δθ − δb_g − n_g
δḃ_a = w_a，δḃ_g = w_g                    （随机游走驱动）
```

速度方程中的 −R[a_m − b_a]× δθ 是理解 IMU 漂移的关键。机体系的比力经过一个稍微错误的旋转，就会指向稍微错误的世界方向。用 R_true ≈ R(I + [δθ]×) 展开，再利用 [δθ]× a = −[a]× δθ，就得到这一项。讲义中的量级例子由此而来：1° 倾角误差让静止时的重力读数漏出约 9.81 × sin 1° ≈ 0.171 m/s² 的水平虚假加速度，持续 10 秒、不考虑其他修正时，位置误差约 ½ × 0.171 × 10² ≈ 8.56 m。陀螺仪偏置因此会通过姿态误差一路影响到位置。[§5.3.3，式 237–259]

### 离散传播：均值和协方差两件事

名义姿态用 q ← q ⊗ Exp((ω_m − b_g)Δt) 更新，位置和速度按当前加速度积分。误差动力学写成 δẋ = A δx + 噪声，得到状态转移矩阵 Φ（一句话：把这一步开始时的误差线性映射到这一步结束时的误差），协方差按 P⁻ = Φ P Φᵀ + Q 传播。误差均值在每次重置后为零，预测后仍为零，所以可以不显式传播；协方差 P 必须每步传播。[§5.4]

附录 A 从 Euler、中点法讲到 RK4（一句话：在一步内取四个斜率加权平均的四阶龙格-库塔积分）；附录 B 在一步内 A 固定时给出 Φ = exp(AΔt) 及 IMU 情形的分块闭式解；附录 C 比较整矩阵截断与分块截断；附录 D 处理 A 随时间变化的情形。

**噪声离散化（示例数值）**。教程区分两类噪声：IMU 的测量噪声在采样时刻取一个值、整个间隔内保持不变；偏置的随机游走扰动从不被采样，在间隔内连续累积。因此离散协方差的写法不同：

```text
测量噪声（采样保持）：Θ_i = σ_ω̃² Δt² I      σ_ω̃ 单位 rad/s（每个采样的标准差）
随机游走扰动：        Ω_i = σ_ωw² Δt I      σ_ωw 单位 rad/s/√s
```

设陀螺仪数据手册给出噪声密度 0.005 rad/s/√Hz，IMU 采样 200 Hz（Δt = 0.005 s）。每个采样的标准差应换算为 σ_ω̃ = 0.005 / √0.005 ≈ 0.0707 rad/s，于是每步姿态噪声方差为 0.0707² × 0.005² ≈ 1.25 × 10⁻⁷ rad²，等价于"密度² × Δt"。若误把密度 0.005 直接当作 σ_ω̃ 代入 Δt² 公式，每步方差变成 6.25 × 10⁻¹⁰ rad²，小了 200 倍。积分 1 秒（200 步）后，正确的姿态标准差约 0.005 rad（0.29°），错误的只有约 0.00035 rad（0.02°），滤波器会过度自信约 14 倍。（密度与采样标准差的换算 σ_ω̃ = 密度 / √Δt 是标准的白噪声采样关系，教程只说明这些参数从数据手册或实验确定。）[§5.4.2 式 262–265，附录 E]

### 更新、注入、重置

观测到来时计算残差 r = y − h(x̂)。观测雅可比必须对误差坐标求导：H = ∂h(x ⊕ δx)/∂δx |₀。按链式法则，它等于"h 对 19 维名义存储量的雅可比"乘以"名义存储量对 18 维误差的雅可比"，后者在四元数处是一个 4×3 块。[§6.1，式 278–281]

卡尔曼增益 K = P Hᵀ (H P Hᵀ + V)⁻¹，误差估计 δx̂ = K r。注入时，平移类量直接相加，姿态用 q ← q ⊗ Exp(δθ̂)。协方差更新推荐 Joseph 形式，原文脚注提醒简化式 (I − KH)P 可能失去对称性和正定性。[§6.1–6.2]

注入之后，真实姿态没变，名义姿态变了，误差的参考点也随之改变。所以要把误差均值归零，同时把协方差搬到新的误差坐标下：P ← G P Gᵀ。局部误差的姿态块 G_θ ≈ I − ½[δθ̂]×，全局误差为 I + ½[δθ̂]×；I − ½[δθ̂]× 一阶等于 Exp(−δθ̂/2)，即把姿态误差的坐标轴反向转过修正量的一半。[§6.3，式 285–294]

**重置手算（示例数值）**。设姿态修正 δθ̂ = (0, 0, 0.02) rad，则

```text
[δθ̂]× = [[0, −0.02, 0], [0.02, 0, 0], [0, 0, 0]]
G_θ  = I − ½[δθ̂]× = [[1, 0.01, 0], [−0.01, 1, 0], [0, 0, 1]]
```

设姿态误差协方差 P_θ = diag(1, 16, 1) × 10⁻⁴ rad²（x、z 轴标准差 0.01 rad，y 轴 0.04 rad）。G P Gᵀ 的 (1,2) 元为 1 × 10⁻⁴ × (−0.01) + 0.01 × 16 × 10⁻⁴ = 1.5 × 10⁻⁵，对应相关系数约 0.037；对角元几乎不变。可见对 0.02 rad 的修正，G 的作用是把不确定性椭球转动约 0.01 rad，影响很小，所以修正小时把 G 近似为单位阵是常见的工程简化；修正越大、各轴不确定度差别越大，这一步越不能省。

### 全局误差版本

第 7 节保留机体系的角速度测量，把姿态误差改为全局定义。名义状态方程不变，误差方程变为 δθ̇_G = −R δb_g − R n_g，速度与姿态的耦合变为 −[R(a_m − b_a)]× δθ_G，观测雅可比的组合块、注入方向（左乘）和重置矩阵都要随之修改。表 4 把这些差异并列，可以直接作为实现核对清单。[§7，表 4]

## 局限与后续

- **没有实验**：教程不提供精度、速度或与其他滤波器的对比。验收一个按它写出的实现，可以用数值一致性测试：随机姿态加小扰动，用有限差分检查 H、A 和 G；比较四元数旋转与矩阵旋转；验证 q 和 −q 结果相同；静止 IMU 的比力应与重力符号一致；用仿真真值检查协方差是否覆盖实际误差。
- **一致性问题**：滤波器的一致性（一句话：给出的协方差与实际误差大小相符）还取决于线性化点、可观测性和噪声建模，教程的误差定义本身不提供这一保证。后续用李群对称性重新定义误差的工作沿这个方向推进：[PLV-IEKF](../arxiv-2311.04477/README.md) 把常规 EKF 的系统不一致和角度漂移列为要解决的问题，改用右不变 EKF；[EqVIO](../arxiv-2205.01980/README.md) 用等变滤波器，使线性化误差只取决于偏置估计误差和测量噪声。
- **学习式组件的接入**：[学习式 IMU 偏置预测](../arxiv-2505.06748/README.md)用网络从历史测量预测偏置，直接提供给不变 MSCKF，而不把偏置放进滤波状态；[自监督可微卡尔曼滤波 VIO](../arxiv-2203.07207/README.md)用网络产生视觉相对位姿观测，由可微滤波器融合并自监督训练。
- **滤波与优化**：多时刻优化路线见 [ORB-SLAM3](../orb-slam3/reading.md)。

## 批注

**易误读**

- "误差状态一直很小"是设计目标和局部近似的工作条件。初始偏差很大或出现错误观测后，这个前提可能不成立（§5.1）。
- 只看到分量顺序 (x, y, z, w) 不能断定用的是 JPL 乘法；存储顺序、乘法代数、主动/被动解释、变换方向是四个独立的选择（§3，表 2）。
- 半角是四元数表示的性质，把旋转矩阵的指数公式直接套到四元数上会差一倍（§2.3）。
- 教程把 R n_a 改写为 n_a 只在噪声各向同性时成立（式 248–250）。
- 18 维与 15 维的差别来自是否估计重力，两者都是正确的建模选择（§5.3）。
- 全局误差版本的式子更短，不代表在所有系统中更准，也不自动等同于任何一种不变 EKF（§7）。

**与其他论文的关联**

- [定位与建图讲义](../../fields/localization-mapping.md)第七节是本篇的 15 维、旋转矩阵、右乘局部误差版本；讲义的 G_reset ≈ I − ½[δθ̂]× 直接取自本篇 §6.3。
- [ORB-SLAM3](../orb-slam3/reading.md) 使用同样的 SO(3) 扰动、Exp/Log 映射和比力模型，但把它们用于多关键帧的 MAP 优化而非递推滤波；其 IMU 初始化同时估计尺度和重力方向，原因正是本篇的速度—姿态耦合项。
- [Convex MPC](../convex-mpc/reading.md) 的初始状态 x₀ 来自 IMU 加关节编码器的状态估计器，下游控制器拿到的是带误差和延迟的估计量。
- [PLV-IEKF](../arxiv-2311.04477/README.md)、[EqVIO](../arxiv-2205.01980/README.md) 改变的是本篇"误差怎样定义"这一步：从 q ⊗ Exp(δθ) 这类定义，换成与系统对称性匹配的不变误差。

**未核实 / 待验证**

- 一般连续白噪声模型下 Q_d = ∫ Φ L Q_c Lᵀ Φᵀ dτ 的离散化，是标准线性随机系统的补充说明，不是本篇附录给出的公式。
- 噪声示例中的密度值 0.005 rad/s/√Hz 是虚构的教学数值，不对应任何具体 IMU 型号。
- 网络输出进入滤波器前需要明确坐标系、时间戳、相关性和协方差，这是阅读建议；上面两篇学习式 VIO 的具体做法只核对了摘要。
