# RADIO-ViPE: Online Tightly Coupled Multi-Modal Fusion for Open-Vocabulary Semantic SLAM in Dynamic Environments

> 状态：文献卡 · 2026 · [原文](https://arxiv.org/abs/2604.26067)

- **解决什么**：从单目 RGB 视频获得适应动态场景的开放词汇语义地图。
- **核心方法**：将视觉与语言表征用于初始化、图连接与几何优化，并采用自适应鲁棒核；相关官方项目现名 QUORUM。
- **为什么在这个库里**：帮助区分语义仅标注地图和语义直接参与估计这两条路线。优先级：必读。

[官方代码](https://github.com/be2rlab/QUORUM)
