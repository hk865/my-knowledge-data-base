# MEM: Multi-Scale Embodied Memory for Vision Language Action Models

> 状态：文献卡 · 2026 · [原文](https://arxiv.org/abs/2603.03596)

[返回机器人与具身目录](../../README.md) · [原文版本与阅读记录](source.json)

- **解决什么**：端到端策略的"记忆"通常就是把过去的观测排成序列输入；但多阶段的真实任务既要记住十几分钟前的抽象事件（菜谱做到了哪一步），又要记住几秒前的细节（手臂挡住之前看到的物体在哪）。直接堆帧在实时延迟下撑不过几个时间步。
- **核心方法**：在 π0.6 上把记忆分成两种模态。短时记忆是视频：视觉编码器每 4 层插入一次时间注意力，不增加可学习参数，预训练用 6 帧、间隔 1 秒，推理时可扩到 18 帧、54 秒。长时记忆是文字：高层策略在执行中不断更新一段语言摘要，训练标签由现成的大语言模型从带子任务标注的回合里生成，并要求它适时删减、压缩，以免训练与部署的分布不一致。机器人因此能完成长达约 15 分钟的整理厨房、准备烤芝士三明治等任务。消融中，去掉视频记忆会卡住、去掉语言记忆会忘掉较早的事件，直接拼接历史指令的"朴素语言记忆"明显更差；在不依赖记忆的灵巧任务上与无记忆的 π0.6 持平。记忆还让策略能在回合内调整做法（抓筷子的高度、开冰箱门的方向）。
- **为什么在这个库里**：[VLA 方向](../../fields/vla/README.md)开放问题"记忆"的 Physical Intelligence 答案：[π0.5](../arxiv-2504.16054/README.md) 自述没有记忆，[π0.7](../arxiv-2604.15483/README.md) 已沿用 MEM。与 [RoboTTT](../arxiv-2607.15275/README.md)（把历史写进快权重）和[具身 Agent](../../fields/embodied-agents/README.md)方向的 [MEMORA](../memora/reading.md)（外部记忆库）对照：记忆放在模型内部的视频与文字、放进参数，还是放在模型之外。作者把跨回合的记忆列为未来工作。优先级：选读。
