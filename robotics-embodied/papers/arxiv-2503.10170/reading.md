# GS-SDF：把整个高斯面片约束到连续表面

> 状态：技术精读 · v2 · 未复现

## 一句话

用 LiDAR 训练的连续 SDF 给 2D 高斯一个可信表面，再把整个高斯面片而非仅中心约束到该表面，同时保留高效的图像渲染。

## 它要解决的问题

[2DGS](https://surfsplatting.github.io/)已经能用具有方向和覆盖范围的二维高斯面片表示三维表面，并通过光栅化快速生成图像。问题是：面片的几何同时受图像损失牵引，图像看起来对，不代表面片真的贴着物体表面。机器人沿一条自由轨迹走过场景时，常缺少物体环绕式多视角，优化容易通过移动面片、扩大覆盖或调整透明度解释图像，产生浮点、地面错位和不自然遮挡。

LiDAR 提供准确却离散的几何观测。直接从点云初始化中心，解决了“基元大概放在哪里”，仍留下“整片面向哪里、覆盖多大、两点之间是什么表面”的问题。GS-SDF 把这些问题转为连续几何场与渲染基元的配合：输入已经有位姿的图像和 LiDAR 点云，输出可渲染的高斯场景与精细 mesh。论文直接使用 FAST-LIVO2 提供的位姿和点云，重建后端是它的主要研究对象。见 [§III](https://arxiv.org/html/2503.10170v2#S3)，PDF p.2–3。

## 核心想法

相对只靠图像约束方向的 2DGS，增量集中在两处：先把 LiDAR 转为连续几何，给高斯一套位置、方向、尺度和透明度的合理初值；再从每个面片上采样，使整个面片朝可信表面靠拢。这个采样损失可以同时影响中心、旋转和尺度，避免只移动中心而留下错误倾斜的大面片。

这里的 SDF（有符号距离场）把三维位置映射为离表面的有符号距离，零水平集就是表面；神经 SDF 用可训练网络表达这个函数。高斯承担快速的外观表示，SDF 承担连续表面的几何提示。论文还让二者联合更新，使几何与图像证据共同细化重建。

## 机制

### 从点云得到连续表面

网络输入位置 x，输出距离 s 和占据转换尺度 β。位置先经过多分辨率 hash encoding（一种在多种网格尺度上查询并拼接可学习特征的表示），再由小 MLP 预测。沿每条 LiDAR 射线采样，实际回波前后的距离差提供表面与自由空间监督；Eikonal 项约束 ||∇s|| 接近 1，使输出具有距离函数的性质。见 §III-B，Eq.(3)–(4)。

实现的主要容量是 32 维编码特征、宽 64 的三层隐藏 MLP。论文先做 10,000 次 SDF 训练，再进行 30,000 次高斯训练；这些设置的意义是先形成粗表面，再拟合外观，而不是从随机基元同时猜测所有内容。见 §IV-A，p.4。

### 由 SDF 初始化面片，再预热颜色

对粗 SDF 用 marching cubes（一种从采样网格抽取指定等值面的算法）抽 mesh，以顶点初始化高斯中心。网格分辨率同时决定初始覆盖尺度；SDF 梯度给表面法向，结合切向构造旋转。透明度初值为 exp(−s²/β)。远处背景另用球面铺设高斯，给天空等无 LiDAR 返回的内容留出画布。见 §III-C.1–2，p.3。

一个面片的参数包括中心 p、正交切向 t_u/t_v、尺度 s_u/s_v、透明度 α 和球谐颜色。球谐颜色用方向基函数的线性组合表达随观察方向变化的 RGB。局部采样位置映射为：

p(u,v)=p+s_u u t_u+s_v v t_v，G(u,v)=exp[−(u²+v²)/2]。

光栅化将面片投到图像，按深度顺序合成，C=Σ_i c_iw_i，其中 w_i=α_iG_iΠ_{j<i}(1−α_jG_j)。遮挡和透明度因此影响每个基元对像素的贡献。见 §III-A，Eq.(1)。

初始化颜色时，论文把中心、旋转、尺度、透明度全部固定，让全部训练图像过一轮，仅更新颜色。作用是避免错误颜色在早期把已经合理的结构拖偏，随后再解冻结构。这个阶段直接回答了“已有好几何时能否先只学外观”：论文确实这样做。见 [§III-C.3](https://arxiv.org/html/2503.10170v2#S3.SS3.SSS3)及 Fig.10，p.7。

### 面片采样怎样约束形状

每个面片采一个二维标准正态位置 u_s，映射为三维 p_s，然后计算：

L_s=Σ_i ½ W_iG(u_si)f(p_si)²。

W_i 是该面片在图像中的累积贡献，G 让面片中心区域更重要。p_s 同时依赖中心、切向和尺度，损失梯度因此可以共同校正面片形状。见 [§III-D.2](https://arxiv.org/html/2503.10170v2#S3.SS4.SSS2)，Eq.(6)–(7)、Fig.3，p.4。

**示例数值：中心贴地仍不够。** 设真实地面 z=0，中心 p=(0,0,0)，但一个切向 t_u=(cos30°,0,sin30°) 倾斜 30°，尺度 s_u=0.2 m。取 u_s=1、v_s=0，采样点高度是 0.2×sin30°=0.1 m。中心约束误差为 0，面片采样却发现了偏离。若 W=1、G=exp(−1/2)≈0.6065，该样本 L_s=½×0.6065×0.1²≈0.00303（乘形状权重前）。这就是整片约束比只拉中心更完整的原因。

另外保留渲染法向一致性：将高斯法向渲染图 N，与渲染深度的有限差分法向 N̂ 对齐，L_r=1−NᵀN̂。图像颜色项为 0.8 L1+0.2 DSSIM。总目标 Eq.(8) 把 LiDAR 的 SDF 监督、Eikonal、颜色、法向和形状项相加。渲染正则负责图像空间的表面一致性，SDF 形状项负责三维连续表面的约束，两者覆盖的信息互补。

### 接入 FAST-LIVO2 与轻量变体

[官方数据准备](https://github.com/hku-mars/GS-SDF#43-custom-fast-livo2-datasets)列出了相机/LiDAR 位姿、原始图像、body-frame 点云导出与 rosbag→COLMAP 转换。保留这些输入比只保存最终有色 PLY 更有价值：图像训练需要相机内参和逐帧位姿，SDF 射线监督还需要测量原点与距离。

对已很可信的几何，代码提供了进一步减负方向：[detach_sdf_grad](https://github.com/hku-mars/GS-SDF/blob/a7372eb911f3d92a0200c6989ba131072622e3fd/config/base.yaml#L47)可以冻结 SDF 网络并跳过联合阶段的 SDF 射线再训练；之后仍计算面片采样的 SDF 形状损失。它相当于固定可信几何场，让高斯向其靠拢。高斯结构则仍可更新，颜色预热和 SDF 冻结是两种不同的分阶段设计。见 [gs_train L369–458](https://github.com/hku-mars/GS-SDF/blob/a7372eb911f3d92a0200c6989ba131072622e3fd/include/neural_mapping/neural_mapping.cpp#L369-L458)。

## 证据：哪个实验支撑哪个主张

Replica 是室内 RGB-D 场景，论文同时测试训练轨迹附近的插值渲染和均匀采样新位置/方向的外推渲染。真机场景由 FAST-LIVO2 提供位姿，每第八张图像留作测试，主要量化插值外观。几何用抽取 mesh 的 Chamfer-L1 距离和 2 cm 阈值 F-score 评价，图像用 PSNR/SSIM 衡量。见 §IV-B/C。

| 主张 | 支撑实验 | 怎么读 |
|---|---|---|
| 高斯外观与精细几何可以兼顾 | Table I：Replica 插值 PSNR 41.433 dB；几何 C-L1 0.506 cm，M2Mapping 为 0.499 cm | 插值强，几何接近所比较 NeRF 系统，而非所有几何指标第一 |
| 真实自由轨迹下渲染有收益 | Table II：真机平均 SSIM 0.830，3DGS 为 0.799 | 几何初始化/正则对单轨迹数据有帮助；各场景并非所有指标都胜 |
| 整片约束比只拉中心更贴近表面 | Fig.8–9：中心约束改为形状约束，地面纹理/法向更合理；对应 PSNR 28.60→28.66 dB | 主要证据是结构改善，分数增益很小 |
| 训练后渲染快，训练本身有额外成本 | §IV-E：Room-2 16.6 分钟训练、101.1 FPS 渲染；2DGS 9.1 分钟、103.2 FPS | 平台 i7-13700K/RTX4090，图像 1200×680；FPS 指推理 |
| 外推仍是短板 | Table I：外推 PSNR 33.725 dB，M2Mapping 38.226 dB | 清晰细纹理与偏离训练轨迹后的自然一致性是不同目标 |

初始化消融特别值得读：Fig.9 显示随机属性初始化即使经过训练也可能留下不合理结构；Fig.10 显示颜色预热有助于避免早期结构偏离。这比单纯增加训练迭代更贴近“好点云怎样真正成为好高斯初值”的问题。

## 局限与后续

论文直接承认外推渲染不及所比较的 NeRF 方法。它得到的是快速、较几何一致、细纹理清晰的表示，未观测内容仍缺少充分约束。真实场景的精细 mesh 与任意视角外推主要是定性展示，进一步验证应保留真实几何参照和远离训练轨迹的相机测试。

对上游输入的依赖也很实际：点云与图像的时间同步、相机模型、外参和位姿误差，会同时影响几何场和渲染监督。若目标是可量测表面，应先测几何偏移；若目标只是快速漫游，可以研究颜色预热后固定中心、只开放尺度/方向/透明度等变体，再与完整联合训练比较。

[LiDAR-GS-SLAM](../arxiv-2607.04127/README.md)提供了另一种减少几何成本的方向：缓存上游已经估计的局部协方差，并按几何复杂度分配基元；[Gaussian-LIC2](../arxiv-2507.04004/README.md)则把重点放在在线增量建图与跨模块 GPU 工程。这些是不同目标下可借鉴的设计，仍需在相同数据和后端中做独立消融。

## 批注

**易误读**
- 101.1 FPS 是训练后渲染，16.6 分钟才是所报告场景的训练时长（§IV-E，p.8）。
- 颜色预热后会解冻结构；SDF 几何正则是软约束，并不保证中心全程不动（§III-C/D）。
- 论文 Eq.(3) 的预测/目标占据量在对数内外的排列与通常 BCE 写法不同；[实现](https://github.com/hku-mars/GS-SDF/blob/a7372eb911f3d92a0200c6989ba131072622e3fd/include/optimizer/loss.cpp#L49-L78)实际将预测作为 logits、射线监督作为 target。
- detach_sdf_grad 的当前默认与“复现论文设为 1”的注释存在差别；配置还会改变 SDF 迭代数，引用实验必须固定配置而非只写仓库名。

**与其他论文的关联**
- [Gaussian-LIC2](../arxiv-2507.04004/README.md)同样结合 LiDAR 与图像，但主线是在线 SLAM/光度跟踪；本文主线是已有位姿下的连续几何与外观重建。
- [LiDAR-GS-SLAM](../arxiv-2607.04127/README.md)同样用面片高斯和法向，但以 G-ICP 协方差替代额外连续 SDF 几何估计，换取在线处理与长期地图预算。
- [2DGS](https://surfsplatting.github.io/)提供面片渲染与法向一致性基线，本文增量在 LiDAR-SDF 初始化和面片形状约束，而非另造一种基本光栅化范式。

**未核实 / 待验证**
- 未本地复现，也没有永久冻结高斯全部几何的质量/速度消融。
- 冻结 SDF、降低训练分辨率或减少增密，在自己的 FAST-LIVO2 数据上的收益要分别实测；公开代码注释未给可靠倍数。
- 动态物体、透明/镜面、稀疏植被、错误外参等条件下的鲁棒性没有由本文现有结果充分覆盖。
