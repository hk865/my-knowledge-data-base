# SimpleVLA-RL: Scaling VLA Training via Reinforcement Learning

> 状态：文献卡 · 2025 · [原文](https://arxiv.org/abs/2509.09674)

[返回机器人与具身目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：VLA（视觉语言动作模型）靠监督微调扩大规模，需要大量昂贵的人工遥操作轨迹，遇到分布偏移时泛化有限（§1）。
- **核心方法**：把 LLM 推理模型的 RL 配方搬到 VLA 上：以 OpenVLA-OFT 为起点，在仿真中只用 0/1 的任务成功奖励，用 GRPO（组内相对策略优化，一句话：同一任务采多条轨迹，用组内平均成绩作基线算优势，不需要价值网络）更新，并去掉 KL 正则、提高采样温度、放宽裁剪上界、丢掉全成功或全失败的批次来鼓励探索（§3.2–3.4）。在 LIBERO-Long 每个任务只给 1 条示范的设定下，成功率从监督微调的 17.3% 提高到 91.7%；训练中出现了示范里没有的"推过去"策略（作者称 pushcut，§6.1）。作者自述：基座模型在某任务上完全不会时，RL 无法起步，提升幅度随初始能力增大（§6.2）。
- **为什么在这个库里**：[模仿与强化学习方向](../../fields/imitation-reinforcement-learning/README.md)"在模仿之上用 RL 微调"一格的仿真代表，与 [π*0.6](../arxiv-2511.14759/README.md) 的真机路线对照；它直接借用了 [DeepSeek-R1](../../../llm/papers/arxiv-2501.12948/README.md) 一类 LLM 后训练的做法，是两个领域共用一套 RL 方法的例子。优先级：选读。
