# Learning to Walk in Minutes Using Massively Parallel Deep Reinforcement Learning

> 状态：文献卡 · 2021 · [原文](https://arxiv.org/abs/2109.11978)

[返回机器人与具身目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：用强化学习训练四足行走策略通常要几小时到几天，奖励和环境每改一次都要等很久，迭代很慢。
- **核心方法**：在单块 GPU 上用 Isaac Gym（NVIDIA 的 GPU 物理仿真环境）同时仿真数千台机器人跑 PPO（近端策略优化，一种常用的同策略强化学习算法），并为这种大规模并行调整批量与超参。重置分两种处理：摔倒等失败重置照常处理；超时重置时，用 critic（价值网络，一句话：预测从当前状态起未来折扣回报的网络）自己的预测补上被截断的回报，这一处理让 critic 损失下降、总奖励提高约 10%–20%（附录 A.2，与不做此处理相比）。地形课程沿用 Lee 等 2020 的自适应课程思路，把其中的粒子滤波换成「游戏式」升降级：机器人走出本格地形就升一级，一回合走不到命令速度对应距离的一半就降一级，通关最高级的机器人被随机送回某一级，以保持多样性、避免灾难性遗忘（§3.1）。ANYmal 的平地策略不到 4 分钟、崎岖地形策略约 20 分钟训练完成，比此前工作快几个数量级，并迁移到实机；训练代码以 legged_gym 开源。
- **为什么在这个库里**：[四足故障后恢复](../../../perspectives/notes/quadruped-recovery.md)四类解法中「场景」一类的基础设施：按表现自动调整训练场景难度，并用回送机制防止学新忘旧。它的奖励设置把机身触地视为 crash 并重置（§3.2），这正是排查「失败状态是否进入训练数据」时要先核对的一项。优先级：必读。
