# ABot-N1: Toward a General Visual Language Navigation Foundation Model

> 状态：文献卡 · 2026 · [原文](https://arxiv.org/abs/2607.10383)

[返回机器人与具身目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：已有导航基础模型的目标坐标会因地图路线或定位误差漂移到不可达处，端到端策略混淆探索与接近、多目标负迁移，且缺少可读的决策过程。
- **核心方法**：慢的视觉语言推理器显式推理并输出像素目标，快的动作专家输出连续航点；用 3000 万样本覆盖点目标、指令跟随、物体目标、POI 目标、跟人五类任务，并开放两个真实场景 benchmark。POI 到达率 77.3%，比此前最好方法高 35 个百分点。
- **为什么在这个库里**：[导航与规划](../../fields/navigation-planning/README.md)主线第 6 步：2026 年导航基础模型的规模化代表，坐标漂移问题的入口。优先级：选读。
