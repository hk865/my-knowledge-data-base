# Introducing Helix 02: Full-Body Autonomy

> 状态：文献卡 · 2026 · [原文](https://www.figure.ai/news/helix-02)

[返回机器人与具身目录](../../README.md) · [原文版本与阅读记录](source.json)

- **解决什么**：Figure 此前的 Helix 只控制上半身；要在整间厨房里连续干活，机器人得同时走、平衡和用手，传统的"下半身行走控制器 + 上半身操作策略"拼接接不起来。
- **核心方法**：2026-01-27 的官方博客给出三层结构。System 0 是 10M 参数的全身控制器，以 1 kHz 把全身关节状态和机身运动映射成关节级执行器指令；它用超过 1,000 小时重定向到关节级的人体动作数据，在 20 万个以上并行仿真环境里用 RL 训练、加大域随机化后上真机，替换了 109,504 行手写 C++。System 1 是 200 Hz 的视觉运动策略，输入头部相机、手掌相机、指尖触觉（能感知约 3 克的力）和全身本体感知，以 System 2 的潜变量为条件，输出给 S0 的全身关节目标。System 2 负责理解场景与语言、给出目标。演示是一段 4 分钟、61 个移动操作动作的装卸洗碗机任务，全程无重置、无人干预，用胯部关抽屉、用脚抬洗碗机门；博客称结果还早，没有给出成功率或失败案例。
- **为什么在这个库里**：[运动控制方向](../../fields/control-locomotion/README.md)"工业界方案"与"为什么绕不开模仿学习"的公司证据：全身控制器的训练信号是人体动作数据加仿真 RL，与 [SONIC](../arxiv-2511.07820/README.md)、[BeyondMimic](../arxiv-2508.08241/README.md) 同一路；也是 [VLA 方向](../../fields/vla/README.md)"VLA 之下仍有一层学到的全身控制器"的实例（S0 的频率比 S1 高 5 倍）。优先级：选读。
