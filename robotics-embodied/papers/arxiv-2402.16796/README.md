# Expressive Whole-Body Control for Humanoid Robots

> 状态：文献卡 · 2024 · [原文](https://arxiv.org/abs/2402.16796)

[返回机器人与具身目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：让真实人形机器人做出像人一样丰富的全身动作。作者指出直接拿图形学的动作捕捉数据做模仿在真机上行不通：图形学角色的执行器增益比现有硬件可行的大一个数量级，人体模型 69 个自由度而 Unitree H1 只有 19 个（§I）。
- **核心方法**：把全身模仿拆开：上半身模仿参考动作，两条腿不再逐关节模仿，只要求稳健地跟随参考动作给出的根部运动命令（「不完全照抄参考动作」是作者写明的核心想法）。数据是约 780 段 CMU 动作捕捉，经重定向后用 RL 训练，回合从参考动作中随机抽帧开始（参考状态初始化，RSI）。消融（表 IV，平均回合长度）显示 RSI 不可少：完整方法 16.87，去掉 RSI 只有 0.23，作者解释为策略找不到正奖励状态，学会了尽快「自杀」以避开负奖励；改用随机采样的目标时策略一开局就跪下，钻了环境的空子；全身逐关节跟踪的各项指标都更差。
- **为什么在这个库里**：[运动控制与腿足运动](../../fields/control-locomotion/README.md)「为什么绕不开模仿学习」一节的主证据之一：没有动作数据给出起始状态，RL 连正奖励都找不到；同时说明人体动作要「改造后再模仿」。后续是 [ExBody2](../arxiv-2412.13196/README.md)（全身跟踪 + 自动筛掉不可行动作）。优先级：选读。
