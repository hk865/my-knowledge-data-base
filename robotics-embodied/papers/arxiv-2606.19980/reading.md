# ENPIRE：Agent 怎样组织真机策略改进

论文卡（本地来源，未发布） · [官方原文](https://arxiv.org/abs/2606.19980v2) · [官方 PDF](https://arxiv.org/pdf/2606.19980v2)

## Agent 从执行任务转向组织机器人实验

ENPIRE 的核心不是让 LLM 每步出动作，而是让 coding agent 改进机器人策略和训练方法。作者指出，真实策略学习常被人工判分、复位和调试阻塞，因此先把这些流程变成可靠环境接口，再允许 Agent 通过物理试验检验改进假设。（§2）

## 两个阶段必须分开看

第一阶段有人参与：定义安全区域，利用成功/失败演示和传感记录构造自动验证器，以及可重复复位程序。经过检查后，安全、奖励和复位接口固定。第二阶段才是策略研究：Agent 查看试验结果、轨迹和视频，修改程序策略、训练代码或学习算法，重新运行并评价；多个机器人/Agent 可以并行探索不同假设。

以插销任务为例，开始前必须知道哪些位姿是合法的、什么传感证据算插入、失败后怎样拔出并回到起点。研究 Agent 才能比较新的接近方式、力控策略或学习配方。若奖励将“碰到孔边”误认作插入，系统会围绕错误目标优化；这也是固定和独立核验环境模块的重要性。

## 到底训练了谁

通用 coding agent 可以保持冻结，但它管理的机器人策略可能进行行为克隆或强化学习，也可能是程序启发式优化。因此 ENPIRE 的“自主改进”并非“整个系统不训练”。其经验也不只是给下一次 prompt 加几句话，还可能改变可执行代码和模型权重。

论文的真机任务包括 Push-T、Pin Insertion 及更多精细操作，研究达到目标性能所需时间、机器人利用率与 token 利用率，具有物理研发闭环证据。自动复位适合选定任务，并不意味着任意家庭环境都能无人复位；部分成功口径允许恢复尝试，不能当作单次无恢复精度。（§3、附录）

## 对本工程的意义和顺序

当前 RPent 单任务复现还不是自主研究平台。更近的一步是建立可靠评测与失败分类：只有奖励、重置与记录可重复，才值得自动搜索程序或训练方法。否则自动化只会更快地产生不可解释结果。

ENPIRE 与 Harness VLA 的角色不同：前者组织改进策略的实验，后者组织一次任务中的执行。二者未来可以结合，但本次只整理方法，没有启动训练、修改奖励或开放自主代码写入。
