# Humanoid Locomotion and Manipulation: Current Progress and Challenges in Control, Planning, and Learning

> 状态：文献卡 · 2025 · [原文](https://arxiv.org/abs/2501.02116)

[返回机器人与具身目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：人形机器人的移动与操作（HLM）在模型方法和学习方法上都进展很快，但两条线往往分开发展，缺一份把控制、规划、学习放在一起比较的综述。
- **核心方法**：综述，不提出新方法。先回顾三十年来作为人形主干的模型方法（接触规划、运动规划、全身控制，以及模型保真度与计算效率的取舍），再讲以强化学习和模仿学习为主的学习方法，讨论基础模型与人形本体的结合、全身触觉的作用，最后从鲁棒性、计算效率、通用性、泛化等维度比较两种范式的长短。
- **为什么在这个库里**：[运动控制与腿足运动](../../fields/control-locomotion/README.md)方向人形部分的地图，用来定位 [Humanoid-Gym](../arxiv-2404.05695/README.md)、[ExBody2](../arxiv-2412.13196/README.md)、[GR00T N1](../arxiv-2503.14734/README.md) 各自处在「模型与学习」「移动与操作」的哪一处。优先级：选读。
