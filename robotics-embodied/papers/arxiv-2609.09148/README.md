# Proxy Policy Steering

> 状态：文献卡 · 2026 · [原文](https://arxiv.org/abs/2609.09148)

- **解决什么**：大型动作策略适应具体任务时训练与部署成本高，怎样用较小模块改变其生成行为。
- **核心方法**：相对直接微调π0.5，训练参考代理和任务代理，用两者预测速度场之差修正冻结基座的flow生成。
- **为什么在这个库里**：[具身 Agent 基线表](../../fields/embodied-agents/BASELINES.md)中的可训练动作工具，说明“保留大模型、学习小模块”的接口；论文本身未加入通用LLM编排器。优先级：选读。
