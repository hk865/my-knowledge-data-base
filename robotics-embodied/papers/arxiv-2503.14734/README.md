# GR00T N1: An Open Foundation Model for Generalist Humanoid Robots

> 状态：文献卡 · 2025 · [原文](https://arxiv.org/abs/2503.14734)

[返回机器人与具身目录](../../README.md) · [原文与阅读记录](source.json)

- **解决什么**：人形机器人缺一个能跨本体、用多种数据训练的开放基础模型；真实机器人数据量少，且各本体的数据彼此隔离，形成「数据孤岛」。
- **核心方法**：双系统 VLA（视觉语言动作模型，一句话：输入图像和语言指令、直接输出机器人动作的模型）：System 2 是 NVIDIA Eagle-2 视觉语言模型，理解图像和指令；System 1 是用流匹配（一句话：学习把噪声连续变换成数据的速度场，与扩散同类的生成方法）训练的扩散 Transformer，跨注意力读取 VLM 特征，生成连续动作块，两部分端到端联合训练。数据组织成「数据金字塔」：底层是网络数据与人类视频，中层是仿真和神经网络生成的合成数据，顶层是真机数据；无动作标签的视频用潜在动作码本和逆动力学模型补出伪动作。公开的 GR00T-N1-2B 共 2.2B 参数，在 Fourier GR-1 人形上做语言条件的双臂操作。
- **为什么在这个库里**：[视觉语言动作模型](../../fields/vla/README.md)方向「数据」与「动作生成」两个部件的组合：动作头与 [π0](../arxiv-2410.24164/README.md) 同用流匹配，数据侧把视频与合成数据当作额外本体。它做的是人形上半身操作，与腿足运动控制关系较远。优先级：选读。
