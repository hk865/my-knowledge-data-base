# ConceptGraphs: Open-Vocabulary 3D Scene Graphs for Perception and Planning

> 状态：技术精读 · 2024 · [原文](https://arxiv.org/abs/2309.16650)

[返回领域目录](../../README.md) · [技术精读](reading.md) · [来源记录](source.json)

- **解决什么**：动态变化的视觉数据如何汇成对象级三维场景表示。
- **核心方法**：结合图像分割、多视角对象关联及点云融合，构建开放词汇对象图。
- **为什么在这个库里**：研究对象融合、关系构建及其在线边界。
