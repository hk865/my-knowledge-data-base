# WildGS-SLAM: Monocular Gaussian Splatting SLAM in Dynamic Environments

> 状态：文献卡 · 2025 · [原文](https://arxiv.org/abs/2504.03886)

- **解决什么**：减少动态物体对单目跟踪及高斯地图的污染。
- **核心方法**：由 DINOv2 特征和浅层多层感知机预测不确定性，同时指导稠密束调整与高斯地图优化。
- **为什么在这个库里**：是学习特征辅助动态处理与高斯建图组合的代表，用于判断地图扩展的增量。优先级：选读。

[官方代码](https://github.com/GradientSpaces/WildGS-SLAM)
