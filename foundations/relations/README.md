# 跨模块关系页

[回到基础模块](../README.md)

关系页把分散在多个基础讲义和论文卡片里的同一条概念链串成一页：每个节点写清它是什么、与上一节点是哪一种关系（`[结构]` 数学结构对应、`[经验]` 实验发现、`[历史]` 作者自述或引用链），以及支撑它的讲义章节或论文。只有把节点连起来才能看到的结论，写在每页的"这条链解释了什么"一节。

- [递推状态谱系](recurrent-state.md)：状态方程 → RNN → LSTM → 线性递推与 SSM（S4、LRU）→ Mamba → 线性注意力。核心问题是状态转移怎样同时做到稳定、按内容选择、可并行。
- [注意力与 FFN 的分工谱系](attention-ffn-division.md)：注意力的 A 与 V → Induction Heads → FFN 键值记忆 → ROME 与事实读出 → MoE → Engram。核心结论是事实主要存于 MLP、由注意力读出，稀疏化与查表一直作用在不依赖上下文的那一侧。
